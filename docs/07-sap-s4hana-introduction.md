# SAP S/4HANA 介绍

**SAP S/4HANA** 是 SAP 公司推出的第四代企业资源规划（ERP）套件，全称为 "SAP Business Suite 4 SAP HANA"。

## 核心特点

- **基于 HANA 内存数据库**：充分利用内存计算技术，实现实时数据处理和分析
- **简化架构**：相比之前的 SAP ECC，大幅简化了数据模型和表结构
- **实时分析**：事务处理和分析处理在同一系统中进行，无需数据复制

## 主要功能模块与二级模块

### 1. 财务管理 (Finance)

#### 1.1 财务会计 (Financial Accounting, FI)
- **总账 (GL)**：主账簿管理、会计科目表、财务报表
- **应付账款 (AP)**：供应商管理、发票处理、付款处理
- **应收账款 (AR)**：客户管理、账单处理、收款管理
- **资产会计 (AA)**：固定资产管理、折旧计算、资产处置
- **银行会计 (BCA)**：银行对账、现金管理、支付向导

#### 1.2 管理会计 (Controlling, CO)
- **成本要素会计 (CE)**：成本与收入要素管理
- **成本中心会计 (CCA)**：成本中心控制、内部订单
- **利润中心会计 (PCA)**：利润中心分析、获利能力分析
- **产品成本控制 (PC)**：成本估算、成本对象控制
- **获利能力分析 (CO-PA)**：市场细分分析、盈利分析
- **内部订单 (IO)**：项目跟踪、专项费用管理

#### 1.3 资金管理 (Treasury, TR)
- **现金管理 (CM)**：流动性预测、资金池管理

- **市场风险管理 (MR)**：汇率风险、利率风险分析
- **财务供应链管理 (FSCM)**：现金与流动性管理、收款与支付管理

#### 1.4 其他财务模块
- **合并财务报表 (EC-CS)**：多公司合并、集团报表
- **旅行费用 (TR)**：差旅费管理、费用报销
- **基金管理 (FM)**：预算管理、基金追踪

## 与 SAP ECC 的区别

| 特性 | SAP ECC | SAP S/4HANA |
|------|---------|-------------|
| 底层数据库 | 支持多种数据库 | 仅支持 SAP HANA |
| 数据模型 | 复杂，多表关联 | 简化，消除冗余 |
| 用户体验 | SAP GUI | Fiori（现代化 Web UI）|
| 分析能力 | 需要分离的数据仓库 | 实时嵌入式分析 |

### 2. 应用层 (Application Layer)

#### 2.1 ABAP 应用服务器
- **编程语言**：ABAP (Advanced Business Application Programming)
- **ABAP 运行时**：支持面向对象编程、内嵌 SQL
- **核心组件**：
  - **Business Objects**：业务对象的抽象表示
  - **BAPI (Business API)**：业务对象的标准接口
  - **IDoc / ALE**：电子数据交换和应用程序链接

#### 2.2 Core Data Services (CDS)
- **CDS Views**：定义数据模型的声明性语言
- **CDS Entities**：业务实体的语义化定义
- **CDS Annotations**：元数据和扩展定义
- **类型系统**：强类型数据定义
- **示例**：
```abap
@EndUserText.label: 'Sales Order View'
@AccessControl.authorizationCheck: #CHECK
define view C_SalesOrder as select from sepa {
    key sales_order_id,
        customer_id,
        sales_amount,
        currency
}
```

#### 2.3 Business Frameworks
- **Business Add-Ins (BAdIs)**：扩展点和增强机制
- **Enhancement Spots**：代码扩展位置
- **Classes / Interfaces**：面向对象编程支持

#### 2.4 集成与连接
| 技术 | 用途 |
|------|------|
| OData | Fiori 应用数据服务 |
| RFC | 远程函数调用 |
| IDoc | 电子数据交换 |
| Web Services | SOAP/REST 集成 |
| SAP Cloud Platform | 云扩展平台 |

### 3. 数据库层 (Database Layer)

#### 3.1 SAP HANA 内存数据库

##### 列式存储 (Column Store)
- **压缩算法**：字典压缩、游程编码、稀疏编码
- **优势**：高压缩比、快速聚合查询
- **适用场景**：分析查询、报表、数据挖掘

##### 行式存储 (Row Store)
- **特性**：保留传统数据库行结构
- **优势**：单行查询、事务处理
- **适用场景**：OLTP 事务、主数据访问

#### 3.2 HANA 高级特性

| 特性 | 描述 |
|------|------|
| **In-Memory Computing** | 数据常驻内存，避免磁盘 I/O |
| **Multi-Model Processing** | 支持 Graph、Spatial、Text、Series |
| **Calculation Views** | 复杂业务逻辑建模 |
| **SQL / SQLScript** | 标准查询语言和过程式扩展 |
| **Predictive Analysis Library (PAL)** | 预测分析算法库 |
| **Business Function Library (BFL)** | 业务函数库 |

#### 3.3 数据库架构组件
```
SAP HANA Database
│
├── Name Server（拓扑管理）
├── Index Server（核心处理引擎）
│   ├── SQL/MDX Processor
│   ├── Planning Engine
│   ├── Calc Engine
│   └── Row/Column Store
├── XS Engine（应用服务器）
├── Preprocessor（文本分析）
└── Statistics Server（监控统计）
```

## SAP Business Technology Platform (SAP BTP) 介绍

### 什么是 SAP BTP

**SAP Business Technology Platform (SAP BTP)** 是 SAP 的云平台产品，原名 SAP Cloud Platform (SCP)。它是一个开放的平台即服务 (PaaS)，为企业提供构建、扩展、集成和管理应用程序的能力。

### 核心定位

```
┌─────────────────────────────────────────────────────────────────┐
│                        企业数字化平台                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   ┌──────────────┐    ┌──────────────┐    ┌──────────────┐     │
│   │   SAP S/4HANA │    │   SAP BTP     │    │   第三方系统   │     │
│   │   (核心业务)  │◄──►│  (扩展与集成)  │◄──►│  (SaaS/On-Prem)│
│   └──────────────┘    └──────────────┘    └──────────────┘     │
│          │                    │                    │            │
│          └────────────────────┴────────────────────┘            │
│                             │                                  │
│                        统一业务体验                            │
└─────────────────────────────────────────────────────────────────┘
```

### ABAP Platform 深度解析

#### 1. 工作进程类型

```
ABAP Application Server
│
├── Dialog Work Process (DWP)
│   └── 处理用户交互、屏幕逻辑、事务处理
│
├── Background Work Process (BWP)
│   └── 后台作业处理、定期任务
│
├── Update Work Process (V1/V2)
│   ├── V1: 关键更新，同步执行
│   └── V2: 非关键更新，异步执行
│
├── Spool Work Process (SWP)
│   └── 打印请求、格式化输出
│
├── Enqueue Work Process (EWP)
│   └── 逻辑锁管理，保证数据一致性
│
└── Message Server (MS)
    └── 集群通信、负载分发、消息传递
```

| 工作进程类型 | 数量配置 | 主要用途 |
|-------------|---------|---------|
| **D (Dialog)** | ≥ 2 | 用户交互处理 |
| **B (Background)** | ≥ 1 | 批量作业 |
| **V1 (Update)** | ≥ 1 | 关键数据更新 |
| **V2 (Update)** | 可选 | 次要数据更新 |
| **S (Spool)** | ≥ 1 | 打印/输出 |
| **E (Enqueue)** | 1 (独占) | 锁管理 |

      EXPORTING
        VALUE(et_sales) TYPE ztt_sales_data.

                        LANGUAGE SQLSCRIPT
                        OPTIONS READ-ONLY

               FROM "ZSALES_ORDER"
