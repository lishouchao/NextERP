# AM 资产主数据

**模块**: Asset Master Data
**对标**: SAP ANLA
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

| 功能 | 说明 | 对标 |
|------|------|------|
| 创建资产 | 新建资产卡片 | AS01 |
| 修改资产 | 修改资产数据 | AS02 |
| 查看资产 | 查看资产详情 | AS03 |
| 冻结资产 | 冻结资产使用 | AS05 |

### 1.2 资产编号规则

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           资产编号规则                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   资产编号格式:                                                              │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   资产号 (asset_number): XXXXXXXXXX (10位)                           │   │
│   │   子号 (sub_number): XXXX (4位)                                      │   │
│   │   完整资产号: XXXXXXXXXX-XXXX (如 1000000001-0000)                   │   │
│   │                                                                       │   │
│   │   子号用途:                                                           │   │
│   │   - 0000: 主资产                                                      │   │
│   │   - 0001, 0002...: 子资产 (资产组件)                                  │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   编号分配:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 按资产分类分配号码范围                                            │   │
│   │   - 1000类: 1000000001 - 1099999999 (房屋建筑物)                     │   │
│   │   - 2000类: 2000000001 - 2099999999 (机器设备)                       │   │
│   │   - 3000类: 3000000001 - 3099999999 (运输工具)                       │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. 资产分类

### 2.1 分类字段 (am_asset_class)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| class_code | VARCHAR(8) | 是 | 分类代码 |
| class_name | VARCHAR(100) | 是 | 分类名称 |
| class_type | VARCHAR(2) | 否 | 分类类型 |
| account_determination | VARCHAR(4) | 否 | 科目确定 |
| default_useful_life | INTEGER | 否 | 默认使用年限 |
| default_depr_method | VARCHAR(2) | 否 | 默认折旧方法 |
| number_range | VARCHAR(4) | 否 | 号码范围 |
| parent_id | UUID | 否 | 父分类ID |

## 3. 资产主数据字段

### 3.1 基本信息

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| asset_number | VARCHAR(12) | 是 | 资产编号 | ANLN1 |
| sub_number | VARCHAR(4) | 是 | 子编号 | ANLN2 |
| description | VARCHAR(100) | 是 | 资产描述 | TXT50 |
| description_2 | VARCHAR(100) | 否 | 描述2 | TXT50 |
| asset_class_id | UUID | 是 | 资产分类 | ANLKL |

### 3.2 组织信息

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| company_id | UUID | 是 | 公司 | BUKRS |
| cost_center_id | UUID | 否 | 成本中心 | KOSTL |
| profit_center_id | UUID | 否 | 利润中心 | PRCTR |
| plant_id | UUID | 否 | 工厂 | WERKS |
| location | VARCHAR(30) | 否 | 资产位置 | RAUMN |
| responsible_person | UUID | 否 | 负责人 | VERAN |

### 3.3 日期信息

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| capitalization_date | DATE | 否 | 资本化日期 | AKTIV |
| acquisition_date | DATE | 否 | 购置日期 | AKTIV_DT |
| first_acquisition_date | DATE | 否 | 首次购置日期 | AKTIV_DT |
| deactivation_date | DATE | 否 | 停用日期 | DEAKT |

### 3.4 价值信息

| 字段 | 类型 | 说明 | 对标 |
|------|------|------|------|
| acquisition_value | DECIMAL(15,2) | 购置原值 | KANSW |
| revaluation_value | DECIMAL(15,2) | 重估价值 | - |
| gross_value | DECIMAL(15,2) | 总值 | - |
| accum_depreciation | DECIMAL(15,2) | 累计折旧 | - |
| net_book_value | DECIMAL(15,2) | 净值 | - |

### 3.5 折旧信息

| 字段 | 类型 | 说明 | 对标 |
|------|------|------|------|
| useful_life_years | INTEGER | 使用年限(年) | NDJAR |
| useful_life_periods | INTEGER | 使用年限(期间) | NDPER |
| salvage_value | DECIMAL(15,2) | 残值 | - |
| salvage_percent | DECIMAL(5,2) | 残值率% | - |
| depreciation_key | VARCHAR(4) | 折旧码 | AFASL |

## 4. 创建资产流程

### 4.1 创建流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           创建资产流程                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. 输入基本信息                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 选择资产分类                                                     │   │
│   │   - 输入资产描述                                                     │   │
│   │   - 自动生成资产编号                                                 │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   2. 输入组织信息                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 选择公司                                                         │   │
│   │   - 选择成本中心 (可选)                                              │   │
│   │   - 选择工厂/位置 (可选)                                             │   │
│   │   - 选择负责人 (可选)                                                │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   3. 配置折旧参数                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 系统自动根据分类填入默认值                                       │   │
│   │   - 可修改: 使用年限、残值率、折旧方法                               │   │
│   │   - 自动创建折旧范围记录                                             │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   4. 保存                                                                   │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 保存资产主数据                                                   │   │
│   │   - 创建折旧范围记录                                                 │   │
│   │   - 资产状态: 在建 (00)                                              │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 5. 接口设计

### 5.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/am/classes | GET | 资产分类列表 |
| /api/am/classes | POST | 创建分类 |
| /api/am/classes/{id} | GET | 分类详情 |
| /api/am/assets | GET | 资产列表 |
| /api/am/assets | POST | 创建资产 |
| /api/am/assets/{id} | GET | 资产详情 |
| /api/am/assets/{id} | PUT | 更新资产 |
| /api/am/assets/{id}/capitalize | POST | 资本化 |
| /api/am/assets/{id}/depreciation-areas | GET | 折旧范围 |
