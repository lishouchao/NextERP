## 2. 折旧方法

### 2.1 方法类型

| 方法 | 代码 | 公式 | 说明 |
|------|------|------|------|
| 直线法 | SL | (原值-残值)/年限/12 | 每月折旧相等 |
| 双倍余额递减 | DR | 2/年限/12 × 净值 | 前期折旧多 |
| 年数总和法 | SY | (原值-残值)×剩余年限/年数总和/12 | 递减 |
| 定率递减 | DI | 固定比率/12 × 净值 | 指定折旧率 |

### 2.2 折旧计算公式

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           折旧计算公式                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   直线法 (Straight-Line):                                                    │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   月折旧额 = (原值 - 残值) / (使用年限 × 12)                        │   │
│   │                                                                       │   │
│   │   示例:                                                               │   │
│   │   原值: 100,000元                                                     │   │
│   │   残值: 5,000元 (5%)                                                  │   │
│   │   年限: 10年                                                          │   │
│   │   月折旧 = (100,000 - 5,000) / 120 = 791.67元                        │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   双倍余额递减法 (Double Declining Balance):                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   月折旧额 = 净值 × (2 / 使用年限 / 12)                              │   │
│   │                                                                       │   │
│   │   示例:                                                               │   │
│   │   原值: 100,000元, 年限: 10年                                        │   │
│   │   第1年折旧 = 100,000 × 20% = 20,000元                               │   │
│   │   第2年折旧 = 80,000 × 20% = 16,000元                                │   │
│   │   ...直到净值接近残值                                                 │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   年数总和法 (Sum of Years Digits):                                          │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   月折旧额 = (原值 - 残值) × 剩余年限 / 年数总和 / 12                │   │
│   │   年数总和 = 1 + 2 + ... + n = n × (n + 1) / 2                      │   │
│   │                                                                       │   │
│   │   示例 (10年):                                                        │   │
│   │   年数总和 = 55                                                       │   │
│   │   第1年: (100,000 - 5,000) × 10/55 = 17,273元                       │   │
│   │   第2年: (100,000 - 5,000) × 9/55 = 15,545元                        │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 3. 折旧范围

### 3.1 折旧范围字段 (am_depreciation_area)

| 字段 | 类型 | 说明 |
|------|------|------|
| asset_id | UUID | 资产ID |
| depr_area | VARCHAR(2) | 折旧范围 |
| depr_method | VARCHAR(2) | 折旧方法 |
| useful_life_years | INTEGER | 使用年限 |
| acquisition_value | DECIMAL(15,2) | 购置价值 |
| accum_depreciation | DECIMAL(15,2) | 累计折旧 |
| depr_this_year | DECIMAL(15,2) | 本年折旧 |
| net_book_value | DECIMAL(15,2) | 账面净值 |
| salvage_value | DECIMAL(15,2) | 残值 |
| periods_depreciated | INTEGER | 已折旧期间 |

## 4. 折旧运行

### 4.1 运行流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           折旧运行流程                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. 启动折旧运行                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   输入参数:                                                          │   │
│   │   - 公司代码                                                         │   │
│   │   - 会计年度                                                         │   │
│   │   - 期间                                                             │   │
│   │   - 折旧范围 (可选，默认全部)                                        │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   2. 计算折旧                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   FOR each 资产 in 公司:                                             │   │
│   │       if 资产状态 = '在用' AND 未完全折旧:                          │   │
│   │           FOR each 折旧范围:                                         │   │
│   │               计算本期折旧 = 根据折旧方法计算                        │   │
│   │               创建折旧明细记录                                       │   │
│   │               更新资产累计折旧                                       │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   3. 生成FI凭证 (可选)                                                      │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   借: 折旧费用 (按成本中心)                                          │   │
│   │   贷: 累计折旧 (按资产分类)                                          │   │
│   │                                                                       │   │
│   │   或稍后通过AFBP单独过账                                             │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.2 运行状态

| 状态 | 代码 | 说明 | 操作 |
|------|------|------|------|
| 运行中 | 01 | 正在计算 | 等待 |
| 完成 | 02 | 计算完成 | 可过账 |
| 已过账 | 03 | 已过账FI | 完成 |
| 错误 | 04 | 运行错误 | 修复重跑 |

## 5. 接口设计

### 5.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
