### 2.1 外部购置 (100)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           外部购置业务                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   触发来源:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   1. 采购订单收货 (MM模块)                                           │   │
│   │      - 收货时自动创建资产                                            │   │
│   │      - 按采购订单金额确定原值                                        │   │
│   │                                                                       │   │
│   │   2. 发票校验 (MM/FI模块)                                            │   │
│   │      - 发票金额更新资产原值                                          │   │
│   │      - 处理差异                                                      │   │
│   │                                                                       │   │
│   │   3. 手工录入 (AM模块)                                               │   │
│   │      - 直接创建资产                                                  │   │
│   │      - 手工输入原值                                                  │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   会计分录:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐   │

│   │   贷: 应付账款 (2202)                                                │   │
│   │                                                                       │   │
│   │   如果是采购订单收货:                                                 │   │
│   │   借: 固定资产 (1601)                                                │   │
│   │   贷: GR/IR 清算科目 (1201)                                          │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 3. 资产转移

### 3.1 转移类型

| 转移类型 | 说明 | 影响 |
|----------|------|------|
| 成本中心转移 | 同公司内转移 | 折旧归属变更 |
| 公司间转移 | 跨公司转移 | 资产清出/清入 |
| 价值转移 | 部分价值转移 | 原值拆分 |

### 3.2 转移流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           资产转移流程                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   成本中心转移:                                                              │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   1. 选择要转移的资产                                                │   │
│   │   2. 指定目标成本中心                                                │   │
│   │   3. 执行转移                                                        │   │
│   │      - 更新资产主数据的成本中心                                      │   │
│   │      - 后续折旧归属新成本中心                                        │   │
│   │      - 不产生FI凭证                                                  │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   公司间转移:                                                                │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   1. 源公司清出资产                                                  │   │
│   │      - 净值转移到目标公司                                            │   │
│   │      - 累计折旧清零                                                  │   │
│   │                                                                       │   │
│   │   2. 目标公司清入资产                                                │   │
│   │      - 按净值作为新资产原值                                          │   │
│   │      - 重新计算折旧                                                  │   │
│   │                                                                       │   │
│   │   3. 公司间往来记账                                                  │   │
│   │      借: 固定资产 (目标公司)                                         │   │
│   │      贷: 公司间往来                                                  │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
