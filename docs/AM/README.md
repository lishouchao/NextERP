# AM 资产管理模块

**对标**: SAP ECC AA / S/4HANA Asset Accounting
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 模块概述

AM (Asset Management) 模块负责企业固定资产的全生命周期管理，从资产购置、折旧计算到资产报废，提供完整的资产管理能力。

### 核心能力

| 能力 | 说明 | 对标 |
|------|------|------|
| 资产主数据 | 资产卡片管理 | AS01/AS02/AS03 |
| 资产业务 | 购置、转移、报废 | AB01/AB08/ABAVN |
| 折旧计算 | 自动折旧与过账 | AFAB/AFBP |
| 资产分类 | 资产类别管理 | OAOA |
| 资产浏览 | 资产报表查询 | AW01N |

## 折旧方法

| 方法 | 代码 | 公式 | 说明 |
|------|------|------|------|
| 直线法 | SL | (原值-残值)/年限 | 每年折旧相等 |
| 双倍余额递减 | DR | 2/年限 × 净值 | 前期折旧多 |
| 年数总和法 | SY | (原值-残值)×剩余年限/年数总和 | 递减 |
| 定率递减 | DI | 固定比率 × 净值 | 指定折旧率 |
