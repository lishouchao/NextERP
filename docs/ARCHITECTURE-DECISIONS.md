## 1. CRM/SCM/SRM 模块独立性决策

### 1.1 背景

学术界和工业界普遍认为CRM（客户关系管理）、SCM（供应链管理）、SRM（供应商关系管理）是独立于核心ERP之外的专业系统。本决策记录分析这一观点及其对NextERP架构的影响。

### 1.2 业界分析

#### 1.2.1 为什么认为应该独立？

| 维度 | ERP (核心) | CRM/SCM/SRM (扩展) |
|------|------------|-------------------|
| **业务焦点** | 内部运营效率 | 外部协作与关系 |
| **用户群体** | 内部员工 | 内部+外部伙伴 |
| **数据特性** | 交易数据（结构化） | 交互数据、预测数据 |
| **技术需求** | 稳定、可靠、一致性 | 实时、移动、社交集成 |
| **更新频率** | 相对稳定 | 快速迭代 |
| **扩展需求** | 线性增长 | 海量数据（如客户行为） |

### 1.3 独立性分析

#### 1.3.1 CRM 独立性分析

| 方面 | 独立的必要性 | 说明 |
|------|-------------|------|
| **数据规模** | 高 | 客户交互数据、行为数据量大 |
| **实时性** | 高 | 销售活动需要实时更新 |
| **外部集成** | 高 | 社交媒体、邮件、呼叫中心 |
| **移动端** | 高 | 销售人员移动办公需求 |
| **AI/分析** | 高 | 客户预测、线索评分 |

#### 1.3.2 SCM 独立性分析

| 方面 | 独立的必要性 | 说明 |
|------|-------------|------|
| **外部协作** | 高 | 与供应商、物流商协作 |
| **预测分析** | 高 | 需求预测、库存优化 |
| **实时可见** | 高 | 供应链可视化 |
| **多企业协同** | 高 | 跨企业数据共享 |

#### 1.3.3 SRM 独立性分析

| 方面 | 独立的必要性 | 说明 |
|------|-------------|------|
| **供应商门户** | 高 | 外部供应商访问 |
| **协同流程** | 高 | RFQ、合同、绩效协同 |
| **采购目录** | 高 | 外部目录集成 |

### 1.7 决策结论

| 决策项 | 结论 |
|--------|------|
| **Schema隔离** | CRM/SCM/SRM使用独立Schema (crm_*, scm_*, srm_*) |
| **API边界** | 每个模块有独立的API前缀 (/api/v1/crm/*, /api/v1/scm/*) |
| **部署策略** | 支持一体化和微服务两种部署模式 |
| **数据同步** | 通过共享主数据服务(MDM)和事件总线实现 |
| **默认部署** | 一体化部署（中小企业友好） |
| **升级路径** | 支持从一体化迁移到微服务部署 |
