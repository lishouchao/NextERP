## 2. 主数据字段

### 2.1 基本信息 (bp_business_partner)

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| bp_number | VARCHAR(10) | 是 | 业务伙伴编号 | PARTNER |
| bp_type | VARCHAR(4) | 是 | BP类型 (P/O/G) | TYPE |
| name | VARCHAR(80) | 是 | 名称/全称 | NAME1 |
| name_2 | VARCHAR(80) | 否 | 名称2 | NAME2 |
| short_name | VARCHAR(40) | 否 | 简称 | NAME_LAST |
| name_en | VARCHAR(80) | 否 | 英文名 | NAME_FIRST2 |

### 2.2 个人信息 (bp_type = 'P')

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| first_name | VARCHAR(40) | 是 | 名 | NAME_FIRST |
| last_name | VARCHAR(40) | 是 | 姓 | NAME_LAST |
| title | VARCHAR(4) | 否 | 称谓 | TITLE |
| gender | ENUM | 否 | 性别 | SEX |
| birth_date | DATE | 否 | 出生日期 | BIRTH_DATE |

### 2.3 组织信息 (bp_type = 'O')

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| legal_entity_type | VARCHAR(4) | 否 | 法律形式 | LEGAL_ENTY |
| incorporation_country | VARCHAR(3) | 否 | 注册国家 | FOUND_DAT |
| tax_number | VARCHAR(18) | 否 | 税号 | TAX_NUM |
| tax_number_2 | VARCHAR(18) | 否 | 税号2 | TAX_NUM2 |

### 2.4 搜索与分类

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| search_term_1 | VARCHAR(20) | 否 | 搜索词1 | SORT1 |
| search_term_2 | VARCHAR(20) | 否 | 搜索词2 | SORT2 |
| industry | VARCHAR(4) | 否 | 行业 | IND_SECTOR |
| bp_category | VARCHAR(10) | 否 | BP分类 | CATEGORY |

### 2.5 信用控制

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| credit_limit | DECIMAL(15,2) | 否 | 信用额度 | CREDIT_LIM |
| credit_status | VARCHAR(2) | 否 | 信用状态 | CREDIT_STA |

### 2.6 状态

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| bp_status | VARCHAR(2) | 是 | BP状态 | CENTRAL |
| status | ENUM | 是 | 通用状态 | - |

## 3. 业务伙伴角色

### 3.1 角色表 (bp_role)

| 字段 | 类型 | 说明 |
|------|------|------|
| bp_id | UUID | 业务伙伴ID |
| role_type | VARCHAR(6) | 角色类型 |
| is_primary | BOOLEAN | 主要角色 |
| valid_from | DATE | 有效起始 |
| valid_to | DATE | 有效结束 |
| role_status | ENUM | 角色状态 |

### 3.2 角色分配规则

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           角色分配规则                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   自动分配 (创建BP时):                                                       │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   if bp_type = 'P':                                                 │   │
│   │       自动分配角色: ZPERSON                                          │   │
│   │   elif bp_type = 'O':                                               │   │
│   │       自动分配角色: ZORGANIZATION                                    │   │
│   │   elif bp_type = 'G':                                               │   │
│   │       自动分配角色: ZORGANIZATION                                    │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   手动添加角色:                                                              │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 添加客户角色 (ZCUSTOMER) → 需要填写bp_customer数据              │   │
│   │   - 添加供应商角色 (ZVENDOR) → 需要填写bp_vendor数据                │   │
│   │   - 添加工厂角色 (ZPLANT) → 需要关联sys_plant                       │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   角色约束:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 同一BP不能重复添加相同角色                                        │   │
│   │   - 一个BP可以有多个角色                                              │   │
│   │   - 主要角色只能有一个                                                │   │
│   │   - 角色可以设置有效期                                                │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 4. 创建流程

### 4.1 创建业务伙伴

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           创建业务伙伴流程                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. 输入基本信息                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   选择BP类型 (P/O/G)                                                 │   │
│   │   输入名称 (根据类型自动生成name)                                    │   │
│   │   输入搜索词                                                         │   │
│   │   选择行业/分类                                                      │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   2. 输入详细信息                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   个人: first_name, last_name, gender, birth_date                   │   │
│   │   组织: legal_entity_type, tax_number                               │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   3. 重复检查                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   检查税号是否重复                                                   │   │
│   │   检查名称相似度                                                     │   │
│   │   发现重复 → 提示确认或继续                                          │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   4. 保存                                                                   │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   生成bp_number                                                      │   │
│   │   创建bp记录                                                         │   │
│   │   自动分配默认角色                                                   │   │
│   │   创建默认地址记录                                                   │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 5. 状态管理

### 5.1 BP状态

| 状态 | 代码 | 说明 | 允许操作 |
|------|------|------|----------|
| 激活 | 01 | 正常使用 | 全部操作 |
| 冻结 | 02 | 暂停使用 | 仅查看 |
| 删除标记 | 03 | 待删除 | 仅查看 |

### 5.2 状态变更规则

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           状态变更规则                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   激活 → 冻结:                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   条件: 无未清业务 (无未清订单、无未清发票)                          │   │
│   │   效果: 不能创建新的业务单据                                         │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   冻结 → 激活:                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   条件: 无限制                                                       │   │
│   │   效果: 恢复正常业务                                                 │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   激活/冻结 → 删除标记:                                                       │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   条件: 无任何业务记录                                               │   │
│   │   效果: 标记删除，存档后物理删除                                     │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 6. 接口设计

### 6.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/bp/partners | GET | 业务伙伴列表 |
| /api/bp/partners | POST | 创建业务伙伴 |
| /api/bp/partners/{id} | GET | 业务伙伴详情 |
| /api/bp/partners/{id} | PUT | 更新业务伙伴 |
| /api/bp/partners/{id}/roles | GET | 业务伙伴角色列表 |
| /api/bp/partners/{id}/roles | POST | 添加角色 |
| /api/bp/partners/search | POST | 搜索业务伙伴 |
| /api/bp/partners/duplicate-check | POST | 重复检查 |

### 6.2 搜索参数

| 参数 | 类型 | 说明 |
|------|------|------|
| keyword | String | 关键词 (名称/搜索词) |
| bp_type | String | BP类型 |
| role_type | String | 角色类型 |
| tax_number | String | 税号 |
| status | String | 状态 |
