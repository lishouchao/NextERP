# BP 客户角色

**模块**: Customer Role
**对标**: SAP KNB1/KNVV
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

客户角色是为业务伙伴添加销售业务能力的角色类型。添加客户角色后，该BP可以：

- 创建销售订单
- 开具销售发票
- 处理销售退货
- 参与信用管理

## 2. 公司代码数据 (bp_customer)

### 2.1 字段定义

对标 SAP KNB1

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| bp_id | UUID | 是 | 业务伙伴ID | - |
| company_id | UUID | 是 | 公司ID | BUKRS |
| customer_code | VARCHAR(10) | 是 | 客户编码 | KUNNR |
| recon_account | VARCHAR(10) | 是 | 统驭科目 | AKONT |
| payment_term | VARCHAR(4) | 否 | 付款条款 | ZTERM |
| payment_method | VARCHAR(2) | 否 | 付款方式 | ZWELS |
| currency_id | UUID | 否 | 货币 | WAERS |
| is_foreign | BOOLEAN | 否 | 外币客户 | XAUSZ |
| credit_limit | DECIMAL(15,2) | 否 | 信用额度 | KLIMK |
| credit_group | VARCHAR(4) | 否 | 信用组 | CTLPC |
| tax_type | VARCHAR(2) | 否 | 税类型 | FITYP |
| tax_number | VARCHAR(18) | 否 | 税号 | STCEG |
| sort_key | VARCHAR(3) | 否 | 排序码 | ZUONR |
| account_group | VARCHAR(4) | 否 | 账户组 | KTOKD |
| is_reconciliation | BOOLEAN | 否 | 清算科目 | XRESI |
| is_one_time | BOOLEAN | 否 | 一次性客户 | XPERR |

### 2.2 统驭科目

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           统驭科目配置                                       │

│                                                                             │
│   统驭科目 (recon_account):                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   应收账款科目，用于FI模块统驭客户明细                               │   │

│   │   常用科目:                                                           │   │
│   │   1122 - 应收账款                                                     │   │
│   │   1123 - 其他应收款                                                   │   │
│   │   1124 - 预收账款                                                     │   │
│   │                                                                       │   │
│   │   作用:                                                               │   │
│   │   - 客户发票 → 借: 应收账款 (统驭)                                   │   │
│   │   - 客户收款 → 贷: 应收账款 (统驭)                                   │   │
│   │   - 余额 = 该客户所有未清发票                                         │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.3 付款条款

| 付款条款 | 说明 | 计算 |
|----------|------|------|
| 0001 | 立即付款 | 净到期日 = 凭证日 |
| 0010 | 10天付款 | 净到期日 = 凭证日 + 10 |
| 0030 | 30天付款 | 净到期日 = 凭证日 + 30 |
| 2/10 | 10天内2%折扣 | 折扣日 + 10，净30天 |

### 3.3 国际贸易条件 (Incoterms)

| 代码 | 说明 | 费用承担 |
|------|------|----------|
| EXW | 工厂交货 | 买方承担所有 |
| FOB | 装运港船上交货 | 买方承担海运 |
| CIF | 成本加保险费加运费 | 卖方承担到港 |
| DDP | 完税后交货 | 卖方承担全部 |
| DAP | 目的地交货 | 卖方承担到点 |

## 4. 信用管理

### 4.1 信用控制

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           信用控制流程                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   信用额度层级:                                                              │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   1. BP级别 (bp_business_partner.credit_limit)                      │   │
│   │      └─ 总信用额度                                                   │   │
│   │                                                                       │   │
│   │   2. 公司级别 (bp_customer.credit_limit)                             │   │
│   │      └─ 每个公司的信用额度                                           │   │
│   │                                                                       │   │
│   │   3. 信用组 (bp_customer.credit_group)                               │   │
│   │      └─ 分组控制策略                                                 │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   信用占用计算:                                                              │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   信用占用 = 应收余额 + 未清订单 + 未清发货                          │   │
│   │                                                                       │   │
│   │   if 信用占用 > 信用额度:                                             │   │
│   │       触发信用冻结                                                    │   │
│   │       销售订单需要审批                                                │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 5. 接口设计

### 5.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/bp/customers | GET | 客户列表 |
