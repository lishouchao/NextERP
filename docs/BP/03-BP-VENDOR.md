# BP 供应商角色

**模块**: Vendor Role
**对标**: SAP LFB1/LFM1
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

供应商角色是为业务伙伴添加采购业务能力的角色类型。添加供应商角色后，该BP可以：

- 创建采购订单
- 处理收货入库
- 供应商发票校验
- 供应商付款

## 2. 公司代码数据 (bp_vendor)

### 2.1 字段定义

对标 SAP LFB1

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| bp_id | UUID | 是 | 业务伙伴ID | - |
| company_id | UUID | 是 | 公司ID | BUKRS |
| vendor_code | VARCHAR(10) | 是 | 供应商编码 | LIFNR |
| recon_account | VARCHAR(10) | 是 | 统驭科目 | AKONT |
| payment_term | VARCHAR(4) | 否 | 付款条款 | ZTERM |
| payment_method | VARCHAR(2) | 否 | 付款方式 | ZWELS |
| payment_block | VARCHAR(2) | 否 | 付款冻结 | ZAHLS |
| currency_id | UUID | 否 | 货币 | WAERS |
| is_foreign | BOOLEAN | 否 | 外币供应商 | XAUSZ |
| purchasing_group | VARCHAR(3) | 否 | 采购组 | EKGRP |
| tax_type | VARCHAR(2) | 否 | 税类型 | FITYP |
| tax_number | VARCHAR(18) | 否 | 税号 | STCEG |
| sort_key | VARCHAR(3) | 否 | 排序码 | ZUONR |
| account_group | VARCHAR(4) | 否 | 账户组 | KTOKK |

### 2.2 统驭科目

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           供应商统驭科目                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   统驭科目 (recon_account):                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   应付账款科目，用于FI模块统驭供应商明细                             │   │
│   │                                                                       │   │
│   │   常用科目:                                                           │   │
│   │   2202 - 应付账款                                                     │   │
│   │   2203 - 其他应付款                                                   │   │
│   │   2204 - 预付账款                                                     │   │
│   │                                                                       │   │
│   │   作用:                                                               │   │
│   │   - 供应商发票 → 贷: 应付账款 (统驭)                                 │   │
│   │   - 供应商付款 → 借: 应付账款 (统驭)                                 │   │
│   │   - 余额 = 该供应商所有未清发票 (贷方余额)                           │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.3 付款冻结

| 代码 | 说明 | 效果 |
|------|------|------|
| A | 冻结所有付款 | 不允许付款 |
| P | 冻结支付 | 不允许付款 |
| 空 | 无冻结 | 正常付款 |

## 3. 采购组织数据 (bp_vendor_purchasing)

### 3.1 字段定义

对标 SAP LFM1

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| bp_id | UUID | 是 | 业务伙伴ID | - |
| purchasing_org_id | UUID | 是 | 采购组织ID | EKORG |

| planned_delivery_time | INTEGER | 否 | 计划交货时间(天) | PLIFZ |
| gr_processing_time | INTEGER | 否 | 收货处理时间(天) | WEBAZ |
| quality_score | DECIMAL(3,1) | 否 | 质量评分 | - |
| delivery_score | DECIMAL(3,1) | 否 | 交货评分 | - |
| is_blocked | BOOLEAN | 否 | 采购冻结 | SPERM |
| valid_from | DATE | 是 | 有效起始 | - |
| valid_to | DATE | 是 | 有效结束 | - |

## 4. 供应商评估

### 4.1 评估维度

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           供应商评估体系                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   评估维度:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   1. 质量评分 (quality_score)                                        │   │
│   │      ┌─────────────────────────────────────────────────────────────┐│   │
│   │      │   计算方式: (合格批次 / 总批次) × 100                        ││   │
│   │      │   数据来源: QM模块检验结果                                   ││   │
│   │      │   更新频率: 每月                                              ││   │
│   │      └─────────────────────────────────────────────────────────────┘│   │
│   │                                                                       │   │
│   │   2. 交货评分 (delivery_score)                                        │   │
│   │      ┌─────────────────────────────────────────────────────────────┐│   │
│   │      │   计算方式: (按时交货批次 / 总批次) × 100                    ││   │
│   │      │   数据来源: MM模块收货记录                                   ││   │
│   │      │   更新频率: 每月                                              ││   │
│   │      └─────────────────────────────────────────────────────────────┘│   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   评估等级:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   A级 (90-100分): 战略供应商，优先合作                               │   │
│   │   B级 (80-89分):  合格供应商，正常合作                               │   │
│   │   C级 (70-79分):  观察期供应商，限制采购                             │   │
│   │   D级 (<70分):    不合格供应商，淘汰                                 │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 5. 接口设计

### 5.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/bp/vendors | GET | 供应商列表 |
| /api/bp/partners/{id}/vendor | POST | 添加供应商角色 |
| /api/bp/vendors/{id} | GET | 供应商详情 |
| /api/bp/vendors/{id} | PUT | 更新供应商数据 |
| /api/bp/vendors/{id}/purchasing-orgs | GET | 采购组织列表 |
| /api/bp/vendors/{id}/purchasing-orgs | POST | 添加采购组织数据 |
| /api/bp/vendors/{id}/evaluation | GET | 供应商评估 |
