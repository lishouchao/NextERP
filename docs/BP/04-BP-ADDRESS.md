# BP 地址管理

**模块**: Address Management
**对标**: SAP BUT020/ADRC
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

地址管理为业务伙伴提供多地址、多用途的灵活管理能力：

- 支持一个BP多个地址
- 地址按用途分类
- 支持有效期管理
- 支持完整地址信息

## 2. 地址类型

### 2.1 类型定义

| 类型 | 代码 | 说明 | 使用场景 |
|------|------|------|----------|
| 默认地址 | 01 | 主地址 | 基本信息、默认通信 |
| 开票地址 | 02 | 发票寄送 | 财务开票 |
| 送货地址 | 03 | 客户收货 | 销售发货 (客户用) |
| 收货地址 | 04 | 供应商发货 | 采购收货 (供应商用) |
| 其他 | 05 | 备用地址 | 特殊场景 |

## 3. 地址字段

### 3.1 字段定义

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| bp_id | UUID | 是 | 业务伙伴ID | - |

| is_default | BOOLEAN | 否 | 默认地址 | - |
| country_id | UUID | 否 | 国家 | COUNTRY |
| region_id | UUID | 否 | 省/州 | REGION |
| city_id | UUID | 否 | 城市 | CITY1 |
| street | VARCHAR(60) | 否 | 街道 | STREET |
| street_2 | VARCHAR(60) | 否 | 街道2 | STREET2 |
| street_3 | VARCHAR(60) | 否 | 街道3 | STREET3 |
| street_4 | VARCHAR(60) | 否 | 街道4 | STREET4 |
| house_number | VARCHAR(10) | 否 | 门牌号 | HOUSE_NUM1 |
| building | VARCHAR(20) | 否 | 楼宇 | BUILDING |
| floor | VARCHAR(10) | 否 | 楼层 | FLOOR |
| room | VARCHAR(10) | 否 | 房间 | ROOMNUMBER |
| postal_code | VARCHAR(10) | 否 | 邮编 | POST_CODE1 |
| po_box | VARCHAR(10) | 否 | 邮政信箱 | PO_BOX |
| city | VARCHAR(40) | 否 | 城市名 | CITY1 |
| district | VARCHAR(40) | 否 | 区/县 | CITY2 |
| phone | VARCHAR(50) | 否 | 电话1 | TEL1_NUM1 |
| phone_2 | VARCHAR(50) | 否 | 电话2 | TEL1_NUM2 |
| fax | VARCHAR(50) | 否 | 传真 | FAX_NUMBER |

## 4. 有效期管理

### 4.1 有效期规则

| 场景 | valid_from | valid_to | 说明 |
|------|------------|----------|------|
| 当前有效 | 当前日期 | 9999-12-31 | 永久有效 |
| 临时地址 | 开始日期 | 结束日期 | 项目/临时使用 |
| 未来生效 | 未来日期 | 9999-12-31 | 提前录入 |

### 4.2 有效期检查

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           有效期检查逻辑                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   查询有效地址:                                                              │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   SELECT * FROM bp_address                                           │   │
│   │   WHERE bp_id = :bp_id                                               │   │
│   │     AND address_type = :address_type                                 │   │
│   │     AND valid_from <= CURRENT_DATE                                   │   │
│   │     AND valid_to >= CURRENT_DATE                                     │   │
│   │   ORDER BY is_default DESC                                           │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   地址切换:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   当新地址生效时:                                                    │   │
│   │   1. 旧地址的 valid_to = 新地址的 valid_from - 1天                  │   │
│   │   2. 或保留旧地址用于历史记录                                        │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 5. 接口设计

### 5.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/bp/partners/{id}/addresses | GET | 地址列表 |
| /api/bp/partners/{id}/addresses | POST | 添加地址 |
| /api/bp/addresses/{id} | GET | 地址详情 |
| /api/bp/addresses/{id} | PUT | 更新地址 |
| /api/bp/addresses/{id} | DELETE | 删除地址 |
| /api/bp/addresses/{id}/set-default | POST | 设为默认 |
