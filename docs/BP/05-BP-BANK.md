# BP 银行账户

**模块**: Bank Account Management
**对标**: SAP BUT0BK
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

银行账户管理为业务伙伴提供多银行账户管理能力：

- 支持一个BP多个银行账户
- 支持主账户标识
- 支持账户用途分类
- 支持有效期管理

## 2. 银行信息

### 2.1 字段定义

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| bank_country | VARCHAR(3) | 是 | 银行国家 | BANKS |
| bank_key | VARCHAR(15) | 是 | 银行代码 | BANKL |
| bank_name | VARCHAR(100) | 否 | 银行名称 | BANKA |
| bank_branch | VARCHAR(100) | 否 | 分行名称 | BRNCH |
| swift_code | VARCHAR(11) | 否 | SWIFT代码 | SWIFT |

### 2.2 银行代码

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           银行代码规则                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   中国:                                                                      │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   bank_key = 联行号 (12位)                                           │   │
│   │   例如:                                                             │   │
│   │   102100099996 - 中国工商银行北京分行                               │   │
│   │   104100000004 - 中国农业银行北京分行                               │   │
│   │   103100000026 - 中国银行北京分行                                   │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   国际:                                                                      │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   bank_key = 银行代码 (各国规则不同)                                 │   │
│   │   swift_code = SWIFT/BIC代码 (8或11位)                               │   │
```

## 3. 账户信息

### 3.1 字段定义

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| bp_id | UUID | 是 | 业务伙伴ID | - |
| account_number | VARCHAR(30) | 是 | 账号 | BANKN |
| account_holder | VARCHAR(100) | 否 | 户名 | KOINH |
| account_type | VARCHAR(2) | 否 | 账户类型 | BKEXT |
| iban | VARCHAR(34) | 否 | IBAN | IBAN |

### 3.2 账户类型

| 类型 | 代码 | 说明 | 特点 |
|------|------|------|------|
| 储蓄账户 | 01 | 储蓄账户 | 个人常用 |
| 支票账户 | 02 | 支票账户 | 企业常用 |
| 其他 | 03 | 其他账户 | 特殊用途 |

## 4. 控制信息

### 4.1 主账户标识

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           主账户规则                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   is_primary = TRUE:                                                        │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 每个BP只能有一个主账户                                           │   │
│   │   - 设置新主账户时，自动取消旧主账户                                 │   │
│   │   - 付款时默认使用主账户                                             │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   用途:                                                                      │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 应收账款: 收款账户                                               │   │
│   │   - 应付账款: 付款账户                                               │   │
│   │   - 银行对账: 对账账户                                               │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.2 用途类型

| 类型 | 代码 | 说明 | 使用场景 |
|------|------|------|----------|
| 全部 | 01 | 全部用途 | 默认 |
| 收款 | 02 | 仅收款 | 客户 |
| 付款 | 03 | 仅付款 | 供应商 |

### 4.3 有效期

| 场景 | valid_from | valid_to | 说明 |
|------|------------|----------|------|
| 当前有效 | 当前日期 | 9999-12-31 | 永久有效 |
| 临时账户 | 开始日期 | 结束日期 | 项目账户 |
| 已销户 | 开始日期 | 销户日期 | 历史记录 |

## 5. IBAN

### 5.1 IBAN格式

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           IBAN格式说明                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   IBAN结构:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   国家代码 (2位) + 校验码 (2位) + 银行账号 (最多30位)               │   │
│   │                                                                       │   │
│   │   例如:                                                               │   │
│   │   GB82 WEST 1234 5698 7654 32                                        │   │
│   │   ↑↑   ↑↑↑↑                                           │   │
│   │   GB  WEST = 英国银行代码                                           │   │
│   │   82  校验码                                                        │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   常见国家IBAN长度:                                                          │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   德国 (DE): 22位                                                    │   │
│   │   法国 (FR): 27位                                                    │   │
│   │   英国 (GB): 22位                                                    │   │
│   │   西班牙 (ES): 24位                                                  │   │
│   │   意大利 (IT): 27位                                                  │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 6. 接口设计

### 6.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/bp/partners/{id}/bank-accounts | GET | 银行账户列表 |
| /api/bp/partners/{id}/bank-accounts | POST | 添加银行账户 |
| /api/bp/bank-accounts/{id} | GET | 账户详情 |
| /api/bp/bank-accounts/{id} | PUT | 更新账户 |
| /api/bp/bank-accounts/{id} | DELETE | 删除账户 |
| /api/bp/bank-accounts/{id}/set-primary | POST | 设为主账户 |
