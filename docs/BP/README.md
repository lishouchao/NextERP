# BP 业务伙伴模块

**对标**: SAP S/4HANA BP (CVI - Customer Vendor Integration)
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 模块概述

BP (Business Partner) 模块采用 SAP S/4HANA 的统一业务伙伴模型，将客户 (Customer) 和供应商 (Vendor) 合并为一个业务伙伴对象，实现主数据的统一管理。

### 核心能力

| 能力 | 说明 | 对标 |
|------|------|------|
| 统一主数据 | 一个业务伙伴可同时是客户和供应商 | SAP BP |
| 角色管理 | 通过角色控制不同业务场景属性 | BP Role |
| 地址管理 | 支持多地址、多用途 | Address Management |
| 银行账户 | 多银行账户管理 | Bank Chain |

## 业务伙伴类型

| 类型 | 代码 | 说明 | 特点 |
|------|------|------|------|
| 个人 | P | 自然人 | 个人信息、身份证 |
| 组织 | O | 法人实体 | 公司信息、营业执照 |
| 集团 | G | 集团公司 | 关联公司管理 |
