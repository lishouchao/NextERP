## 4. 成本对象

### 4.1 成本中心

成本中心是企业内部归集成本的最小组织单元。

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           成本中心层次                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   公司 → 利润中心 → 成本中心                                                │
│                                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   1000 公司                                                          │   │
│   │   ├── PC01 利润中心 (华东)                                          │   │
│   │   │   ├── CC001 采购部门                                            │   │
│   │   │   ├── CC002 销售部门                                            │   │
│   │   │   └── CC003 管理部门                                            │   │
│   │   └── PC02 利润中心 (华北)                                          │   │
│   │       ├── CC004 采购部门                                            │   │
│   │       └── CC005 销售部门                                            │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.2 内部订单

内部订单用于归集特定项目或活动的成本。

| 类型 | 代码 | 说明 | 用途 |
|------|------|------|------|
| 间接费用订单 | IO01 | 间接费用 | 费用归集 |
| 投资订单 | IO02 | 资本支出 | 资产建设 |
| 维修订单 | IO03 | 设备维修 | 维修费用 |
| 研发订单 | IO04 | 研发项目 | 研发费用 |

### 4.3 利润中心

利润中心是内部独立核算利润的组织单元。
