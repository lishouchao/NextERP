# CO 成本要素

**模块**: Cost Element
**对标**: SAP KA01/KA02
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

| 功能 | 说明 | 对标 |
|------|------|------|
| 初级成本要素 | FI科目对应 | KA01 |
| 次级成本要素 | CO内部分配 | KA06 |
| 成本要素组 | 分组管理 | KAH1 |

### 1.2 成本要素分类

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           成本要素分类                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   初级成本要素 (对应FI科目):                                                │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   400000 - 直接材料    → 6401 (原材料费用)                          │   │
│   │   400001 - 直接人工    → 6402 (人工费用)                            │   │
│   │   400002 - 制造费用    → 6403 (制造费用)                            │   │
│   │   400003 - 折旧费用    → 6404 (折旧费用)                            │   │
│   │   500000 - 销售收入    → 6001 (销售收入)                            │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   次级成本要素 (CO内部):                                                    │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   600001 - 分摊要素     (用于成本分摊)                              │   │
│   │   600002 - 作业分配     (用于作业分配)                              │   │
│   │   600003 - 结算要素     (用于订单结算)                              │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. 初级成本要素

### 2.1 字段 (co_cost_element)

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| cost_element | VARCHAR(10) | 是 | 成本要素代码 | KSTAR |
| name | VARCHAR(100) | 是 | 名称 | KTEXT |
| description | TEXT | 否 | 描述 | LTEXT |
| element_type | VARCHAR(1) | 是 | 类型 | KATYP |
| element_category | VARCHAR(2) | 否 | 类别 | - |
| gl_account_id | UUID | 否 | 科目ID | - |
| gl_account_code | VARCHAR(10) | 否 | 科目代码 | KONTO |
| controlling_area | VARCHAR(4) | 否 | 控制范围 | KOKRS |
| valid_from | DATE | 是 | 有效起始 | DATAB |
| valid_to | DATE | 是 | 有效结束 | DATBI |
| status | VARCHAR(2) | 是 | 状态 | - |

### 2.2 成本要素类型

| 类型 | 代码 | 说明 | 用途 |
|------|------|------|------|
| 成本 | 1 | 成本要素 | 成本归集 |
| 收入 | 2 | 收入要素 | 收入归集 |
| 销售扣除 | 3 | 销售扣除 | 折扣处理 |
| 成本抵减 | 4 | 成本抵减 | 成本调整 |

### 2.3 常用初级成本要素

| 成本要素 | 名称 | 类型 | 科目 |
|----------|------|------|------|
| 400000 | 直接材料 | 1 | 6401 |
| 400001 | 直接人工 | 1 | 6402 |
| 400002 | 制造费用 | 1 | 6403 |
| 400003 | 折旧费用 | 1 | 6404 |
| 400004 | 租赁费用 | 1 | 6405 |
| 400005 | 水电费用 | 1 | 6406 |
| 400006 | 差旅费用 | 1 | 6407 |
| 500000 | 销售收入 | 2 | 6001 |
| 500001 | 其他收入 | 2 | 6002 |

### 2.4 创建初级成本要素

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           创建初级成本要素                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   前提条件:                                                                 │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - FI科目已创建                                                    │   │
│   │   - 科目类型为成本/收入类                                           │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   创建步骤:                                                                 │

│   │   1. 输入成本要素代码                                               │   │

│   │   3. 选择成本要素类型                                               │   │
│   │   4. 关联FI科目                                                     │   │

│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 3. 次级成本要素

### 3.1 字段 (co_cost_element_sec)

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| cost_element | VARCHAR(10) | 是 | 成本要素代码 | KSTAR |
| name | VARCHAR(100) | 是 | 名称 | KTEXT |
| element_category | VARCHAR(2) | 是 | 成本要素类别 | KATYP |
| controlling_area | VARCHAR(4) | 否 | 控制范围 | KOKRS |
| allocation_type | VARCHAR(2) | 否 | 分配类型 | - |
| valid_from | DATE | 是 | 有效起始 | DATAB |
| valid_to | DATE | 是 | 有效结束 | DATBI |
| status | VARCHAR(2) | 是 | 状态 | - |

### 3.2 次级成本要素类别

| 作业分配 | 22 | 作业要素 | 作业分配 |
| 结算 | 23 | 结算要素 | 订单结算 |
| 订单结算 | 42 | 订单结算 | 内部订单 |
| 项目结算 | 43 | 项目结算 | 项目结算 |

### 3.3 常用次级成本要素

| 成本要素 | 名称 | 类别 | 用途 |
|----------|------|------|------|

| 600002 | 人工分配 | 22 | 人工成本分配 |
| 600003 | 机器分配 | 22 | 机器成本分配 |
| 600004 | 订单结算 | 42 | 内部订单结算 |
| 600005 | 项目结算 | 43 | 项目结算 |

## 5. 接口设计

### 5.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/co/elements | GET | 成本要素列表 |
| /api/co/elements | POST | 创建成本要素 |
| /api/co/elements/{id} | GET | 成本要素详情 |
| /api/co/elements/{id} | PUT | 更新成本要素 |
| /api/co/elements/primary | GET | 初级成本要素列表 |
| /api/co/elements/secondary | GET | 次级成本要素列表 |
| /api/co/element-groups | GET | 成本要素组列表 |
| /api/co/element-groups | POST | 创建成本要素组 |
