## 2. 成本中心

### 2.1 成本中心字段 (sys_cost_center)

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| cost_center_code | VARCHAR(10) | 是 | 成本中心代码 | KOSTL |
| cost_center_name | VARCHAR(100) | 是 | 成本中心名称 | KTEXT |
| company_id | UUID | 是 | 公司 | BUKRS |
| parent_id | UUID | 否 | 父成本中心 | - |
| profit_center_id | UUID | 否 | 利润中心 | PRCTR |
| manager_id | UUID | 否 | 负责人 | VERAK |
| valid_from | DATE | 是 | 有效起始 | DATAB |
| valid_to | DATE | 是 | 有效结束 | DATBI |
| cost_center_type | VARCHAR(2) | 否 | 成本中心类型 | KOSAR |
| status | VARCHAR(2) | 是 | 状态 | - |

### 2.2 成本中心类型

| 类型 | 代码 | 说明 |
|------|------|------|
| 生产 | 01 | 生产成本中心 |
| 辅助 | 02 | 辅助成本中心 |
| 管理 | 03 | 管理成本中心 |
| 销售 | 04 | 销售成本中心 |

## 3. 作业类型

### 3.1 作业类型字段 (co_activity_type)

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| activity_type | VARCHAR(6) | 是 | 作业类型代码 | LSTAR |
| name | VARCHAR(100) | 是 | 名称 | KTEXT |
| description | TEXT | 否 | 描述 | LTEXT |
| unit | VARCHAR(3) | 是 | 作业单位 | LEINH |
| activity_category | VARCHAR(1) | 否 | 作业类别 | LEART |
| cost_center_id | UUID | 否 | 成本中心 | KOSTL |
| plan_price | DECIMAL(15,4) | 否 | 计划价格 | - |
| plan_price_unit | INTEGER | 否 | 价格单位 | - |
| valid_from | DATE | 是 | 有效起始 | DATAB |
| valid_to | DATE | 是 | 有效结束 | DATBI |
| status | VARCHAR(2) | 是 | 状态 | - |

### 3.2 作业类别

| 类别 | 代码 | 说明 | 单位 |
|------|------|------|------|
| 人工 | 1 | 人工工时 | H |
| 机器 | 2 | 机器工时 | H |
| 其他 | 3 | 其他作业 | 各异 |

### 3.3 常用作业类型

| 作业类型 | 名称 | 单位 | 类别 |
|----------|------|------|------|
| LAB001 | 直接人工 | H | 1 |
| LAB002 | 间接人工 | H | 1 |
| LAB003 | 准备工时 | H | 1 |
| MAC001 | 机器工时 | H | 2 |
| MAC002 | 设备使用 | H | 2 |
| OTH001 | 管理费分摊 | % | 3 |

## 4. 作业价格

### 4.1 作业价格字段 (co_activity_price)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| activity_type_id | UUID | 是 | 作业类型ID |
| cost_center_id | UUID | 是 | 成本中心ID |
| fiscal_year | INTEGER | 是 | 会计年度 |
| period_from | INTEGER | 是 | 起始期间 |
| period_to | INTEGER | 是 | 结束期间 |
| plan_price | DECIMAL(15,4) | 是 | 计划价格 |
| actual_price | DECIMAL(15,4) | 否 | 实际价格 |
| price_unit | INTEGER | 是 | 价格单位 |
| currency_id | UUID | 否 | 货币ID |
| price_status | VARCHAR(2) | 是 | 价格状态 |

### 4.2 价格状态

| 状态 | 代码 | 说明 |
|------|------|------|
| 计划 | 01 | 计划价格 |
| 已释放 | 02 | 已释放使用 |

### 4.3 价格维护流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           作业价格维护流程                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. 制定计划价格                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 根据历史数据和预算制定                                           │   │
│   │   - 按期间维护价格                                                   │   │
│   │   - 价格单位 (如: 每100工时的价格)                                   │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   2. 释放价格                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 释放后可用于生产订单                                             │   │
│   │   - 影响产品成本核算                                                 │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   3. 计算实际价格 (期末)                                                    │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 实际成本 / 实际作业量                                            │   │
│   │   - 用于差异分析                                                     │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 5.1 成本字段 (co_cost_center_cost)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| cost_center_id | UUID | 是 | 成本中心ID |
| fiscal_year | INTEGER | 是 | 会计年度 |
| period | INTEGER | 是 | 期间 |
| cost_element_id | UUID | 是 | 成本要素ID |
| planned_cost | DECIMAL(15,2) | 否 | 计划成本 |
| actual_cost | DECIMAL(15,2) | 否 | 实际成本 |
| allocated_cost | DECIMAL(15,2) | 否 | 分配成本 |
| variance | DECIMAL(15,2) | 否 | 差异 |
