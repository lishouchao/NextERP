# CO 内部订单

**模块**: Internal Order
**对标**: SAP KO01/KO02
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

| 功能 | 说明 | 对标 |
|------|------|------|
| 订单创建 | 创建内部订单 | KO01 |
| 订单修改 | 修改订单数据 | KO02 |
| 预算管理 | 预算控制 | KO22 |
| 结算 | 订单结算 | KO88 |

### 1.2 内部订单类型

| 类型 | 代码 | 说明 | 用途 |
|------|------|------|------|
| 间接费用订单 | IO01 | 间接费用 | 费用归集 |
| 投资订单 | IO02 | 资本支出 | 资产建设 |
| 维修订单 | IO03 | 设备维修 | 维修费用 |
| 研发订单 | IO04 | 研发项目 | 研发费用 |

### 1.3 订单生命周期

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           内部订单生命周期                                   │
├─────────────────────────────────────────────────────────────────────────────┤

│                          │                                                  │

│   2. 释放                                                                   │

│   │   - 允许成本归集                                                     │   │
│   │   - 状态: 释放 (02)                                                  │   │
│   └─────────────────────────────────────────────────────────────────────┘   │

│   ┌─────────────────────────────────────────────────────────────────────┐   │

│   │   - 预算检查                                                         │   │

│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   5. 结算                                                                   │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 将成本结算到接收方                                               │   │
│   │   - 生成结算凭证                                                     │   │
│   │   - 状态: 结算 (04)                                                  │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. 内部订单主数据

### 2.1 订单头字段 (co_internal_order_hdr)

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| order_number | VARCHAR(12) | 是 | 订单号 | AUFNR |
| order_type | VARCHAR(4) | 是 | 订单类型 | AUART |
| description | VARCHAR(100) | 是 | 描述 | KTEXT |
| company_id | UUID | 是 | 公司 | BUKRS |
| cost_center_id | UUID | 否 | 成本中心 | KOSTL |
| profit_center_id | UUID | 否 | 利润中心 | PRCTR |
| controlling_area | VARCHAR(4) | 否 | 控制范围 | KOKRS |
| responsible_id | UUID | 否 | 负责人 | VERAK |
| start_date | DATE | 否 | 开始日期 | GSTRP |
| end_date | DATE | 否 | 结束日期 | GLTRP |
| total_budget | DECIMAL(15,2) | 否 | 总预算 | - |
| committed_cost | DECIMAL(15,2) | 否 | 承诺成本 | - |
| actual_cost | DECIMAL(15,2) | 否 | 实际成本 | - |
| currency_id | UUID | 否 | 货币 | - |
| settlement_rule | VARCHAR(2) | 否 | 结算规则 | - |
| settlement_receiver | VARCHAR(24) | 否 | 结算接收方 | - |
| order_status | VARCHAR(2) | 是 | 订单状态 | - |

### 2.2 订单状态

| 状态 | 代码 | 说明 | 允许操作 |
|------|------|------|----------|
| 创建 | 01 | 已创建 | 修改、释放 |
| 释放 | 02 | 已释放 | 过账、完成 |
| 完成 | 03 | 已完成 | 结算 |
| 结算 | 04 | 已结算 | 关闭 |

### 2.3 创建订单流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           创建内部订单                                       │

│   1. 输入基本信息                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 选择订单类型 (如 IO01 间接费用订单)                              │   │
│   │   - 输入订单描述                                                     │   │
│   │   - 系统自动生成订单号                                               │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   2. 输入组织信息                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 选择公司                                                         │   │
│   │   - 选择成本中心                                                     │   │
│   │   - 选择利润中心 (可选)                                              │   │

│   └─────────────────────────────────────────────────────────────────────┘   │

│                          ▼                                                  │
│   4. 配置结算规则                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐   │

│   │   - 结算比例                                                         │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 3. 预算管理

### 3.1 预算类型

| 类型 | 说明 |
|------|------|
| 总预算 | 订单总预算金额 |
| 年度预算 | 按年度分配预算 |
| 月度预算 | 按月度分配预算 |

### 3.2 预算控制

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           预算控制逻辑                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   预算检查公式:                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   可用预算 = 总预算 - 已使用预算 - 承诺成本                          │   │
│   │                                                                       │   │
│   │   已使用预算 = 实际成本                                              │   │
│   │   承诺成本 = 采购订单未清金额                                        │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   预算警告阈值:                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 80%: 提示警告                                                    │   │
│   │   - 90%: 严重警告                                                    │   │
│   │   - 100%: 阻止过账 (可配置)                                          │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.3 预算补充和转储

| 操作 | 说明 |
|------|------|
| 预算补充 | 增加订单预算 |
| 预算转储 | 从其他订单转入预算 |
| 预算释放 | 释放未使用预算 |

## 4. 订单成本

### 4.1 订单成本字段 (co_order_cost)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| order_id | UUID | 是 | 订单ID |
| fiscal_year | INTEGER | 是 | 会计年度 |
| period | INTEGER | 是 | 期间 |
| cost_element_id | UUID | 是 | 成本要素ID |
| planned_cost | DECIMAL(15,2) | 否 | 计划成本 |
| actual_cost | DECIMAL(15,2) | 否 | 实际成本 |
| committed_cost | DECIMAL(15,2) | 否 | 承诺成本 |
| settled_cost | DECIMAL(15,2) | 否 | 已结算成本 |

### 4.2 成本归集来源

| 来源 | 说明 |
|------|------|
| FI凭证 | 费用报销、发票校验 |
| 采购订单 | 采购承诺成本 |
| 工时确认 | 人工成本 |
| 作业分配 | 内部作业成本 |

## 5. 订单结算

### 5.1 结算规则

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           结算规则配置                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   结算规则示例:                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   规则1:                                                             │   │
│   │   - 接收方类型: 成本中心                                             │   │
│   │   - 接收方: CC001                                                    │   │
│   │   - 结算比例: 80%                                                    │   │
│   │                                                                       │   │
│   │   规则2:                                                             │   │
│   │   - 接收方类型: 资产                                                 │   │
│   │   - 接收方: 1000000001                                               │   │
│   │   - 结算比例: 20%                                                    │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   结算接收方类型:                                                           │
│   - 成本中心 (CC)                                                           │
│   - 资产 (AS)                                                               │
│   - 总账科目 (GL)                                                           │
│   - 利润中心 (PC)                                                           │
│   - 其他订单 (OR)                                                           │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 5.2 结算流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           结算流程                                           │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. 标记订单完成                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 确认所有成本已归集                                               │   │
│   │   - 订单状态改为"完成"                                               │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   2. 执行结算                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 按结算规则计算分配金额                                           │   │
│   │   - 生成结算凭证                                                     │   │
│   │   - 借: 接收方 / 贷: 订单                                            │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   3. 更新状态                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 订单状态改为"已结算"                                             │   │
│   │   - 记录已结算金额                                                   │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 6. 接口设计

### 6.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/co/internal-orders | GET | 内部订单列表 |
| /api/co/internal-orders | POST | 创建内部订单 |
| /api/co/internal-orders/{id} | GET | 订单详情 |
| /api/co/internal-orders/{id} | PUT | 更新订单 |
| /api/co/internal-orders/{id}/release | POST | 释放订单 |
| /api/co/internal-orders/{id}/complete | POST | 完成订单 |
| /api/co/internal-orders/{id}/settle | POST | 结算订单 |
| /api/co/internal-orders/{id}/budget | GET | 预算信息 |
| /api/co/internal-orders/{id}/budget | POST | 更新预算 |
| /api/co/internal-orders/{id}/costs | GET | 订单成本 |
