# CO 产品成本核算

**模块**: Product Cost Controlling
**对标**: SAP CK11N/CK24
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

| 功能 | 说明 | 对标 |
|------|------|------|
| 成本估算 | 计算产品成本 | CK11N |
| 成本发布 | 发布标准成本 | CK24 |
| 成本结构 | 成本构成 | OKEON |
| 差异分析 | 成本差异 | CKM3 |

### 1.2 成本核算流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           产品成本核算流程                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. 数据准备                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 物料主数据 (价格控制、采购价格)                                  │   │
│   │   - BOM (物料清单)                                                   │   │
│   │   - 工艺路线 (工序、作业类型)                                        │   │
│   │   - 作业价格 (成本中心作业价格)                                      │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   2. 成本估算                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 读取BOM结构                                                      │   │
│   │   - 计算材料成本                                                     │   │
│   │   - 计算人工成本 (工艺 × 作业价格)                                   │   │
│   │   - 计算制造费用                                                     │   │
│   │   - 汇总总成本                                                       │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   3. 成本审批                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 审查成本明细                                                     │   │
│   │   - 与历史成本比较                                                   │   │
│   │   - 审批通过                                                         │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   4. 成本发布                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 标记为未来标准成本                                               │   │
│   │   - 发布到物料主数据                                                 │   │
│   │   - 生效日期                                                         │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. 成本估算

### 2.1 成本估算头字段 (co_cost_estimate_hdr)

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| estimate_number | VARCHAR(12) | 是 | 估算号 | KALNR |
| estimate_type | VARCHAR(2) | 是 | 估算类型 | KADKY |
| material_id | UUID | 是 | 物料ID | MATNR |
| material_code | VARCHAR(18) | 是 | 物料代码 | - |
| plant_id | UUID | 是 | 工厂 | WERKS |
| costing_version | VARCHAR(3) | 否 | 成本核算版本 | VERID |
| costing_date | DATE | 是 | 核算日期 | KADAT |
| valid_from | DATE | 否 | 有效起始 | DATAB |
| valid_to | DATE | 否 | 有效结束 | DATBI |
| costing_lot_size | DECIMAL(13,3) | 否 | 成本批量 | LOSGR |
| total_cost | DECIMAL(15,2) | 是 | 总成本 | - |
| material_cost | DECIMAL(15,2) | 否 | 材料成本 | - |
| labor_cost | DECIMAL(15,2) | 否 | 人工成本 | - |
| machine_cost | DECIMAL(15,2) | 否 | 机器成本 | - |
| overhead_cost | DECIMAL(15,2) | 否 | 制造费用 | - |
| external_cost | DECIMAL(15,2) | 否 | 外协成本 | - |
| currency_id | UUID | 否 | 货币 | - |
| estimate_status | VARCHAR(2) | 是 | 估算状态 | - |

### 2.2 成本估算类型

| 类型 | 代码 | 说明 | 用途 |
|------|------|------|------|
| 标准成本估算 | 01 | 标准成本 | 成本控制 |
| 修改估算 | 02 | 修改成本 | 成本调整 |
| 销售订单估算 | 03 | 订单成本 | 报价参考 |

### 2.3 估算状态

| 状态 | 代码 | 说明 |
|------|------|------|
| 创建 | 01 | 已创建 |
| 审批 | 02 | 已审批 |
| 标记 | 03 | 已标记 |
| 发布 | 04 | 已发布 |

### 2.4 成本估算项字段 (co_cost_estimate_itm)

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| header_id | UUID | 是 | 估算头ID | - |
| level_number | INTEGER | 是 | 层级 | - |
| item_number | INTEGER | 是 | 项目号 | - |
| cost_category | VARCHAR(4) | 是 | 成本类别 | KKHER |
| cost_element_id | UUID | 否 | 成本要素 | - |
| source_type | VARCHAR(2) | 否 | 来源类型 | - |
| total_cost | DECIMAL(15,2) | 是 | 总成本 | - |
| fixed_cost | DECIMAL(15,2) | 否 | 固定成本 | - |
| variable_cost | DECIMAL(15,2) | 否 | 变动成本 | - |
| quantity | DECIMAL(13,3) | 否 | 数量 | - |
| unit | VARCHAR(3) | 否 | 单位 | - |
| unit_cost | DECIMAL(15,4) | 否 | 单位成本 | - |

### 2.5 成本类别

| 类别 | 代码 | 说明 |
|------|------|------|
| 原材料 | M001 | 直接材料 |
| 半成品 | M002 | 半成品 |
| 人工 | L001 | 直接人工 |
| 准备人工 | L002 | 准备人工 |
| 机器 | MCH01 | 机器成本 |
| 外协 | V001 | 外协成本 |
| 制造费用 | O001 | 制造费用 |

## 6. 接口设计
