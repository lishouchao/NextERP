# CO 获利分析

**模块**: Profitability Analysis (CO-PA)
**对标**: SAP KEA0/KE30
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

| 功能 | 说明 | 对标 |
|------|------|------|
| 获利段定义 | PA维度配置 | KEA0 |
| 获利数据 | 实际/计划数据 | KE21N |
| 获利报表 | PA报表 | KE30 |
| 贡献毛利 | 盈利分析 | KE24 |

### 1.2 CO-PA架构

## 2. 获利段

### 2.1 获利段字段 (co_profitability_segment)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| segment_code | VARCHAR(30) | 是 | 获利段编码 |
| company_id | UUID | 否 | 公司ID |
| profit_center_id | UUID | 否 | 利润中心ID |
| customer_id | UUID | 否 | 客户ID |
| material_id | UUID | 否 | 物料ID |
| sales_org_id | UUID | 否 | 销售组织ID |
| distribution_channel | VARCHAR(2) | 否 | 分销渠道 |
| division | VARCHAR(2) | 否 | 产品组 |
| product_group | VARCHAR(4) | 否 | 产品组 |
| region_id | UUID | 否 | 地区ID |
| country_id | UUID | 否 | 国家ID |
| is_active | BOOLEAN | 是 | 是否激活 |

### 2.2 PA维度

| 维度 | 说明 | 对标 |
|------|------|------|
| 公司 | 公司代码 | BUKRS |
| 利润中心 | 利润中心代码 | PRCTR |
| 客户 | 客户代码 | KUNNR |
| 物料 | 物料代码 | MATNR |
| 销售组织 | 销售组织 | VKORG |
| 分销渠道 | 分销渠道 | VTWEG |
| 产品组 | 产品组 | SPART |
| 地区 | 地区代码 | REGIO |
| 国家 | 国家代码 | LAND1 |

## 3. 获利数据

### 3.1 获利数据字段 (co_pa_data)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| segment_id | UUID | 是 | 获利段ID |
| fiscal_year | INTEGER | 是 | 会计年度 |
| period | INTEGER | 是 | 期间 |
| record_type | VARCHAR(1) | 否 | 记录类型 |
| source_type | VARCHAR(2) | 否 | 来源类型 |
| source_document | VARCHAR(20) | 否 | 来源单据 |
| sales_qty | DECIMAL(13,3) | 否 | 销售数量 |
| sales_unit | VARCHAR(3) | 否 | 销售单位 |
| revenue | DECIMAL(15,2) | 否 | 销售收入 |
| cost_of_sales | DECIMAL(15,2) | 否 | 销售成本 |
| gross_profit | DECIMAL(15,2) | 否 | 毛利 |
| material_cost | DECIMAL(15,2) | 否 | 材料成本 |
| labor_cost | DECIMAL(15,2) | 否 | 人工成本 |
| overhead_cost | DECIMAL(15,2) | 否 | 制造费用 |
| discount_amount | DECIMAL(15,2) | 否 | 折扣金额 |
| rebate_amount | DECIMAL(15,2) | 否 | 返利金额 |
| contribution_margin | DECIMAL(15,2) | 否 | 贡献毛利 |
| currency_id | UUID | 否 | 货币ID |
| posting_date | DATE | 是 | 过账日期 |
| customer_group | VARCHAR(2) | 否 | 客户组 |
| material_group | VARCHAR(9) | 否 | 物料组 |

## 4. 盈利分析

### 4.1 盈利指标

| 指标 | 计算公式 | 说明 |
|------|----------|------|
| 毛利 | 收入 - 销售成本 | 销售毛利 |
| 毛利率 | 毛利 / 收入 × 100% | 毛利率 |
| 贡献毛利 | 毛利 - 变动费用 | 边际贡献 |
| 贡献毛利率 | 贡献毛利 / 收入 × 100% | 边际贡献率 |

## 5. 接口设计

### 5.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/co/pa/segments | GET | 获利段列表 |
| /api/co/pa/segments | POST | 创建获利段 |
| /api/co/pa/segments/{id} | GET | 获利段详情 |
| /api/co/pa/data | GET | 获利数据列表 |
| /api/co/pa/data | POST | 创建获利数据 |
| /api/co/pa/reports/profitability | GET | 盈利分析报表 |
| /api/co/pa/reports/contribution | GET | 贡献毛利报表 |
| /api/co/pa/reports/by-product | GET | 按产品分析 |
| /api/co/pa/reports/by-customer | GET | 按客户分析 |
| /api/co/pa/reports/by-region | GET | 按地区分析 |
