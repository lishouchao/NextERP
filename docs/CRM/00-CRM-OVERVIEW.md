# CRM 客户关系管理模块总览

**模块**: Customer Relationship Management (客户关系管理)
**对标**: SAP CRM / Salesforce / Microsoft Dynamics
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 模块概述

### 1.1 功能范围

CRM模块负责管理企业与客户的完整关系生命周期，从线索获取到成交转化：

| 子模块 | 功能 | 对标 |
|--------|------|------|
| 线索管理 | 销售线索获取与转化 | Salesforce Leads |
| 商机管理 | 销售机会阶段管理 | SAP CRM Opportunity |
| 客户360° | 客户全景视图 | Salesforce Account 360 |
| 活动管理 | 任务、日程、交互记录 | SAP CRM Activity |
| 销售管道 | 管道分析与预测 | SAP CRM Pipeline |
| 营销管理 | 营销活动与效果追踪 | SAP Marketing |

### 3.2 商机阶段详情

| 阶段 | 代码 | 成功概率 | 主要活动 |
|------|------|----------|----------|
| 初步接触 | 01 | 10% | 首次沟通，了解需求 |
| 需求确认 | 02 | 20% | 深入了解，确认痛点 |
| 方案演示 | 03 | 40% | 产品演示，方案讲解 |
| 商务谈判 | 04 | 60% | 价格协商，条款讨论 |
| 合同审批 | 05 | 80% | 合同签署，内部审批 |
| 赢单 | 06 | 100% | 成交 |
| 输单 | 07 | 0% | 失败 |

## 4. 客户生命周期

### 4.1 生命周期阶段

```
客户生命周期:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   01潜在 ──► 02新客户 ──► 03活跃 ──► 04忠诚 ──► 05流失风险 ──► 06流失      │
│      │          │          │          │           │            │            │
│      ▼          ▼          ▼          ▼           ▼            ▼            │
│   尚未成交   首次成交   持续购买   高频高价    购买减少     不再购买        │
│   线索培育   建立关系   深化合作   VIP服务    挽留措施     重新激活        │
│                                                                             │
│   客户等级 (Customer Tier):                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   01 钻石  - 顶级大客户，年收入>500万                                │  │
│   │   02 白金  - 重要客户，年收入100-500万                               │  │
│   │   03 金    - 主要客户，年收入50-100万                                │  │
│   │   04 银    - 普通客户，年收入10-50万                                 │  │
│   │   05 铜    - 小客户，年收入<10万                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.2 RFM分析

| 指标 | 说明 | 计算方式 |
|------|------|----------|
| R (Recency) | 最近购买时间 | 距今天数 |
| F (Frequency) | 购买频次 | 总订单数 |
| M (Monetary) | 消费金额 | 总消费金额 |
| RFM Score | 综合得分 | R×100 + F×10 + M |
