# CRM 线索管理设计

**模块**: Lead Management (线索管理)
**对标**: Salesforce Leads / SAP CRM Lead
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

线索管理负责销售线索的获取、评分、培育与转化：

| 功能 | 说明 | 对标 |
|------|------|------|
| 线索获取 | 多渠道线索录入 | Salesforce Lead |
| 线索评分 | 自动评分与分级 | Lead Scoring |
| 线索培育 | 市场活动跟进 | Lead Nurturing |
| 线索转化 | 转换为商机/客户 | Lead Conversion |

### 2.3 线索状态

| 状态 | 代码 | 说明 | 允许操作 |
|------|------|------|----------|
| 新建 | 01 | 新创建的线索 | 联系、评分 |
| 已联系 | 02 | 已首次联系 | 跟进、合格 |
| 合格 | 03 | 确认为合格线索 | 转化商机 |
| 不合格 | 04 | 确认为不合格 | 关闭、培育 |
| 已转化 | 05 | 已转化为商机/客户 | 查看 |
| 已关闭 | 06 | 已关闭 | 重新激活 |

### 2.4 公司规模

| 代码 | 范围 | 说明 |
|------|------|------|
| 01 | 1-50人 | 小型企业 |
| 02 | 51-200人 | 中小型企业 |
| 03 | 201-500人 | 中型企业 |
| 04 | 501-1000人 | 中大型企业 |
| 05 | 1000+人 | 大型企业 |

### 2.5 预算范围

| 代码 | 范围 | 说明 |
|------|------|------|
| 01 | <10万 | 小预算 |
| 02 | 10-50万 | 中小预算 |
| 03 | 50-100万 | 中等预算 |
| 04 | 100-500万 | 较大预算 |
| 05 | >500万 | 大预算 |

## 3. 线索评分

### 3.1 评分规则 (crm_lead_scoring_rule)

| 字段 | 类型 | 说明 |
|------|------|------|
| rule_name | VARCHAR(100) | 规则名称 |
| field_name | VARCHAR(50) | 字段名 |
| operator | VARCHAR(2) | 操作符 (EQ/NE/IN/GT/LT) |
| field_value | VARCHAR(200) | 字段值 |
| score | INTEGER | 得分 |
| priority | INTEGER | 优先级 |
| is_active | BOOLEAN | 是否激活 |

### 3.2 评分规则配置

```
默认评分规则:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   规则名称              字段          条件              得分    优先级       │
│   ─────────────────────────────────────────────────────────────────────    │
│   大型企业加分          company_size  IN (04,05)       +20     10          │
│   中型企业加分          company_size  IN (02,03)       +10     10          │
│   目标行业加分          industry      IN (01,02,03)    +15     20          │
│   大预算加分            budget        IN (04,05)       +25     30          │
│   中等预算加分          budget        IN (03)          +15     30          │
│   决策者加分            title         IN (CEO,CTO)     +20     40          │
│   高管加分              title         LIKE 'VP%'       +15     40          │
│   有效邮箱              email         NOT NULL         +5      50          │
│   有效电话              phone         NOT NULL         +5      50          │
│   ─────────────────────────────────────────────────────────────────────    │
│                                                                             │
│   总分计算: SUM(匹配规则的得分), 最高100分                                   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 4. 线索转化

### 4.1 转化流程

```
线索转化流程:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   1. 检查线索状态                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   └── 线索状态必须为"合格"(03)，且未转化                             │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                          │                                                  │
│                          ▼                                                  │
│   2. 创建/关联客户                                                          │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                                                                     │  │
│   │   ┌─────────────────────────────────────────────────────────────┐  │  │
│   │   │   if (公司已存在于BP):                                       │  │  │
│   │   │       关联现有客户                                           │  │  │
│   │   │   else:                                                      │  │  │
│   │   │       创建新客户(BP) + 添加客户角色                           │  │  │
│   │   └─────────────────────────────────────────────────────────────┘  │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                          │                                                  │
│                          ▼                                                  │
│   3. 创建联系人                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   └── 将线索联系人信息转为CRM联系人，关联到客户                      │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                          │                                                  │
│                          ▼                                                  │
│   4. 创建商机                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   ┌─────────────────────────────────────────────────────────────┐  │  │
│   │   │   商机名称: 公司名称 - 商机                                    │  │  │
│   │   │   阶段: 01 (初步接触)                                         │  │  │
│   │   │   概率: 10%                                                   │  │  │
│   │   │   金额: 根据预算范围估算                                       │  │  │
│   │   │   来源线索: 原线索ID                                          │  │  │
│   │   └─────────────────────────────────────────────────────────────┘  │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                          │                                                  │
│                          ▼                                                  │
│   5. 更新线索状态                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   └── 状态=已转化(05)，记录转化日期和关联ID                          │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 6. 接口设计

### 6.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/crm/leads | GET | 线索列表 |
| /api/crm/leads | POST | 创建线索 |
| /api/crm/leads/{id} | GET | 线索详情 |
| /api/crm/leads/{id} | PUT | 更新线索 |
| /api/crm/leads/{id} | DELETE | 删除线索 |
| /api/crm/leads/{id}/score | POST | 重新评分 |
| /api/crm/leads/{id}/convert | POST | 转化线索 |
| /api/crm/leads/{id}/qualify | POST | 标记合格 |
| /api/crm/leads/{id}/disqualify | POST | 标记不合格 |
| /api/crm/leads/scoring-rules | GET | 评分规则列表 |
| /api/crm/leads/scoring-rules | POST | 创建评分规则 |
| /api/crm/leads/analytics/by-source | GET | 来源分析 |
