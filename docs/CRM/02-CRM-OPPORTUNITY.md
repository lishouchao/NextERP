# CRM 商机管理设计

**模块**: Opportunity Management (商机管理)
**对标**: Salesforce Opportunity / SAP CRM Opportunity
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

商机管理负责销售机会的全生命周期管理：

| 功能 | 说明 | 对标 |
|------|------|------|
| 商机创建 | 创建销售机会 | Opportunity Create |
| 阶段管理 | 推进销售阶段 | Stage Management |
| 预测分析 | 销售预测 | Forecasting |
| 赢单/输单 | 结果管理 | Win/Loss |

## 2. 商机主数据

### 2.1 商机字段 (crm_opportunity)

| 字段 | 类型 | 说明 | 对标 |
|------|------|------|------|
| opportunity_number | VARCHAR(12) | 商机号 | Opportunity Number |
| opportunity_name | VARCHAR(100) | 商机名称 | Opportunity Name |
| description | TEXT | 描述 | Description |
| customer_id | UUID | 客户ID | Account |
| customer_name | VARCHAR(100) | 客户名称 | Account Name |
| contact_id | UUID | 主要联系人 | Primary Contact |
| stage | VARCHAR(2) | 商机阶段 | Stage |
| probability | INTEGER | 成功概率% | Probability |
| is_closed | BOOLEAN | 是否关闭 | Closed |
| is_won | BOOLEAN | 是否赢单 | Won |
| close_date | DATE | 预计成交日期 | Close Date |
| amount | DECIMAL(15,2) | 商机金额 | Amount |
| currency_id | UUID | 币种 | Currency |
| expected_revenue | DECIMAL(15,2) | 加权收入 | Expected Revenue |
| lead_id | UUID | 来源线索 | Lead |
| campaign_id | UUID | 营销活动 | Campaign |
| source_type | VARCHAR(2) | 来源类型 | Source |
| product_interest | VARCHAR(200) | 产品兴趣 | Products |
| owner_id | UUID | 负责人 | Owner |
| team_id | UUID | 销售团队 | Team |
| company_id | UUID | 公司 | Company |
| sales_org_id | UUID | 销售组织 | Sales Org |
| competitor_id | UUID | 竞争对手 | Competitor |
| competition_status | VARCHAR(2) | 竞争状态 | Competition |
| loss_reason | VARCHAR(4) | 输单原因 | Loss Reason |
| loss_remark | TEXT | 输单备注 | Loss Remark |

### 2.2 商机阶段

```
商机阶段配置:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   阶段  代码  名称        概率    关键活动                可进入阶段         │
│   ─────────────────────────────────────────────────────────────────────    │
│   01    初步接触  10%     首次沟通，了解需求        02,07                 │
│   02    需求确认  20%     深入了解，确认痛点        01,03,07              │
│   03    方案演示  40%     产品演示，方案讲解        02,04,07              │
│   04    商务谈判  60%     价格协商，条款讨论        03,05,07              │
│   05    合同审批  80%     合同签署，内部审批        04,06,07              │
│   06    赢单      100%    成交，关闭商机           -                     │
│   07    输单      0%      失败，关闭商机           -                     │
│   ─────────────────────────────────────────────────────────────────────    │
│                                                                             │
│   加权收入计算:                                                              │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   expected_revenue = amount × probability / 100                     │  │
│   │                                                                     │  │
│   │   示例:                                                              │  │
│   │   商机金额: 1,000,000元                                              │  │
│   │   阶段: 03 (方案演示)                                                │  │
│   │   概率: 40%                                                          │  │
│   │   加权收入: 1,000,000 × 40% = 400,000元                             │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.3 输单原因

| 代码 | 原因 | 说明 |
|------|------|------|
| 01 | 价格过高 | 价格不具竞争力 |
| 02 | 功能不足 | 产品功能无法满足需求 |
| 03 | 竞争对手 | 选择了竞争对手 |
| 04 | 预算取消 | 客户预算被取消 |
| 05 | 项目暂停 | 项目被暂停或延期 |
| 06 | 决策变更 | 决策者变更或需求变化 |
| 07 | 响应不及时 | 响应速度太慢 |
| 08 | 其他 | 其他原因 |

## 7. 接口设计

### 7.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/crm/opportunities | GET | 商机列表 |
| /api/crm/opportunities | POST | 创建商机 |
| /api/crm/opportunities/{id} | GET | 商机详情 |
| /api/crm/opportunities/{id} | PUT | 更新商机 |
| /api/crm/opportunities/{id} | DELETE | 删除商机 |
| /api/crm/opportunities/{id}/stage | PUT | 更新阶段 |
| /api/crm/opportunities/{id}/win | POST | 标记赢单 |
| /api/crm/opportunities/{id}/lose | POST | 标记输单 |
| /api/crm/opportunities/{id}/products | GET | 商机产品 |
| /api/crm/opportunities/{id}/products | POST | 添加产品 |
| /api/crm/opportunities/{id}/history | GET | 阶段历史 |
| /api/crm/opportunities/{id}/create-order | POST | 创建销售订单 |
