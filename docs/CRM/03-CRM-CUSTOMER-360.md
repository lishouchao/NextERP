# CRM 客户360°设计

**模块**: Customer 360° (客户全景视图)
**对标**: Salesforce Account 360 / SAP CRM Customer View
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

客户360°提供客户的完整全景视图：

| 功能 | 说明 | 对标 |
|------|------|------|
| 客户视图 | 客户完整信息 | Account View |
| 联系人管理 | 联系人信息维护 | Contact Management |
| 交互记录 | 客户交互历史 | Interaction History |
| 客户摘要 | 统计信息汇总 | Customer Summary |

## 3. 客户交互

### 3.1 交互字段 (crm_interaction)

| 字段 | 类型 | 说明 | 对标 |
|------|------|------|------|
| customer_id | UUID | 客户ID | Account |
| contact_id | UUID | 联系人ID | Contact |
| opportunity_id | UUID | 商机ID | Opportunity |
| lead_id | UUID | 线索ID | Lead |
| interaction_type | VARCHAR(2) | 交互类型 | Type |
| direction | VARCHAR(1) | 方向 (I/O) | Direction |
| subject | VARCHAR(200) | 主题 | Subject |
| content | TEXT | 内容 | Content |
| interaction_date | TIMESTAMP | 交互时间 | Date |
| duration | INTEGER | 持续时间(分钟) | Duration |
| related_type | VARCHAR(2) | 关联类型 | Related |
| related_document | VARCHAR(20) | 关联单据 | Document |
| owner_id | UUID | 负责人 | Owner |

### 3.2 交互类型

| 类型 | 代码 | 说明 | 方向 |
|------|------|------|------|
| 电话 | 01 | 电话沟通 | I/O |
| 邮件 | 02 | 邮件往来 | I/O |
| 会议 | 03 | 线上/线下会议 | O |
| 拜访 | 04 | 客户现场拜访 | O |
| 微信 | 05 | 微信沟通 | I/O |
| 其他 | 06 | 其他方式 | I/O |

### 4.4 RFM分析

```
RFM分析模型:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   RFM 定义:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   R (Recency)  - 最近一次购买距今天数                               │  │
│   │   F (Frequency) - 一定时期内购买次数                                │  │
│   │   M (Monetary)  - 一定时期内消费金额                                │  │
│   │                                                                     │  │
│   │   RFM Score = R_score × 100 + F_score × 10 + M_score                │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   评分标准:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   R Score:                                                          │  │
│   │   5分: ≤30天    4分: 31-90天    3分: 91-180天                       │  │
│   │   2分: 181-365天    1分: >365天                                     │  │
│   │                                                                     │  │
│   │   F Score:                                                          │  │
│   │   5分: ≥12次    4分: 8-11次    3分: 4-7次                           │  │
│   │   2分: 2-3次    1分: 1次                                            │  │
│   │                                                                     │  │
│   │   M Score:                                                          │  │
│   │   5分: ≥100万    4分: 50-100万    3分: 20-50万                      │  │
│   │   2分: 10-20万    1分: <10万                                        │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   客户分群:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   RFM ≥ 444: 重要价值客户 - 重点维护                                │  │
│   │   R ≥ 4, F ≥ 4: 重要保持客户 - 保持关系                             │  │
│   │   R ≥ 4, F ≤ 2: 重要发展客户 - 促进消费                             │  │
│   │   R ≤ 2, F ≥ 4: 重要挽留客户 - 挽留激活                             │  │
│   │   R ≤ 2, F ≤ 2: 低价值客户 - 低成本维护                             │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
