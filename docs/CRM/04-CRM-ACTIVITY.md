# CRM 活动管理设计

**模块**: Activity Management (活动管理)
**对标**: Salesforce Activity / SAP CRM Activity
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

活动管理负责销售活动的计划与执行：

| 功能 | 说明 | 对标 |
|------|------|------|
| 任务管理 | 销售任务跟踪 | Task Management |
| 日程管理 | 日历与日程 | Calendar |
| 交互记录 | 客户互动记录 | Interaction Log |

## 2. 任务管理

### 2.1 任务字段 (crm_task)

| 字段 | 类型 | 说明 | 对标 |
|------|------|------|------|
| subject | VARCHAR(200) | 主题 | Subject |
| description | TEXT | 描述 | Description |
| task_type | VARCHAR(2) | 任务类型 | Task Type |
| related_type | VARCHAR(2) | 关联类型 | Related To |
| related_id | UUID | 关联ID | Related ID |
| related_name | VARCHAR(100) | 关联名称 | Related Name |
| priority | VARCHAR(2) | 优先级 | Priority |
| due_date | DATE | 截止日期 | Due Date |
| completed_date | DATE | 完成日期 | Completed Date |
| task_status | VARCHAR(2) | 任务状态 | Status |
| is_completed | BOOLEAN | 是否完成 | Completed |
| owner_id | UUID | 负责人 | Owner |

### 2.2 任务类型

| 类型 | 代码 | 说明 | 适用场景 |
|------|------|------|----------|
| 电话 | 01 | 电话联系 | 跟进、确认 |
| 邮件 | 02 | 发送邮件 | 资料发送 |
| 会议 | 03 | 安排会议 | 方案演示 |
| 拜访 | 04 | 客户拜访 | 现场沟通 |
| 演示 | 05 | 产品演示 | 方案展示 |
| 跟进 | 06 | 常规跟进 | 状态确认 |
| 其他 | 07 | 其他任务 | - |

### 2.3 任务优先级

| 优先级 | 代码 | 说明 | 提醒 |
|--------|------|------|------|
| 高 | 01 | 紧急任务 | 超期提醒 |
| 中 | 02 | 重要任务 | 当天提醒 |
| 低 | 03 | 普通任务 | 提前一天提醒 |

### 2.4 任务状态

| 状态 | 代码 | 说明 | 操作 |
|------|------|------|------|
| 未开始 | 01 | 尚未开始 | 开始、取消 |
| 进行中 | 02 | 正在执行 | 完成、取消 |
| 已完成 | 03 | 已经完成 | 重新打开 |
| 已取消 | 04 | 已取消 | 重新打开 |

### 2.5 任务关联类型

| 类型 | 代码 | 说明 | 关联表 |
|------|------|------|--------|
| 线索 | LE | 线索相关任务 | crm_lead |
| 商机 | OP | 商机相关任务 | crm_opportunity |
| 客户 | CU | 客户相关任务 | bp_business_partner |
| 联系人 | CO | 联系人相关任务 | crm_contact |

## 3. 日程管理

### 3.1 日程字段 (crm_calendar)

| 字段 | 类型 | 说明 | 对标 |
|------|------|------|------|
| subject | VARCHAR(200) | 主题 | Subject |
| description | TEXT | 描述 | Description |
| location | VARCHAR(200) | 地点 | Location |
| event_type | VARCHAR(2) | 日程类型 | Event Type |
| start_time | TIMESTAMP | 开始时间 | Start Time |
| end_time | TIMESTAMP | 结束时间 | End Time |
| is_all_day | BOOLEAN | 全天事件 | All Day |
| recurrence_type | VARCHAR(1) | 重复类型 | Recurrence |
| recurrence_end | DATE | 重复结束日期 | Recurrence End |
| related_type | VARCHAR(2) | 关联类型 | Related To |
| related_id | UUID | 关联ID | Related ID |
| owner_id | UUID | 参与人 | Owner |
| reminder_minutes | INTEGER | 提前提醒分钟 | Reminder |
| event_status | VARCHAR(2) | 日程状态 | Status |

### 3.2 日程类型

| 类型 | 代码 | 说明 | 时长 |
|------|------|------|------|
| 会议 | 01 | 内外部会议 | 30min-2h |
| 拜访 | 02 | 客户拜访 | 1-4h |
| 演示 | 03 | 产品演示 | 1-2h |
| 培训 | 04 | 内部培训 | 1-8h |
| 其他 | 05 | 其他日程 | - |

### 3.3 重复规则

| 类型 | 代码 | 说明 | 示例 |
|------|------|------|------|
| 不重复 | N | 单次事件 | - |
| 每日 | D | 每天重复 | 每天上午9点 |
| 每周 | W | 每周重复 | 每周一 |
| 每月 | M | 每月重复 | 每月1号 |
| 每年 | Y | 每年重复 | 每年1月1日 |

## 4. 交互记录

交互记录已在客户360°文档中详细说明，这里仅作概要：

| 字段 | 类型 | 说明 |

## 7. 接口设计

### 7.1 REST API

**任务接口:**

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/crm/tasks | GET | 任务列表 |
| /api/crm/tasks | POST | 创建任务 |
| /api/crm/tasks/{id} | GET | 任务详情 |
| /api/crm/tasks/{id} | PUT | 更新任务 |
| /api/crm/tasks/{id} | DELETE | 删除任务 |
| /api/crm/tasks/{id}/complete | POST | 完成任务 |
| /api/crm/tasks/{id}/cancel | POST | 取消任务 |
| /api/crm/tasks/today | GET | 今日任务 |
| /api/crm/tasks/overdue | GET | 超期任务 |

**日程接口:**

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/crm/calendar | GET | 日程列表 |
| /api/crm/calendar | POST | 创建日程 |
| /api/crm/calendar/{id} | GET | 日程详情 |
| /api/crm/calendar/{id} | PUT | 更新日程 |
| /api/crm/calendar/{id} | DELETE | 删除日程 |
| /api/crm/calendar/week | GET | 周视图 |
| /api/crm/calendar/month | GET | 月视图 |

### 7.2 创建任务请求

```json
{
  "subject": "跟进 ABC科技 商务谈判",
  "description": "确认合同条款，讨论付款条件",
  "taskType": "01",
  "relatedType": "OP",
  "relatedId": "uuid-opportunity",
  "priority": "01",
  "dueDate": "2026-03-25",
  "ownerId": "uuid-employee"
}
```

### 7.3 创建日程请求

```json
{
  "subject": "ABC科技 产品演示会议",
  "description": "向客户IT团队演示ERP系统功能",
  "location": "ABC科技会议室A",
  "eventType": "03",
  "startTime": "2026-03-22T10:00:00Z",
  "endTime": "2026-03-22T12:00:00Z",
  "isAllDay": false,
  "recurrenceType": "N",
  "relatedType": "OP",
  "relatedId": "uuid-opportunity",
  "reminderMinutes": 15
}
```
