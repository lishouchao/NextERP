# CRM 销售管道与分析设计

**模块**: Sales Pipeline & Analytics (销售管道与分析)
**对标**: Salesforce Pipeline / SAP CRM Analytics
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

销售管道与分析负责销售绩效跟踪与预测：

| 功能 | 说明 | 对标 |
|------|------|------|
| 销售管道 | 管道阶段分析 | Pipeline Analysis |
| 销售配额 | 目标设定与管理 | Sales Quota |
| 营销活动 | 市场活动管理 | Campaign Management |
| 竞争对手 | 竞争分析 | Competitor Analysis |
| 销售团队 | 团队组织管理 | Sales Team |

## 3. 销售配额管理

### 3.1 配额字段 (crm_sales_quota)

| 字段 | 类型 | 说明 | 对标 |
|------|------|------|------|
| company_id | UUID | 公司 | Company |
| sales_org_id | UUID | 销售组织 | Sales Org |
| owner_id | UUID | 负责人 | Owner |
| team_id | UUID | 销售团队 | Team |

## 4. 营销活动管理

### 4.1 活动字段 (crm_campaign)

| 字段 | 类型 | 说明 | 对标 |
|------|------|------|------|
| campaign_number | VARCHAR(10) | 活动编号 | Campaign ID |
| campaign_name | VARCHAR(100) | 活动名称 | Name |
| description | TEXT | 描述 | Description |
| campaign_type | VARCHAR(2) | 活动类型 | Type |
| campaign_status | VARCHAR(2) | 活动状态 | Status |
| start_date | DATE | 开始日期 | Start |
| end_date | DATE | 结束日期 | End |
| budget | DECIMAL(15,2) | 预算 | Budget |
| actual_cost | DECIMAL(15,2) | 实际成本 | Actual Cost |
| target_leads | INTEGER | 目标线索数 | Target Leads |
| target_opportunities | INTEGER | 目标商机数 | Target Opps |
| target_revenue | DECIMAL(15,2) | 目标收入 | Target Revenue |
| actual_leads | INTEGER | 实际线索数 | Actual Leads |
| actual_opportunities | INTEGER | 实际商机数 | Actual Opps |
| actual_revenue | DECIMAL(15,2) | 实际收入 | Actual Revenue |
| owner_id | UUID | 负责人 | Owner |

### 4.2 活动类型

| 类型 | 代码 | 说明 | 特点 |
|------|------|------|------|
| 展会 | 01 | 行业展会 | 线下、高成本 |
| 网络营销 | 02 | 数字营销 | 线上、可追踪 |
| 邮件营销 | 03 | 邮件推广 | 低成本、批量 |
| 电话营销 | 04 | 电话推广 | 直接、高接触 |
| 社交媒体 | 05 | 社交推广 | 互动性、传播快 |

### 4.3 活动状态

| 状态 | 代码 | 说明 | 操作 |
|------|------|------|------|
| 计划 | 01 | 计划中 | 编辑、开始 |
| 进行中 | 02 | 执行中 | 跟踪、完成 |
| 已完成 | 03 | 已结束 | 查看、分析 |
| 取消 | 04 | 已取消 | 查看 |
