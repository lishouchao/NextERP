# CRM 模块 - 客户关系管理

**对标**: Salesforce / SAP CRM
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 模块概述

CRM (Customer Relationship Management) 模块负责管理企业与客户的完整生命周期，从线索获取到成交再到客户维护，提供全方位的客户关系管理能力。

### 核心能力

| 能力 | 说明 | 对标 |
|------|------|------|
| 线索管理 | 线索获取、评分、转化 | Salesforce Lead |
| 商机管理 | 销售机会全生命周期 | Salesforce Opportunity |
| 客户360° | 客户全景视图 | SAP Customer 360 |
| 活动管理 | 任务、日程、交互记录 | Salesforce Activity |
| 销售管道 | 管道分析与销售预测 | Salesforce Pipeline |

## 枚举值参考

### 线索状态

| 代码 | 说明 |
|------|------|
| 01 | 新建 |
| 02 | 已联系 |
| 03 | 合格 |
| 04 | 不合格 |
| 05 | 已转化 |
| 06 | 已关闭 |

### 线索等级

| 代码 | 说明 | 评分范围 |
|------|------|----------|
| A | 优秀 | 80-100 |
| B | 良好 | 60-79 |
| C | 一般 | 40-59 |
| D | 较差 | 0-39 |

### 商机阶段

| 代码 | 说明 | 成功概率 |
|------|------|----------|
| 01 | 初步接触 | 10% |
| 02 | 需求确认 | 20% |
| 03 | 方案演示 | 40% |
| 04 | 商务谈判 | 60% |
| 05 | 合同审批 | 80% |
| 06 | 赢单 | 100% |
| 07 | 输单 | 0% |

### 客户等级

| 代码 | 说明 | RFM特征 |
|------|------|---------|
| 01 | 钻石 | R近、F高、M高 |
| 02 | 白金 | R较近、F较高、M较高 |
| 03 | 金 | R一般、F一般、M一般 |
| 04 | 银 | R较远、F较低、M较低 |
| 05 | 铜 | R远、F低、M低 |

### 客户生命周期

| 代码 | 说明 | 特征 |
|------|------|------|
| 01 | 潜在 | 尚未成交 |
| 02 | 新客户 | 首次成交 |
| 03 | 活跃 | 持续购买 |
| 04 | 忠诚 | 高频高价 |
| 05 | 流失风险 | 购买减少 |
| 06 | 流失 | 停止购买 |
