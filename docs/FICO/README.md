## 核心概念

### FI 财务会计

| 概念 | 说明 | SAP 对标 |
|------|------|----------|
| 公司代码 | 法人实体/独立核算单位 | T001 |
| 会计科目表 | 科目主数据集合 | SKA1 |
| 会计凭证 | 记账凭证 | BKPF/BSEG |
| 总账余额 | 科目余额 | GLT0/FAGLFLEXT |
| 会计期间 | 过账期间控制 | T001B |

### CO 管理会计

| 概念 | 说明 | SAP 对标 |
|------|------|----------|
| 成本控制范围 | 管理会计核算范围 | TKA01 |
| 成本中心 | 成本归集单元 | CSKS |
| 利润中心 | 利润归集单元 | CEPC |
| 成本要素 | 成本分类 | CSKA/CSKB |
| 功能范围 | 成本功能分类 | TFKB |
