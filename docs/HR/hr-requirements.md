## 1. 文档概述

### 1.1 目的

本文档定义 NextERP 人力资源 (HR) 模块的功能需求，以 SAP S/4HANA HCM 为对标产品，结合中国企业人力资源管理特点，构建完整的人力资源管理系统。

### 1.2 适用范围

- 中大型企业 (500-50000人)
- 多组织、多地域集团化企业
- 需要合规性管理的在华企业

### 1.3 术语定义

| 术语 | 英文 | 定义 |
|------|------|------|
| 信息类型 | Infotype | SAP 中按有效期管理的员工数据单元 |
| 人事措施 | Personnel Action | 触发员工状态变更的业务流程 |
| 组织单位 | Organizational Unit | 组织架构中的节点 (公司/部门/小组) |
| 职位 | Position | 组织中的具体岗位，可由人员持有 |
| 职务 | Job | 职位的分类描述，可复用 |
| 工作中心 | Work Center | 工作地点或成本归属点 |
| 薪资范围 | Payroll Area | 薪资核算的分组单位 |

### 1.4 参考文档

- SAP S/4HANA HCM 官方文档
- 《企业人力资源管理实务》
- 《中华人民共和国劳动法》
- 《个人所得税法》及相关规定

## 3. 组织管理 (OM)

> 对标 SAP 事务码: PPOME, PPOCE, PPOSE, PO10, PO13

### 3.1 组织架构管理

#### 3.1.1 功能描述

提供可视化的组织架构管理，支持多层级组织结构的创建、维护和查询。

#### 3.1.2 组织单位 (Organizational Unit)

| 属性 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 组织编码 | String(20) | 是 | 唯一标识 |
| 组织名称 | String(100) | 是 | 组织单位名称 |
| 组织简称 | String(50) | 否 | 简称 |
| 上级组织 | FK | 否 | 父组织单位 |
| 组织类型 | Enum | 是 | 公司/分公司/部门/中心/小组/项目组 |
| 组织级别 | Integer | 自动 | 层级深度 |
| 负责人 | FK | 否 | 组织负责人 (员工) |
| 成立日期 | Date | 是 | 生效日期 |
| 撤销日期 | Date | 否 | 失效日期 |
| 成本中心 | FK | 否 | 关联财务成本中心 |
| 法人实体 | FK | 否 | 关联法人公司 |
| 地理位置 | String(200) | 否 | 办公地点 |
| 状态 | Enum | 是 | 规划中/运营中/已撤销 |
| 排序号 | Integer | 否 | 显示顺序 |

#### 3.1.3 功能列表

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 组织树展示 | 树形结构展示组织架构 | P0 |
| 组织创建 | 新建组织单位 | P0 |
| 组织编辑 | 修改组织信息 | P0 |
| 组织撤销 | 设置失效日期，保留历史 | P0 |
| 组织合并 | 多个组织合并为一个 | P2 |
| 组织拆分 | 一个组织拆分为多个 | P2 |
| 组织调整 | 变更上级组织 | P1 |
| 批量导入 | Excel 批量导入组织 | P1 |
| 组织图导出 | 导出组织架构图 | P2 |
| 版本管理 | 记录组织变更历史 | P2 |

#### 3.1.4 业务规则

1. 组织编码全局唯一，不可重复
2. 组织单位必须有唯一的上级 (根组织除外)
3. 组织层级最多支持 10 级
4. 撤销组织前需确认无下属员工和子组织
5. 组织变更需要审批流程 (可配置)
6. 组织调整时自动更新下属员工的 IT0001 记录

### 3.2 职位管理

#### 3.2.1 功能描述

管理组织中的具体岗位，职位可由员工持有，支持一人多岗。

#### 3.2.2 职位 (Position)

| 属性 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 职位编码 | String(20) | 是 | 唯一标识 |
| 职位名称 | String(100) | 是 | 职位名称 |
| 所属职务 | FK | 是 | 关联职务 |
| 所属组织 | FK | 是 | 所属组织单位 |
| 持有人 | FK | 否 | 当前持有人 (员工) |
| 编制数 | Integer | 否 | 该职位可容纳人数 |
| 空缺数 | Integer | 自动 | 当前空缺 |
| 工作中心 | FK | 否 | 工作地点 |
| 成本中心 | FK | 否 | 成本归属 |
| 生效日期 | Date | 是 | 开始日期 |
| 失效日期 | Date | 否 | 结束日期 |
| 状态 | Enum | 是 | 空缺/已填/冻结/撤销 |
| 职位描述 | Text | 否 | 岗位职责说明 |

#### 3.2.3 功能列表

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 职位创建 | 在组织下创建职位 | P0 |
| 职位编辑 | 修改职位信息 | P0 |
| 职位分配 | 将职位分配给员工 | P0 |
| 职位撤销 | 标记为失效 | P0 |
| 编制管理 | 设置和监控编制 | P1 |
| 一人多岗 | 支持员工兼任多职位 | P1 |
| 职位复制 | 复制职位创建新职位 | P2 |

#### 3.2.4 业务规则

1. 职位编码全局唯一
2. 职位必须关联职务和组织单位
3. 职位持有人变更时自动更新 IT0001
4. 支持一人持有多个职位 (主职/兼职)
5. 编制控制可配置是否启用

### 3.3 职务管理

#### 3.3.1 功能描述

管理可复用的职务分类，职务是职位的基础描述。

#### 3.3.2 职务 (Job)

| 属性 | 类型 | 必填 | 说明 |

| 职务名称 | String(100) | 是 | 职务名称 |
| 职务分类 | FK | 是 | 职务类别 |
| 职务等级 | FK | 否 | 职级体系 |
| 任职要求 | Text | 否 | 任职资格说明 |
| 岗位职责 | Text | 否 | 职责描述 |
| 状态 | Enum | 是 | 有效/失效 |

```
│   ├── 专家 (P8)

│   └── 助理
└── 操作类 (O)
    ├── 高级技工
    ├── 技工
    └── 普工
```

### 3.4 编制管理

#### 3.4.1 功能描述

管理人员编制预算，支持编制申请、审批、监控。

#### 3.4.2 编制记录

| 属性 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 编制ID | String(20) | 是 | 唯一标识 |
| 组织/职位 | FK | 是 | 关联组织或职位 |
| 年度 | Integer | 是 | 预算年度 |
| 预算编制 | Integer | 是 | 计划人数 |
| 实际人数 | Integer | 自动 | 当前在职 |
| 冻结数 | Integer | 否 | 冻结编制 |
| 生效日期 | Date | 是 | 开始日期 |
| 审批状态 | Enum | 是 | 草稿/待审/已批 |

#### 3.4.3 编制控制规则

1. 招聘时可配置是否检查编制
2. 超编招聘需要特批
3. 冻结编制不可新增人员
4. 支持临时编制 (项目制)

#### 4.1.4 有效期管理规则

1. 每条记录有开始日期 (BEGDA) 和结束日期 (ENDDA)
2. 当前有效记录的结束日期为 9999-12-31
3. 新记录插入时会自动分隔已有记录
4. 不允许时间重叠
5. 历史记录不可修改，只能查看

### 4.2 人事措施

#### 4.2.1 功能描述

人事措施是触发员工状态变更的标准化业务流程，一个措施会同时更新多个信息类型。

#### 4.2.2 标准措施类型

| 措施类型 | 编码 | 触发场景 | 更新的信息类型 |
|----------|------|----------|----------------|
| 录用 | HIRE | 新员工入职 | IT0000, IT0001, IT0002, IT0006, IT0007, IT0008, IT0016, IT0105 |
| 离职 | TERM | 员工离职 | IT0000, IT0001(结束) |
| 调动 | TRANS | 部门调动 | IT0000, IT0001 |
| 晋升 | PROM | 职位晋升 | IT0000, IT0001, IT0008 |
| 降职 | DEMO | 职位降级 | IT0000, IT0001, IT0008 |
| 转正 | CONF | 试用期转正 | IT0000 |
| 合同续签 | RENEW | 合同到期续签 | IT0016 |
| 停薪留职 | SUSP | 长期休假 | IT0000, IT0001 |
| 复职 | REIN | 停薪留职后复职 | IT0000, IT0001 |
| 退休 | RETI | 员工退休 | IT0000, IT0001 |
| 死亡 | DEAT | 员工死亡 | IT0000, IT0001 |

```
│                    人事措施执行流程                              │
├─────────────────────────────────────────────────────────────────┤
```

### 6.4 个人所得税

#### 6.4.1 计算方法

采用**累计预扣法**:

```
累计应纳税所得额 = 累计收入 - 累计免税收入 - 累计减除费用
                  - 累计专项扣除 - 累计专项附加扣除 - 累计其他扣除

本期应扣税额 = (累计应纳税所得额 × 税率 - 速算扣除数) - 累计已扣税额
```

#### 6.4.2 税率表 (2024年)

| 级数 | 累计预扣预缴应纳税所得额 | 税率 | 速算扣除数 |
|------|--------------------------|------|------------|

| 2 | 超过 36,000 元至 144,000 元 | 10% | 2,520 |
| 3 | 超过 144,000 元至 300,000 元 | 20% | 16,920 |
| 4 | 超过 300,000 元至 420,000 元 | 25% | 31,920 |
| 5 | 超过 420,000 元至 660,000 元 | 30% | 52,920 |
| 6 | 超过 660,000 元至 960,000 元 | 35% | 85,920 |
| 7 | 超过 960,000 元 | 45% | 181,920 |

## 11. 非功能性需求

### 11.1 性能要求

| 指标 | 要求 | 说明 |
|------|------|------|
| 页面响应 | < 2秒 | 95% 请求 |
| 报表生成 | < 30秒 | 1万条记录 |
| 薪资核算 | < 10分钟 | 5000人 |
| 并发用户 | 500+ | 同时在线 |
| 数据量 | 100万+ | 员工记录 |

### 11.2 安全要求

- 数据加密: 敏感数据加密存储
- 访问控制: 基于角色的权限控制 (RBAC)
- 操作日志: 关键操作审计追踪
- 数据脱敏: 导出数据敏感字段脱敏
- 传输加密: HTTPS/TLS

### 11.3 可用性要求

- 系统可用性: 99.9%
- 数据备份: 每日备份，保留 30 天
- 灾难恢复: RTO < 4 小时，RPO < 1 小时

### 11.4 合规性要求

- 劳动法合规
- 个人信息保护法 (PIPL)
- 数据留存期限
- 等保三级要求
