# MM 库存管理设计

**模块**: Inventory Management (库存管理)
**对标**: SAP MM - Inventory Management (MSEG/MARD/MKPF)
**版本**: 1.0
**更新日期**: 2026-03-14

## 1. 概述

### 1.1 功能范围

库存管理负责物料的收发存管理：

| 功能 | 说明 | SAP 对标 |
|------|------|----------|
| 收货 | 采购收货、生产入库、其他入库 | MIGO |
| 发货 | 领料出库、销售发货、其他出库 | MIGO/MB1A |
| 转储 | 工厂间、存储地点间、批次间转移 | MB1B |
| 盘点 | 实物盘点、盘点差异处理 | MI01/MI04/MI07 |
| 预留 | 生产预留、维护预留 | MB21/MB22 |
| 库存查询 | 实时库存、库存概览 | MMBE/MB52 |

## 2. 库存类型

### 2.1 库存状态

| 状态 | 说明 | 特点 |
|------|------|------|
| UR (非限制使用) | 可用于任何目的 | 正常生产/销售可用 |
| QC (质量检验) | 等待检验结果 | 不可用于生产/销售 |
| BL (冻结) | 因质量问题冻结 | 不可使用 |
| RE (退货) | 客户退货库存 | 等待处理 |

### 2.2 特殊库存

| 类型 | 名称 | 说明 |
|------|------|------|
| K | 客户寄售 | 寄售在客户地点的库存 |
| V | 供应商寄售 | 供应商寄售在本公司的库存 |
| O | 订单库存 | 销售订单专用库存 |
| E | 单个客户库存 | 为特定客户预留的库存 |
| Q | 项目库存 | WBS元素项目库存 |
| W | 估值项目库存 | 需要单独估值的项目库存 |

### 2.3 库存层级

```
库存层级结构:
┌─────────────────────────────────────────────────────────────────┐

│              └─ 批次 (如启用批次管理)                           │
│                  └─ 特殊库存 (如有)                             │

```

## 8. 库存价值

### 8.1 价值更新

```
库存价值更新逻辑:
┌─────────────────────────────────────────────────────────────────┐
│ 标准价 (S)                                                      │
├─────────────────────────────────────────────────────────────────┤
│ 收货:                                                           │
│   库存 = 库存 + (标准价 × 数量)                                 │
│   价格差异 = (实际价 - 标准价) × 数量                           │
│                                                                 │
│ 发货:                                                           │
│   库存 = 库存 - (标准价 × 数量)                                 │
│   无价格差异                                                    │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ 移动平均价 (V)                                                  │
├─────────────────────────────────────────────────────────────────┤
│ 收货 (库存 > 0):                                                │
│   新MAP = (库存价值 + 收货价值) / (库存数量 + 收货数量)         │
│   库存 = 库存 + 收货数量                                        │
│   库存价值 = 库存价值 + 收货价值                                │
│                                                                 │
│ 收货 (库存 = 0):                                                │
│   MAP = 收货价格                                                │
│                                                                 │
│ 发货:                                                           │
│   库存 = 库存 - 数量                                            │
│   库存价值 = 库存价值 - (MAP × 数量)                            │
│   MAP 不变                                                      │
└─────────────────────────────────────────────────────────────────┘
```
