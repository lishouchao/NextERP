# MM 发票校验设计

**模块**: Invoice Verification (发票校验)
**对标**: SAP MM - LIV (Logistics Invoice Verification)
**版本**: 1.0
**更新日期**: 2026-03-14

---

## 1. 概述

### 1.1 功能范围

发票校验是采购流程的最后环节，连接物料管理 (MM) 和财务会计 (FI)：

| 功能 | 说明 | SAP 对标 |
|------|------|----------|
| 发票录入 | 录入供应商发票 | MIRO |
| 发票校验 | 三单匹配验证 | MIRO |
| 发票审批 | 差异审批流程 | MRBR |
| 发票过账 | 生成FI凭证 | MIRO |
| 发票冲销 | 取消错误发票 | MR8M |
| 贷项凭证 | 处理退货/折扣 | MIRO |

## 3. 三单匹配

### 3.1 匹配逻辑

```
三单匹配验证:
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   采购订单 (PO)                                                 │
│       │                                                         │
│       │ 订单数量、单价                                          │
│       │                                                         │
│       ▼                                                         │
│   收货凭证 (GR)                                                 │
│       │                                                         │
│       │ 收货数量                                                │
│       │                                                         │
│       ▼                                                         │
│   发票 (Invoice)                                                │
│       │                                                         │
│       └── 验证: 数量 × 单价 = 发票金额                          │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│ 匹配类型:                                                       │
│                                                                 │
│ 1. 订单匹配: 发票数量 ≤ 订单数量                                │
│ 2. 收货匹配: 发票数量 ≤ 已收货数量                              │
│ 3. 价格匹配: 发票单价 ≤ 订单单价 + 容差                         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 匹配结果

| 状态 | 说明 | 处理 |
|------|------|------|
| 绿灯 | 完全匹配 | 自动过账 |
| 黄灯 | 在容差范围内 | 警告，可过账 |
| 红灯 | 超出容差 | 冻结，需审批 |

### 3.3 容差配置

| 容差类型 | 说明 | 默认值 |
|----------|------|--------|
| 小额差异 | 金额差异 | 1.00 |
| 价格差异 | 价格差异百分比 | 10% |
| 数量差异 | 数量差异百分比 | 10% |
| 日期差异 | 发票日期偏差 | 30天 |

```
容差限制检查:
┌─────────────────────────────────────────────────────────────────┐
│ 检查类型: 价格差异                                              │
├─────────────────────────────────────────────────────────────────┤
│ 订单单价: 100.00 CNY                                            │
│ 发票单价: 105.00 CNY                                            │
│ 差异: 5.00 CNY (5%)                                             │
│                                                                 │
│ 容差限制: 10% = 10.00 CNY                                       │
│ 检查结果: 5% < 10% → 黄灯 (警告)                                │
└─────────────────────────────────────────────────────────────────┘
```

## 5. 发票冻结

### 5.1 冻结原因

| 原因 | 说明 | 触发条件 |
|------|------|----------|
| A | 价格差异 | 价格超出容差 |
| B | 数量差异 | 数量超出容差 |
| C | 金额差异 | 金额超出小额容差 |
| D | 日期差异 | 日期偏差超限 |
| E | 质量问题 | 质量未放行 |
| F | 手工冻结 | 手动冻结 |
| G | 供应商冻结 | 供应商信用问题 |
| H | 订单冻结 | 订单未审批 |

```
发票冲销规则:
┌─────────────────────────────────────────────────────────────────┐
```
