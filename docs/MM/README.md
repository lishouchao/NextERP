## 核心概念

### 物料类型

| 类型 | 说明 | SAP 对标 |
|------|------|----------|
| ROH | 原材料 | MARA-MTART |
| HALB | 半成品 | MARA-MTART |
| FERT | 成品 | MARA-MTART |
| VERP | 包装材料 | MARA-MTART |
| DIEN | 服务 | MARA-MTART |

### 库存状态

| 状态 | 说明 | 标识 |
|------|------|------|
| 非限制 | 可用库存 | UR |
| 质检 | 检验中 | QC |
| 冻结 | 不可用 | BL |
| 退货 | 客户退货 | RE |

### 价格控制

| 类型 | 说明 | 特点 |
|------|------|------|
| S | 标准价 | 固定价格，差异计入价格差异科目 |
| V | 移动平均价 | 实际价格，随采购价变动 |
