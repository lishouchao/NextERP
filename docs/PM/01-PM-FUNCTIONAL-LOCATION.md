# PM 功能位置管理设计

**模块**: Functional Location Management (功能位置管理)
**对标**: SAP PM - IL01/IL02/IL03
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

功能位置管理负责设备安装位置的定义与层级管理：

| 功能 | 说明 | SAP 对标 |
|------|------|----------|
| 功能位置创建 | 创建功能位置 | IL01 |
| 功能位置修改 | 修改功能位置 | IL02 |
| 功能位置显示 | 查看功能位置 | IL03 |
| 层级管理 | 管理位置层级 | IL01 |
| 设备安装 | 安装设备到位置 | IE02 |

## 2. 功能位置主数据

### 2.1 功能位置字段 (对标 SAP IFLOT)

| 字段 | 类型 | 说明 | SAP 字段 |
|------|------|------|----------|
| location_code | VARCHAR(12) | 功能位置代码 | TPLNR |
| description | VARCHAR(100) | 描述 | PLTXT |
| parent_id | UUID | 上级位置 | TPLMA |
| level | INTEGER | 层级 | LEVEL |
| path | VARCHAR(200) | 层级路径 | - |
| plant_id | UUID | 工厂 | WERKS |
| cost_center_id | UUID | 成本中心 | KOSTL |
| category | VARCHAR(2) | 功能位置类别 | FLTYP |
| location_status | VARCHAR(2) | 位置状态 | - |
| is_active | BOOLEAN | 是否激活 | - |

### 2.2 功能位置类别

```

│   01    建筑物      厂房、建筑物        顶层 (Level 1)                      │
│   02    系统        生产系统、装置      第二层 (Level 2)                    │
```

### 2.3 功能位置状态

| 状态 | 代码 | 说明 | 影响 |
|------|------|------|------|
| 安装 | 01 | 正常安装 | 可安装设备 |
| 拆除 | 02 | 已拆除 | 不可安装设备 |
| 停用 | 03 | 停用 | 不可使用 |

## 6. 接口设计

### 6.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/pm/functional-locations | GET | 功能位置列表 |
| /api/pm/functional-locations | POST | 创建功能位置 |
| /api/pm/functional-locations/{id} | GET | 功能位置详情 |
| /api/pm/functional-locations/{id} | PUT | 更新功能位置 |
| /api/pm/functional-locations/{id} | DELETE | 删除功能位置 |
| /api/pm/functional-locations/{id}/hierarchy | GET | 获取层级结构 |
| /api/pm/functional-locations/{id}/install | POST | 安装设备 |
| /api/pm/functional-locations/{id}/dismantle | POST | 拆除设备 |
| /api/pm/functional-locations/{id}/equipment | GET | 已安装设备 |

### 6.2 创建功能位置请求

```json
{
  "locationCode": "1000-A-01-01-01",
  "description": "包装机1",
  "parentId": "uuid-parent",
  "category": "04",
  "plantId": "uuid-plant",
  "costCenterId": "uuid-cost-center"
}
```

### 6.3 安装设备请求

```json
{
  "equipmentId": "uuid-equipment",
  "installationDate": "2026-03-16"
}
```
