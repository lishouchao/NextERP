# PM 设备主数据管理设计

**模块**: Equipment Master Data Management (设备主数据管理)
**对标**: SAP PM - IE01/IE02/IE03
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

设备主数据管理负责企业设备档案的全生命周期管理：

| 功能 | 说明 | SAP 对标 |
|------|------|----------|
| 设备创建 | 创建设备档案 | IE01 |
| 设备修改 | 修改设备信息 | IE02 |
| 设备显示 | 查看设备详情 | IE03 |
| 设备分类 | 设备类型管理 | CL02 |
| 技术参数 | 设备技术数据 | IE02 |

## 2. 设备主数据

| equipment_number | VARCHAR(18) | 设备编号 | EQUNR |

| equipment_type | VARCHAR(10) | 设备类型 | EQART |

### 2.3 设备状态

| 状态 | 代码 | 说明 | 影响 |
|------|------|------|------|
| 运行 | 01 | 正常运行 | 可创建维护订单 |
| 停机 | 02 | 计划停机 | 预防性维护 |
| 维修 | 03 | 维修中 | 关联维护订单 |
| 报废 | 04 | 已报废 | 不可创建订单 |

### 2.4 维护策略

| 策略 | 代码 | 说明 | 适用场景 |
|------|------|------|----------|
| 故障维修 | 01 | 故障后维修 | 非关键设备 |
| 预防性维护 | 02 | 定期保养 | 关键设备 |
| 预测性维护 | 03 | 基于状态监测 | 高价值设备 |

## 7. 接口设计

### 7.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/pm/equipment | GET | 设备列表 |
| /api/pm/equipment | POST | 创建设备 |
| /api/pm/equipment/{id} | GET | 设备详情 |
| /api/pm/equipment/{id} | PUT | 更新设备 |
| /api/pm/equipment/{id} | DELETE | 删除设备 |
| /api/pm/equipment/{id}/status | PUT | 更新设备状态 |
| /api/pm/equipment/{id}/install | POST | 安装到功能位置 |
| /api/pm/equipment/{id}/dismantle | POST | 从功能位置拆除 |
| /api/pm/equipment/{id}/history | GET | 维护历史 |
| /api/pm/equipment/classes | GET | 设备分类列表 |
| /api/pm/equipment/classes | POST | 创建设备分类 |
