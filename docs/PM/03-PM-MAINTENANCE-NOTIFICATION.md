# PM 维护通知管理设计

**模块**: Maintenance Notification Management (维护通知管理)
**对标**: SAP PM - IW21/IW22/IW23
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

维护通知管理负责故障报告和维护申请的处理：

| 功能 | 说明 | SAP 对标 |
|------|------|----------|
| 通知创建 | 创建维护通知 | IW21 |
| 通知修改 | 修改维护通知 | IW22 |
| 通知显示 | 查看维护通知 | IW23 |
| 通知处理 | 处理维护通知 | IW22 |
| 转换订单 | 生成维护订单 | IW36 |

## 2. 维护通知主数据

### 2.1 通知字段 (对标 SAP QMEL)

| 字段 | 类型 | 说明 | SAP 字段 |
|------|------|------|----------|
| notification_number | VARCHAR(12) | 通知单号 | QMNUM |
| notification_type | VARCHAR(3) | 通知类型 | QMART |
| short_text | VARCHAR(100) | 简短描述 | QMTXT |
| long_text | TEXT | 详细描述 | - |
| priority | VARCHAR(2) | 优先级 | PRIOK |
| equipment_id | UUID | 设备ID | EQUNR |
| equipment_number | VARCHAR(18) | 设备编号 | EQUNR |
| functional_loc_id | UUID | 功能位置ID | TPLNR |
| functional_loc_code | VARCHAR(12) | 功能位置代码 | TPLNR |
| breakdown_date | TIMESTAMP | 故障时间 | AUSVN |
| breakdown_duration | DECIMAL(8,2) | 停机时长 | AUSBS |
| failure_cause | VARCHAR(4) | 故障原因代码 | OTGRP |
| failure_cause_text | VARCHAR(100) | 故障原因描述 | - |
| failure_effect | VARCHAR(4) | 故障影响代码 | - |
| plant_id | UUID | 工厂ID | WERKS |
| work_center_id | UUID | 工作中心ID | ARBPL |
| order_id | UUID | 关联订单ID | AUFNR |
| reported_date | DATE | 报告日期 | ERDAT |
| due_date | DATE | 截止日期 | - |
| completion_date | DATE | 完成日期 | - |
| notification_status | VARCHAR(2) | 通知状态 | - |
| system_status | VARCHAR(10) | 系统状态 | - |
| reported_by | UUID | 报告人 | ERNAM |
| responsible_id | UUID | 负责人 | - |

### 2.2 通知类型

```
通知类型配置:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   类型  名称        说明                用途                                 │
│   ─────────────────────────────────────────────────────────────────────    │
│   M1    故障报告    设备故障通知        记录故障信息，触发维修             │
│   M2    活动报告    维护活动报告        记录已完成的维护工作               │
│   M3    维护申请    维护需求申请        申请维护资源                       │
│   M4    停机报告    设备停机报告        记录计划/非计划停机                │
│   ─────────────────────────────────────────────────────────────────────    │
│                                                                             │
│   类型特点:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                                                                     │  │
│   │   M1 故障报告:                                                       │  │
│   │   ├── 必须关联设备或功能位置                                         │  │
│   │   ├── 记录故障时间和停机时长                                         │  │
│   │   ├── 可转换为维护订单                                               │  │
│   │   └── 用于故障统计分析                                               │  │
│   │                                                                     │  │
│   │   M2 活动报告:                                                       │  │
│   │   ├── 记录已执行的维护活动                                           │  │
│   │   ├── 可不创建订单直接完成                                           │  │
│   │   └── 用于维护历史记录                                               │  │
│   │                                                                     │  │
│   │   M3 维护申请:                                                       │  │
│   │   ├── 申请维护资源或改造                                             │  │
│   │   ├── 需要审批流程                                                   │  │
│   │   └── 转换为维护订单                                                 │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.3 优先级

| 优先级 | 代码 | 说明 | 响应时间 |
|--------|------|------|----------|
| 紧急 | 1 | 立即处理 | < 1小时 |
| 高 | 2 | 优先处理 | < 4小时 |
| 中 | 3 | 正常处理 | < 24小时 |
| 低 | 4 | 计划处理 | < 72小时 |

### 2.4 通知状态

| 状态 | 代码 | 系统状态 | 说明 |
|------|------|----------|------|
| 创建 | 01 | OSNO | 通知已创建 |
| 处理中 | 02 | NOPC | 正在处理 |
| 完成 | 03 | NOCO | 处理完成 |
| 关闭 | 04 | QUTX | 已关闭 |

## 6. 接口设计

### 6.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/pm/notifications | GET | 通知列表 |
| /api/pm/notifications | POST | 创建通知 |
| /api/pm/notifications/{id} | GET | 通知详情 |
| /api/pm/notifications/{id} | PUT | 更新通知 |
| /api/pm/notifications/{id} | DELETE | 删除通知 |
| /api/pm/notifications/{id}/process | POST | 处理通知 |
| /api/pm/notifications/{id}/complete | POST | 完成通知 |
| /api/pm/notifications/{id}/convert | POST | 转换为订单 |
| /api/pm/notifications/statistics | GET | 故障统计 |

### 6.2 创建通知请求

```json
{
  "notificationType": "M1",
  "shortText": "包装机无法启动，控制面板显示E01错误",
  "longText": "今早开机时发现包装机无法启动，控制面板显示E01错误代码，已检查电源正常，怀疑是控制板故障。",
  "priority": "2",
  "equipmentId": "uuid-equipment",
  "functionalLocId": "uuid-fl",
  "breakdownDate": "2026-03-16T09:30:00Z",
  "breakdownDuration": 2.5,
  "failureCause": "B003",
  "failureCauseText": "控制故障",
  "failureEffect": "E001",
  "plantId": "uuid-plant",
  "reportedBy": "uuid-employee"
}
```
