# PM 预防性维护设计

**模块**: Preventive Maintenance (预防性维护)
**对标**: SAP PM - IP01/IP02/IP03/IP30
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

预防性维护负责定期保养计划的创建与调度：

| 功能 | 说明 | SAP 对标 |
|------|------|----------|
| 维护计划创建 | 创建维护计划 | IP01 |
| 维护计划修改 | 修改维护计划 | IP02 |
| 维护计划显示 | 查看维护计划 | IP03 |
| 计划调度 | 生成维护订单 | IP30 |
| 计划监控 | 查看到期计划 | IP24 |

## 2. 维护计划

### 2.1 计划字段 (对标 SAP MPLA)

| 字段 | 类型 | 说明 | SAP 字段 |
|------|------|------|----------|
| plan_number | VARCHAR(10) | 计划号 | WARPL |
| plan_name | VARCHAR(100) | 计划名称 | PLTXT |
| description | TEXT | 描述 | - |
| plan_type | VARCHAR(2) | 计划类型 | STRAT |
| cycle_length | INTEGER | 周期长度 | KZRIE |
| cycle_unit | VARCHAR(1) | 周期单位 | ZEIEH |
| start_date | DATE | 开始日期 | STRDT |
| end_date | DATE | 结束日期 | ENDDT |
| lead_time | INTEGER | 提前天数 | HOZIT |
| tolerance | INTEGER | 容差天数 | TOBER |
| order_type | VARCHAR(4) | 默认订单类型 | AUART |
| plan_status | VARCHAR(2) | 计划状态 | - |
| is_active | BOOLEAN | 是否激活 | - |

### 2.2 计划类型

```
维护计划类型配置:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   类型  名称          说明                计算方式                           │
│   ─────────────────────────────────────────────────────────────────────    │
│   01    时间基础      按时间周期          日/周/月/年                       │
│   02    性能基础      按运行参数          运行小时/产量/里程                │
│   03    统计基础      按统计数据          故障次数/使用次数                 │
│   ─────────────────────────────────────────────────────────────────────    │
│                                                                             │
│   类型特点:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                                                                     │  │
│   │   01 时间基础:                                                       │  │
│   │   ├── 固定周期维护                                                   │  │
│   │   ├── 周期单位: D(天)/W(周)/M(月)/Y(年)                              │  │
│   │   ├── 示例: 每1个月维护一次                                          │  │
│   │   └── 适用: 常规保养、更换易损件                                     │  │
│   │                                                                     │  │
│   │   02 性能基础:                                                       │  │
│   │   ├── 基于设备运行参数                                               │  │
│   │   ├── 计数器类型: 运行小时/产量/里程                                 │  │
│   │   ├── 示例: 每500运行小时维护一次                                    │  │
│   │   └── 适用: 需要根据使用情况维护的设备                               │  │
│   │                                                                     │  │
│   │   03 统计基础:                                                       │  │
│   │   ├── 基于历史统计数据                                               │  │
│   │   ├── 示例: 每1000次操作维护一次                                     │  │
│   │   └── 适用: 特殊设备                                                 │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.3 周期单位

| 单位 | 代码 | 说明 | 示例 |
|------|------|------|------|
| D | 天 | 按天计算 | 每30天 |
| W | 周 | 按周计算 | 每2周 |
| M | 月 | 按月计算 | 每3月 |
| Y | 年 | 按年计算 | 每1年 |

### 2.4 计划状态

| 状态 | 代码 | 说明 | 影响 |
|------|------|------|------|
| 创建 | 01 | 计划已创建 | 可修改 |
| 激活 | 02 | 计划已激活 | 可调度 |
| 停用 | 03 | 计划已停用 | 不可调度 |

## 3. 维护项目

### 3.1 项目字段 (pm_maintenance_item)

| 字段 | 类型 | 说明 |
|------|------|------|
| plan_id | UUID | 计划ID |
| plan_number | VARCHAR(10) | 计划号 |
| equipment_id | UUID | 设备ID |
| equipment_number | VARCHAR(18) | 设备编号 |
| functional_loc_id | UUID | 功能位置ID |
| functional_loc_code | VARCHAR(12) | 功能位置代码 |
| task_list_id | UUID | 任务清单ID |
| last_completion_date | DATE | 上次完成日期 |
| last_counter_value | DECIMAL(15,2) | 上次计数器值 |
| next_due_date | DATE | 下次到期日 |
| next_call_date | DATE | 下次调用日 |
| counter_type | VARCHAR(2) | 计数器类型 |
| cycle_counter | DECIMAL(15,2) | 周期计数 |
| item_status | VARCHAR(2) | 项目状态 |

### 3.2 计数器类型

| 类型 | 代码 | 说明 | 适用 |
|------|------|------|------|
| 01 | 运行小时 | 累计运行时间 | 机械设备 |
| 02 | 产量 | 累计产量 | 生产设备 |
| 03 | 里程 | 行驶里程 | 运输设备 |

## 4. 调度运行

### 4.1 调度逻辑

```
调度运行流程:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   1. 启动调度                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   └── 选择调度范围 (工厂/计划/日期)                                   │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                          │                                                  │
│                          ▼                                                  │
│   2. 检查到期项目                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                                                                     │  │
│   │   时间基础:                                                          │  │
│   │   ┌─────────────────────────────────────────────────────────────┐  │  │
│   │   │   if (next_call_date <= 当前日期 + lead_time) {              │  │  │
│   │   │       到期 = true;                                            │  │  │
│   │   │   }                                                           │  │  │
│   │   └─────────────────────────────────────────────────────────────┘  │  │
│   │                                                                     │  │
│   │   性能基础:                                                          │  │
│   │   ┌─────────────────────────────────────────────────────────────┐  │  │
│   │   │   if (当前计数器值 >= 下次维护计数器值 - 容差) {              │  │  │
│   │   │       到期 = true;                                            │  │  │
│   │   │   }                                                           │  │  │
│   │   └─────────────────────────────────────────────────────────────┘  │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                          │                                                  │
│                          ▼                                                  │
│   3. 生成维护订单                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                                                                     │  │
│   │   ┌─────────────────────────────────────────────────────────────┐  │  │
│   │   │   订单类型:   计划配置的 order_type (如 PM02)                 │  │  │
│   │   │   设备:       从维护项目获取                                   │  │  │
│   │   │   任务清单:   复制任务清单到订单操作                           │  │  │
│   │   │   计划日期:   next_due_date                                   │  │  │
│   │   └─────────────────────────────────────────────────────────────┘  │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                          │                                                  │
│                          ▼                                                  │
│   4. 更新下次到期日                                                         │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   └── next_due_date = next_due_date + cycle_length                 │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 6. 接口设计

### 6.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/pm/maintenance-plans | GET | 计划列表 |
| /api/pm/maintenance-plans | POST | 创建计划 |
| /api/pm/maintenance-plans/{id} | GET | 计划详情 |
| /api/pm/maintenance-plans/{id} | PUT | 更新计划 |
| /api/pm/maintenance-plans/{id} | DELETE | 删除计划 |
| /api/pm/maintenance-plans/{id}/activate | POST | 激活计划 |
| /api/pm/maintenance-plans/{id}/deactivate | POST | 停用计划 |
| /api/pm/maintenance-plans/{id}/items | GET | 计划项目 |
| /api/pm/maintenance-plans/{id}/items | POST | 添加项目 |
| /api/pm/maintenance-plans/schedule | POST | 运行调度 |
| /api/pm/maintenance-plans/due-items | GET | 到期项目 |

### 6.2 创建计划请求

```json
{
  "planNumber": "MP001",
  "planName": "包装机月度保养",
  "description": "包装机设备月度预防性维护计划",
  "planType": "01",
  "cycleLength": 1,
  "cycleUnit": "M",
  "startDate": "2026-01-01",
  "leadTime": 7,
  "tolerance": 3,
  "orderType": "PM02",
  "items": [
    {
      "equipmentId": "uuid-equipment-1",
      "taskListId": "uuid-task-list"
    },
    {
      "equipmentId": "uuid-equipment-2",
      "taskListId": "uuid-task-list"
    }
  ]
}
```
