# PM 工厂维护模块

**模块**: Plant Maintenance (工厂维护/设备管理)
**对标**: SAP ECC PM

## 模块概述

PM模块是NextERP的设备管理与维护核心模块，负责管理企业资产的全生命周期维护。

## 核心业务流程

### 纠正性维护流程

1. **故障报告**: 创建故障通知 (M1)
2. **评估分派**: 维护主管评估并分配
3. **创建订单**: 将通知转换为维护订单 (PM01)
4. **执行维修**: 领料、执行操作、记录工时
5. **完成确认**: 技术完成、成本结算

### 预防性维护流程

1. **创建计划**: 定义周期、设备、任务清单
2. **激活计划**: 系统自动计算下次维护日期
3. **调度运行**: 到期自动生成维护订单
4. **执行维护**: 执行订单并确认完成
5. **更新计划**: 更新下次到期日期

## 模块集成

- **PP 模块**: 工作中心、生产订单
- **MM 模块**: 物料领用、备件管理
- **AM 模块**: 固定资产关联
- **CO 模块**: 成本核算、结算
- **HR 模块**: 员工、责任人
