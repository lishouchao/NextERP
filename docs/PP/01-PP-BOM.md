# PP 物料清单管理设计

**模块**: Bill of Material Management (物料清单管理)
**对标**: SAP PP - CS01/CS02/CS03
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

BOM管理负责产品结构的定义与维护：

| 功能 | 说明 | SAP 对标 |
|------|------|----------|
| BOM创建 | 创建物料清单 | CS01 |
| BOM修改 | 修改BOM项目 | CS02 |
| BOM显示 | 查看BOM结构 | CS03 |
| BOM删除 | 删除BOM | CS02 |
| BOM复制 | 复制现有BOM | CS01 |
| BOM展开 | 展开BOM层级 | CS11/CS12 |

## 2. BOM头管理

### 2.1 BOM头字段 (对标 SAP MAST)

| 字段 | 类型 | 说明 | SAP 字段 |
|------|------|------|----------|
| bom_number | VARCHAR(10) | BOM号 | STNUM |
| bom_type | VARCHAR(1) | BOM类型 | STLAN |
| material_id | UUID | 物料ID | MATNR |
| material_code | VARCHAR(18) | 物料编码 | MATNR |
| plant_id | UUID | 工厂 | WERKS |
| description | VARCHAR(100) | 描述 | KTEXT |
| base_qty | DECIMAL(13,3) | 基本数量 | BMENG |
| base_unit | VARCHAR(3) | 基本单位 | BMEIN |
| bom_status | VARCHAR(2) | BOM状态 | STTAS |
| valid_from | DATE | 有效开始 | DATUV |
| valid_to | DATE | 有效结束 | DATUB |

### 2.2 BOM类型

### 2.3 BOM用途

| 用途 | 代码 | 说明 | 影响 |
|------|------|------|------|
| 生产 | 1 | 生产订单使用 | 默认用途 |
| 工程 | 2 | 工程设计 | 设计参考 |
| 成本 | 3 | 成本核算 | 成本估算 |

## 3. BOM项目管理

### 3.1 BOM项目字段 (对标 SAP STPO)

| 字段 | 类型 | 说明 | SAP 字段 |
|------|------|------|----------|
| item_number | VARCHAR(4) | 项目编号 | POSNR |
| item_category | VARCHAR(1) | 项目类别 | POSTP |
| material_id | UUID | 组件物料 | IDNRK |
| material_code | VARCHAR(18) | 组件编码 | IDNRK |
| description | VARCHAR(100) | 组件描述 | OJTXP |
| component_qty | DECIMAL(13,3) | 组件数量 | MENGE |
| unit | VARCHAR(3) | 单位 | MEINS |
| is_fixed_qty | BOOLEAN | 固定数量 | FMENG |
| scrap_factor | DECIMAL(5,2) | 废品率 | AUSCH |
| production_plant | UUID | 生产工厂 | WEKRS |
| is_phantom | BOOLEAN | 虚拟件 | VPNK |
| is_bulk | BOOLEAN | 散装物料 | SCHGT |
| is_co_product | BOOLEAN | 联产品 | KZKUP |

### 3.3 组件数量计算

```
组件数量计算:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   基本公式:                                                                 │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                                                                     │  │
│   │   组件需求数量 = (订单数量 / BOM基本数量) × 组件数量                  │  │
│   │                 × (1 + 废品率/100)                                  │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   计算示例:                                                                 │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                                                                     │  │
│   │   BOM定义:                                                           │  │
│   │   成品: FGD-001    基本数量: 100 EA                                  │  │
│   │   组件: CMP-001    组件数量: 2 EA    废品率: 5%                       │  │
│   │                                                                     │  │
│   │   生产订单数量: 500 EA                                               │  │
│   │                                                                     │  │
│   │   组件需求 = (500 / 100) × 2 × 1.05                                 │  │
│   │            = 10.5 EA                                                │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   固定数量项目:                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                                                                     │  │
│   │   如果 is_fixed_qty = TRUE:                                          │  │
│   │   组件需求数量 = 固定数量值 (不随订单数量变化)                        │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.2 多层展开

```
多层BOM展开 (CS12):
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   Level  项目    物料      描述        数量    单位    父物料               │
│   ─────────────────────────────────────────────────────────────────────    │
│    0     0000   FGD-001   成品        1.000   EA      -                    │
│    1     0010   CMP-001   组件A        2.000   EA      FGD-001             │
│    2     0010   SUB-001   子件1        4.000   EA      CMP-001             │
│    2     0020   SUB-002   子件2        2.000   EA      CMP-001             │
│    1     0020   CMP-002   组件B        1.000   EA      FGD-001             │
│    2     0010   SUB-003   子件3        3.000   EA      CMP-002             │
│    1     0030   CMP-003   辅料         0.500   KG      FGD-001             │
│   ─────────────────────────────────────────────────────────────────────    │
│                                                                             │
│   总需求:                                                                   │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   SUB-001: 2 × 2 = 4 EA                                             │  │
│   │   SUB-002: 2 × 1 = 2 EA                                             │  │
│   │   SUB-003: 1 × 3 = 3 EA                                             │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 5. 特殊BOM项目

### 5.1 虚拟件

```
虚拟件 (Phantom Item):
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   定义: 虚拟件是一个逻辑上的组件组合，不进行库存管理                           │
│                                                                             │
│   特点:                                                                     │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   1. 不创建库存记录                                                   │  │
│   │   2. 需求直接传递到下层组件                                           │  │
│   │   3. 用于简化BOM结构                                                  │  │
│   │   4. 常用于标准化组件组合                                             │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   示例:                                                                     │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                                                                     │  │
│   │   成品 (FGD-001)                                                    │  │
│   │       └── 虚拟件 (ASSY-001) is_phantom = TRUE                       │  │
│   │              ├── 螺丝 (SCR-001)                                     │  │
│   │              ├── 螺母 (NUT-001)                                     │  │
│   │              └── 垫片 (WAS-001)                                     │  │
│   │                                                                     │  │
│   │   生产时: 虚拟件不产生库存记录，需求直接传给螺丝/螺母/垫片            │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 5.2 联产品

```
联产品 (Co-Product):
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   定义: 同一生产过程中产生的多个有价值产品                                    │
│                                                                             │
│   特点:                                                                     │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   1. 具有独立库存价值                                                │  │
│   │   2. 成本按比例分摊                                                  │  │
│   │   3. 都可销售                                                        │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   示例 (石化行业):                                                          │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                                                                     │  │
│   │   原油加工 → 汽油 (主产品)                                           │  │
│   │            → 柴油 (联产品)                                           │  │
│   │            → 沥青 (联产品)                                           │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 6. BOM变更管理

### 6.1 变更类型

```
BOM变更类型:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   变更类型          影响            处理方式                                │
│   ─────────────────────────────────────────────────────────────────────    │
│   新增项目          新增组件        直接添加新项目                          │
│   删除项目          移除组件        设置删除标志                            │
│   修改数量          改变用量        修改数量字段                            │
│   替换物料          组件替代        结束旧项目，添加新项目                  │
│   ─────────────────────────────────────────────────────────────────────    │
│                                                                             │
│   变更控制:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                                                                     │  │
│   │   1. 有效期控制                                                      │  │
│   │      - valid_from: 变更生效日期                                      │  │
│   │      - valid_to: 变更失效日期                                        │  │
│   │                                                                     │  │
│   │   2. 工程变更管理 (ECM)                                              │  │
│   │      - 变更号                                                        │  │
│   │      - 变更原因                                                      │  │
│   │      - 变更审批                                                      │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 7. 接口设计

### 7.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/pp/boms | GET | BOM列表 |
| /api/pp/boms | POST | 创建BOM |
| /api/pp/boms/{id} | GET | BOM详情 |
| /api/pp/boms/{id} | PUT | 更新BOM |
| /api/pp/boms/{id} | DELETE | 删除BOM |
| /api/pp/boms/{id}/items | GET | BOM项目列表 |
| /api/pp/boms/{id}/items | POST | 添加BOM项目 |
| /api/pp/boms/{id}/items/{itemId} | PUT | 更新BOM项目 |
| /api/pp/boms/{id}/items/{itemId} | DELETE | 删除BOM项目 |
| /api/pp/boms/{id}/explode | GET | BOM展开 |
| /api/pp/boms/where-used/{materialId} | GET | 反查使用 |

### 7.2 创建BOM请求

```json
{
  "bomType": "1",
  "materialId": "uuid-material",
  "materialCode": "FGD-001",
  "plantId": "uuid-plant",
  "description": "成品BOM",
  "baseQty": 100,
  "baseUnit": "EA",
  "validFrom": "2026-03-01",
  "validTo": "9999-12-31",
  "items": [
    {
      "itemNumber": "0010",
      "itemCategory": "L",
      "materialId": "uuid-component-1",
      "materialCode": "CMP-001",
      "description": "组件A",
      "componentQty": 2.0,
      "unit": "EA",
      "scrapFactor": 5.0
    }
  ]
}
```
