# PP 工作中心管理设计

**模块**: Work Center Management (工作中心管理)
**对标**: SAP PP - CR01/CR02
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

工作中心管理负责生产资源的定义与产能管理：

| 功能 | 说明 | SAP 对标 |
|------|------|----------|
| 工作中心创建 | 创建工作中心 | CR01 |
| 工作中心修改 | 修改工作中心 | CR02 |
| 工作中心显示 | 查看工作中心 | CR03 |
| 产能管理 | 定义产能数据 | CR01 |
| 产能评估 | 查看产能负荷 | CM01 |

## 2. 工作中心主数据

### 2.1 工作中心字段 (对标 SAP CRHD)

| 字段 | 类型 | 说明 | SAP 字段 |
|------|------|------|----------|
| work_center_code | VARCHAR(8) | 工作中心代码 | ARBPL |
| work_center_name | VARCHAR(100) | 工作中心名称 | KTEXT |
| work_center_type | VARCHAR(2) | 工作中心类型 | VERWE |
| plant_id | UUID | 所属工厂 | WERKS |
| cost_center_id | UUID | 成本中心 | KOSTL |
| capacity_category | VARCHAR(2) | 产能类别 | KAPAR |
| capacity | DECIMAL(13,3) | 产能 | KAPANZ |
| capacity_unit | VARCHAR(3) | 产能单位 | KAPEH |
| efficiency_factor | DECIMAL(5,2) | 效率因子 | EFFKT |
| operating_time | DECIMAL(8,2) | 运行时间 | - |
| wc_status | VARCHAR(2) | 工作中心状态 | - |

### 2.3 工作中心状态

| 状态 | 代码 | 说明 | 影响 |
|------|------|------|------|
| 可用 | 01 | 正常可用 | 可分配工序 |
| 维护 | 02 | 维护中 | 不分配新工序 |
| 停用 | 03 | 停用 | 不可使用 |

## 3. 产能管理

### 3.1 产能类别

| 类别 | 代码 | 说明 | 计算方式 |
|------|------|------|----------|
| 机器 | 01 | 机器产能 | 设备运行时间 |
| 人员 | 02 | 人员产能 | 工作时间 |
| 生产线 | 03 | 生产线产能 | 节拍时间 |

### 3.2 产能字段 (对标 SAP KAKO)

| 字段 | 类型 | 说明 | SAP 字段 |
|------|------|------|----------|
| work_center_id | UUID | 工作中心ID | OBJID |
| capacity_code | VARCHAR(8) | 产能代码 | KAPAR |
| capacity_name | VARCHAR(100) | 产能名称 | KTEXT |
| capacity_category | VARCHAR(2) | 产能类别 | KAPAR |
| available_capacity | DECIMAL(13,3) | 可用产能 | KAN03 |
| capacity_unit | VARCHAR(3) | 产能单位 | KAPEH |
| start_time | TIME | 开始时间 | BEGZT |
| end_time | TIME | 结束时间 | ENDZT |
| operating_hours | DECIMAL(5,2) | 运行小时数 | KAZEI |
| efficiency_rate | DECIMAL(5,2) | 效率% | EFFZI |
| utilization_rate | DECIMAL(5,2) | 利用率% | AUSLZ |

### 3.3 产能计算

```
产能计算示例:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   工作中心: WC-001 (装配中心)                                                │
│   ─────────────────────────────────────────────────────────────────────    │
│                                                                             │
│   基础数据:                                                                 │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   开始时间:     08:00                                                │  │
│   │   结束时间:     17:00                                                │  │
│   │   休息时间:     1小时                                                │  │
│   │   运行小时:     8小时/天                                             │  │
│   │   效率:         100%                                                 │  │
│   │   利用率:       90%                                                  │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   可用产能计算:                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                                                                     │  │
│   │   日产能 = 运行小时 × 效率 × 利用率                                   │  │
│   │          = 8 × 100% × 90%                                           │  │
│   │          = 7.2 小时/天                                               │  │
│   │                                                                     │  │
│   │   周产能 = 7.2 × 5 = 36 小时/周                                      │  │
│   │   月产能 = 7.2 × 22 = 158.4 小时/月                                  │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 4. 标准值管理

### 4.1 标准值类型

| 类型 | 说明 | 用途 |
|------|------|------|
| 准备时间 (Setup) | 换模、调试时间 | 排程计算 |
| 机器时间 (Machine) | 机器加工时间 | 排程和成本 |
| 人工时间 (Labor) | 人工操作时间 | 排程和成本 |

### 4.2 标准值单位

```
标准值单位配置:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   单位  名称        说明                使用场景                             │
│   ─────────────────────────────────────────────────────────────────────    │
│   MIN    分钟       以分钟计            精确排程                             │
│   HR     小时       以小时计            长工序                               │
│   S      秒         以秒计              高速工序                             │
│   ─────────────────────────────────────────────────────────────────────    │
│                                                                             │
│   换算关系:                                                                  │
│   1 HR = 60 MIN = 3600 S                                                   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 7. 接口设计

### 7.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/pp/work-centers | GET | 工作中心列表 |
| /api/pp/work-centers | POST | 创建工作中心 |
| /api/pp/work-centers/{id} | GET | 工作中心详情 |
| /api/pp/work-centers/{id} | PUT | 更新工作中心 |
| /api/pp/work-centers/{id} | DELETE | 删除工作中心 |
| /api/pp/work-centers/{id}/capacity | GET | 产能信息 |
| /api/pp/work-centers/{id}/capacity | POST | 设置产能 |
| /api/pp/work-centers/{id}/load | GET | 产能负荷 |

### 7.2 创建工作中心请求

```json
{
  "workCenterCode": "WC-001",
  "workCenterName": "装配中心A",
  "workCenterType": "01",
  "plantId": "uuid-plant",
  "costCenterId": "uuid-cost-center",
  "capacityCategory": "01",
  "capacity": 8.0,
  "capacityUnit": "HR",
  "efficiencyFactor": 100,
  "operatingTime": 8.0,
  "capacities": [
    {
      "capacityCode": "MACHINE",
      "capacityName": "机器产能",
      "capacityCategory": "01",
      "availableCapacity": 8.0,
      "capacityUnit": "HR",
      "startTime": "08:00:00",
      "endTime": "17:00:00",
      "operatingHours": 8.0,
      "efficiencyRate": 100,
      "utilizationRate": 90
    }
  ]
}
```
