# PP 工艺路线管理设计

**模块**: Routing Management (工艺路线管理)
**对标**: SAP PP - CA01/CA02/CA03
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

工艺路线管理负责生产工序的定义与标准值管理：

| 功能 | 说明 | SAP 对标 |
|------|------|----------|
| 工艺路线创建 | 创建工艺路线 | CA01 |
| 工艺路线修改 | 修改工艺路线 | CA02 |
| 工艺路线显示 | 查看工艺路线 | CA03 |
| 工序管理 | 定义工序数据 | CA01 |
| 标准值维护 | 维护标准时间 | CA01 |

## 2. 工艺路线主数据

### 2.1 工艺路线头字段 (对标 SAP MAPL/PLKO)

| 字段 | 类型 | 说明 | SAP 字段 |
|------|------|------|----------|
| routing_number | VARCHAR(10) | 工艺路线号 | PLNNR |
| routing_type | VARCHAR(1) | 工艺路线类型 | PLNTY |
| description | VARCHAR(100) | 工艺路线描述 | KTEXT |
| task_list_usage | VARCHAR(1) | 任务清单用途 | VERWE |
| material_id | UUID | 物料ID | MATNR |
| material_code | VARCHAR(18) | 物料代码 | MATNR |
| plant_id | UUID | 工厂ID | WERKS |
| routing_status | VARCHAR(2) | 工艺路线状态 | - |
| valid_from | DATE | 有效开始日期 | DATUV |
| valid_to | DATE | 有效结束日期 | DATUB |
| total_setup_time | DECIMAL(10,2) | 总准备时间 | - |
| total_machine_time | DECIMAL(10,2) | 总机器时间 | - |
| total_labor_time | DECIMAL(10,2) | 总人工时间 | - |

### 2.3 工艺路线状态

| 状态 | 代码 | 说明 | 影响 |
|------|------|------|------|
| 创建 | 01 | 创建中 | 可修改 |
| 激活 | 02 | 已激活 | 可用于生产 |
| 冻结 | 03 | 冻结 | 不可使用 |

## 3. 工序管理

### 3.1 工序字段 (对标 SAP PLPO)

| 字段 | 类型 | 说明 | SAP 字段 |
|------|------|------|----------|
| routing_id | UUID | 工艺路线ID | PLNAL |
| operation_number | VARCHAR(4) | 工序号 | VORNR |
| operation_text | VARCHAR(100) | 工序描述 | LTXA1 |
| work_center_id | UUID | 工作中心ID | ARBID |
| work_center_code | VARCHAR(8) | 工作中心代码 | ARBPL |
| setup_time | DECIMAL(10,2) | 准备时间 | VORWRT |
| machine_time | DECIMAL(10,2) | 机器时间 | BEIMWRT |
| labor_time | DECIMAL(10,2) | 人工时间 | RUEST |
| time_unit | VARCHAR(3) | 时间单位 | ZEINR |
| base_qty | DECIMAL(13,3) | 基本数量 | BMSCH |
| control_key | VARCHAR(4) | 控制码 | STEUS |
| cost_center_id | UUID | 成本中心ID | KOSTL |
| activity_type | VARCHAR(6) | 作业类型 | LARNT |

## 4. 标准值计算

### 4.1 标准值类型

| 类型 | 说明 | 计算方式 | 用途 |
|------|------|----------|------|
| 准备时间 | 换模、调试时间 | 固定值 | 排程计算 |
| 机器时间 | 机器加工时间 | 数量 × 单位时间 | 排程和成本 |
| 人工时间 | 人工操作时间 | 数量 × 单位时间 | 排程和成本 |

### 4.2 工序时间计算

```
工序时间计算示例:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   产品: A001 零件加工件                                                     │
│   订单数量: 100 PCS                                                         │
│   ─────────────────────────────────────────────────────────────────────    │
│                                                                             │
│   工序    准备时间    机器时间/件   人工时间/件   总机器时间   总人工时间   │
│   ─────────────────────────────────────────────────────────────────────    │
│   0010    10min      0.5min        0.3min        50min        30min        │
│   0020    15min      1.0min        0.5min        100min       50min        │
│   0030    20min      2.0min        1.0min        200min       100min       │
│   ─────────────────────────────────────────────────────────────────────    │
│   合计    45min      -             -             350min       180min       │
│                                                                             │
│   总生产时间 = 45 + 350 + 180 = 575min = 9.58小时                          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 5. 成本集成

### 5.1 工序成本计算

```
工序成本计算:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   成本计算公式:                                                              │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                                                                     │  │
│   │   工序成本 = (准备时间 × 准备费率)                                   │  │
│   │            + (机器时间 × 机器费率)                                   │  │
│   │            + (人工时间 × 人工费率)                                   │  │
│   │                                                                     │  │
│   │   费率来源: 作业类型 (Activity Type)                                 │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   计算示例:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                                                                     │  │
│   │   工序: 0020 加工                                                   │  │
│   │   工作中心: WC-002                                                  │  │
│   │   成本中心: CC-1002                                                 │  │
│   │                                                                     │  │
│   │   准备时间: 15min × 50元/h = 12.50元                                │  │
│   │   机器时间: 100min × 80元/h = 133.33元                              │  │
│   │   人工时间: 50min × 40元/h = 33.33元                                │  │
│   │   ─────────────────────────────────                                │  │
│   │   工序成本: 179.16元                                                │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 7. 接口设计

### 7.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/pp/routings | GET | 工艺路线列表 |
| /api/pp/routings | POST | 创建工艺路线 |
| /api/pp/routings/{id} | GET | 工艺路线详情 |
| /api/pp/routings/{id} | PUT | 更新工艺路线 |
| /api/pp/routings/{id} | DELETE | 删除工艺路线 |
| /api/pp/routings/{id}/operations | GET | 工序列表 |
| /api/pp/routings/{id}/operations | POST | 添加工序 |
| /api/pp/routings/{id}/operations/{opId} | PUT | 更新工序 |
| /api/pp/routings/{id}/operations/{opId} | DELETE | 删除工序 |
