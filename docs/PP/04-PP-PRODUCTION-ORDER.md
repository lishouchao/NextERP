# PP 生产订单管理设计

**模块**: Production Order Management (生产订单管理)
**对标**: SAP PP - CO01/CO02/CO03
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

生产订单管理负责生产订单的全生命周期管理：

| 功能 | 说明 | SAP 对标 |
|------|------|----------|
| 订单创建 | 创建生产订单 | CO01 |
| 订单修改 | 修改生产订单 | CO02 |
| 订单显示 | 查看生产订单 | CO03 |
| 订单审批 | 审批订单 | CO02 |
| 订单下达 | 释放订单 | CO02 |
| 订单结算 | 技术完成 | CO02 |

## 3. 订单工序

### 3.1 订单工序字段 (对标 SAP AFVC)

| 字段 | 类型 | 说明 | SAP 字段 |
|------|------|------|----------|
| order_id | UUID | 订单ID | AUFPL |

| work_center_id | UUID | 工作中心ID | ARBID |
| work_center_code | VARCHAR(8) | 工作中心代码 | ARBPL |
| setup_time | DECIMAL(10,2) | 准备时间 | VORWRT |
| machine_time | DECIMAL(10,2) | 机器时间 | BEIMWRT |
| labor_time | DECIMAL(10,2) | 人工时间 | RUEST |
| planned_start_date | DATE | 计划开始日期 | FSAVD |
| planned_finish_date | DATE | 计划完成日期 | FSEDD |
| planned_qty | DECIMAL(13,3) | 计划数量 | IGMNG |
| actual_start_date | DATE | 实际开始日期 | ISDD |
| actual_finish_date | DATE | 实际完成日期 | IEDD |
| confirmed_qty | DECIMAL(13,3) | 已确认数量 | LMNGA |
| operation_status | VARCHAR(2) | 工序状态 | - |

### 3.2 工序状态

| 状态 | 代码 | 说明 | 影响 |
|------|------|------|------|
| 未开始 | 01 | 工序未开始 | 等待前工序 |
| 处理中 | 02 | 工序进行中 | 可确认 |
| 已完成 | 03 | 工序已完成 | 进入下工序 |

## 8. 接口设计

### 8.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/pp/production-orders | GET | 生产订单列表 |
| /api/pp/production-orders | POST | 创建生产订单 |
| /api/pp/production-orders/{id} | GET | 订单详情 |
| /api/pp/production-orders/{id} | PUT | 更新订单 |
| /api/pp/production-orders/{id} | DELETE | 删除订单 |
| /api/pp/production-orders/{id}/approve | POST | 审批订单 |
| /api/pp/production-orders/{id}/release | POST | 下达订单 |
| /api/pp/production-orders/{id}/teco | POST | 技术完成 |
| /api/pp/production-orders/{id}/operations | GET | 订单工序 |
| /api/pp/production-orders/{id}/costs | GET | 订单成本 |
