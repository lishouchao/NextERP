# PP 生产确认管理设计

**模块**: Production Confirmation Management (生产确认管理)
**对标**: SAP PP - CO11N/CO15
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

生产确认管理负责工序报工与生产进度跟踪：

| 功能 | 说明 | SAP 对标 |
|------|------|----------|
| 工序确认 | 报工确认 | CO11N |
| 最终确认 | 完成确认 | CO11N |
| 部分确认 | 部分报工 | CO11N |
| 返工确认 | 返工报工 | CO11N |
| 确认冲销 | 取消确认 | CO13 |

## 2. 确认主数据

### 2.1 确认字段 (对标 SAP AFRU)

| 字段 | 类型 | 说明 | SAP 字段 |
|------|------|------|----------|
| confirmation_number | VARCHAR(12) | 确认号 | RUECK |
| confirmation_type | VARCHAR(2) | 确认类型 | VORGR |
| order_id | UUID | 订单ID | AUFNR |
| order_number | VARCHAR(12) | 订单号 | AUFNR |
| operation_number | VARCHAR(4) | 工序号 | VORNR |
| yield_qty | DECIMAL(13,3) | 产量 | LMNGA |
| scrap_qty | DECIMAL(13,3) | 报废量 | XMNGA |
| rework_qty | DECIMAL(13,3) | 返工量 | - |
| unit | VARCHAR(3) | 单位 | MEINS |
| setup_time | DECIMAL(10,2) | 准备时间 | ISM03 |
| machine_time | DECIMAL(10,2) | 机器时间 | ISM02 |
| labor_time | DECIMAL(10,2) | 人工时间 | ISM01 |
| time_unit | VARCHAR(3) | 时间单位 | ISMNE |
| confirmation_date | DATE | 确认日期 | ISDD |
| posting_date | DATE | 过账日期 | BUDAT |
| work_center_id | UUID | 工作中心ID | ARBID |
| employee_id | UUID | 员工ID | PERNR |
| actual_cost | DECIMAL(15,2) | 实际成本 | - |
| remarks | TEXT | 备注 | - |
| is_reversed | BOOLEAN | 是否冲销 | STKAN |
| reversed_confirmation_id | UUID | 冲销确认ID | - |

## 4. 确认类型详解

### 4.1 最终确认

```
最终确认逻辑:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   触发条件: 工序全部完成                                                     │
│   ─────────────────────────────────────────────────────────────────────    │
│                                                                             │
│   确认规则:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                                                                     │  │
│   │   1. 产量 = 订单数量                                                │  │
│   │   2. 工序状态 → 已完成                                              │  │
│   │   3. 不可再对该工序确认                                              │  │
│   │   4. 触发下一工序开始                                               │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   示例:                                                                      │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                                                                     │  │
│   │   订单数量: 100 PCS                                                 │  │
│   │   工序: 0020 加工                                                   │  │
│   │                                                                     │  │
│   │   最终确认:                                                         │  │
│   │   ├── 产量: 100 PCS (全部)                                          │  │
│   │   ├── 报废: 0 PCS                                                   │  │
│   │   └── 工序状态: 已完成                                              │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
