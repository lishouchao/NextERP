# PP 物料需求计划设计

**模块**: Material Requirements Planning (物料需求计划)
**对标**: SAP PP - MD01/MD02/MD04
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

物料需求计划负责物料需求的计算与计划：

| 功能 | 说明 | SAP 对标 |
|------|------|----------|
| MRP运行 | 运行MRP计算 | MD01 |
| 单物料MRP | 单个物料计划 | MD02 |
| 库存/需求清单 | 查看计划结果 | MD04 |
| 计划订单 | 生成计划订单 | MD11/MD12 |
| 采购申请 | 生成采购申请 | ME51N |

## 3. MRP 计算逻辑

### 3.1 净需求计算

```
净需求计算:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   计算公式:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                                                                     │  │
│   │   净需求 = 毛需求 - 可用库存 - 计划接收 + 安全库存                   │  │
│   │                                                                     │  │
│   │   其中:                                                              │  │
│   │   毛需求 = 销售订单 + 预测需求 + 上级物料需求                        │  │
│   │   可用库存 = 当前库存 - 已预留库存                                   │  │
│   │   计划接收 = 采购订单 + 生产订单 + 计划订单                          │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   计算示例:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                                                                     │  │
│   │   物料: A001                                                        │  │
│   │   ─────────────────────────────────────────────────────────────    │  │
│   │   毛需求:       1000 PCS (销售订单)                                 │  │
│   │   当前库存:      300 PCS                                            │  │
│   │   已预留:        100 PCS                                            │  │
│   │   可用库存:      200 PCS                                            │  │
│   │   计划接收:      400 PCS (在途PO)                                   │  │
│   │   安全库存:       50 PCS                                            │  │
│   │   ─────────────────────────────────────────────────────────────    │  │
│   │   净需求 = 1000 - 200 - 400 + 50 = 450 PCS                         │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
