# PP 生产计划模块

**模块**: Production Planning (生产计划)
**对标**: SAP ECC PP

## 模块概述

PP模块是NextERP的生产制造核心模块，负责管理从BOM到生产执行的全流程。

## 核心业务流程

### 生产计划到执行流程

1. **基础数据准备**: 创建BOM、工作中心、工艺路线
2. **需求计划**: MRP运行 → 计划订单 → 生产订单
3. **订单执行**: 订单创建 → 审批 → 下达 → 工序排程
4. **生产执行**: 发料 → 生产确认 → 收货 → 成本计算
5. **订单完成**: TECO → 结算 → 关闭

## 模块集成

- **MM 模块**: 发料/收货、库存更新
- **SD 模块**: 销售需求、订单集成
- **CO 模块**: 成本核算、差异分析
- **QM 模块**: 生产检验批次
- **PM 模块**: 设备维修订单
