## 1. 模块概述

### 1.1 功能范围

PS (Project System) 项目系统是企业资源规划中的项目管理核心模块，用于规划、执行和监控各类项目：

| 子模块 | 说明 | SAP 对标 |
|--------|------|----------|
| 项目定义 | 项目主数据创建与管理 | CJ01/CJ02 |
| WBS | 工作分解结构层次管理 | CJ20N |
| 网络/活动 | 项目执行活动的网络计划 | CN21/CN22 |
| 里程碑 | 项目进度与开票里程碑 | CJ20N |
| 项目预算 | 预算编制与可用性控制 | CJ30/CJ32 |
| 项目结算 | 成本结算到接收方 | CJ88 |

## 2. 核心概念

### 2.1 项目类型

| 类型 | 代码 | 说明 | 典型场景 |
|------|------|------|----------|
| 投资项目 | 01 | 固定资产投资项目 | 厂房建设、设备购置 |
| 客户项目 | 02 | 为客户执行的项目 | 工程项目、咨询服务 |
| 内部项目 | 03 | 企业内部项目 | IT实施、流程优化 |
| 研发项目 | 04 | 研究开发项目 | 新产品开发 |
| 维护项目 | 05 | 设备维护项目 | 大修、停机检修 |

### 2.2 WBS 类型

| 类型 | 代码 | 说明 | 用途 |
|------|------|------|------|
| 汇总WBS | 01 | 仅用于汇总 | 层级结构中的父节点 |
| 记账WBS | 02 | 可记账成本 | 成本收集点 |
| 计划WBS | 03 | 用于计划 | 计划与排程 |
| 开票WBS | 04 | 可开票 | 收入确认 |

### 2.3 系统状态

| 状态 | 代码 | 说明 | 影响 |
|------|------|------|------|
| 创建 | CRTD | 已创建未释放 | 仅可查看 |
| 释放 | REL | 已释放可执行 | 可记账、可采购 |
| 技术完成 | TECO | 技术性关闭 | 不再允许过账 |
| 完成 | DLFL | 完全完成 | 准备归档 |
| 关闭 | CLSD | 业务关闭 | 最终状态 |

## 5. 接口设计

### 5.1 项目接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/ps/projects | GET | 项目列表 |
| /api/ps/projects | POST | 创建项目 |
| /api/ps/projects/{id} | GET | 项目详情 |
| /api/ps/projects/{id} | PUT | 更新项目 |
| /api/ps/projects/{id}/release | POST | 释放项目 |
| /api/ps/projects/{id}/complete | POST | 完成项目 |
| /api/ps/projects/{id}/close | POST | 关闭项目 |

### 5.2 WBS 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/ps/projects/{id}/wbs | GET | WBS结构 |
| /api/ps/projects/{id}/wbs | POST | 创建WBS |
| /api/ps/wbs/{id} | GET | WBS详情 |
| /api/ps/wbs/{id} | PUT | 更新WBS |
| /api/ps/wbs/{id}/release | POST | 释放WBS |
| /api/ps/wbs/{id}/complete | POST | 完成WBS |

### 5.3 网络/活动接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/ps/networks | GET | 网络列表 |
| /api/ps/networks | POST | 创建网络 |
| /api/ps/networks/{id}/activities | GET | 网络活动 |
| /api/ps/activities/{id} | GET | 活动详情 |
| /api/ps/activities/{id}/confirm | POST | 确认活动 |

### 5.4 预算接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/ps/projects/{id}/budget | GET | 项目预算 |
| /api/ps/projects/{id}/budget | POST | 编制预算 |
| /api/ps/projects/{id}/budget/release | POST | 释放预算 |
| /api/ps/projects/{id}/budget/supplement | POST | 补充预算 |

### 5.5 里程碑接口
