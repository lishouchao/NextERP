# PS 项目定义与WBS设计

**模块**: Project Definition & WBS (项目定义与工作分解结构)
**对标**: SAP PS - CJ01/CJ02/CJ20N
**版本**: 1.0
**更新日期**: 2026-03-14

---

## 1. 概述

### 1.1 功能范围

项目定义和WBS是PS模块的核心主数据，用于定义项目的基本信息和层次结构：

| 功能 | 说明 | SAP 对标 |
|------|------|----------|
| 项目创建 | 创建项目定义 | CJ01 |
| 项目修改 | 修改项目属性 | CJ02 |
| 项目显示 | 查看项目信息 | CJ03 |
| WBS创建 | 创建工作分解结构 | CJ20N |
| WBS维护 | 维护WBS层次 | CJ20N |
| 项目释放 | 释放项目可执行 | CJ20N |
| 项目完成 | 技术性关闭项目 | CJ20N |

## 2. 项目定义

### 2.1 项目主数据 (对标 SAP PROJ)

| 字段 | 类型 | 说明 |
|------|------|------|
| project_number | VARCHAR(24) | 项目定义号 (外部/内部编号) |
| project_name | VARCHAR(100) | 项目名称 |
| description | TEXT | 项目描述 |
| project_type | VARCHAR(2) | 项目类型 |
| project_profile | VARCHAR(7) | 项目档案 |
| company_id | UUID | 公司代码 |
| business_area | VARCHAR(4) | 业务范围 |
| profit_center_id | UUID | 利润中心 |
| plant_id | UUID | 工厂 |
| cost_center_id | UUID | 成本中心 |
| project_manager | UUID | 项目经理 |
| responsible_id | UUID | 负责人 |
| planned_start_date | DATE | 计划开始日期 |
| planned_finish_date | DATE | 计划完成日期 |
| actual_start_date | DATE | 实际开始日期 |
| actual_finish_date | DATE | 实际完成日期 |
| customer_id | UUID | 客户 |
| currency_id | UUID | 货币 |
| total_budget | DECIMAL(15,2) | 总预算 |
| released_budget | DECIMAL(15,2) | 已释放预算 |
| committed_cost | DECIMAL(15,2) | 承诺成本 |
| actual_cost | DECIMAL(15,2) | 实际成本 |
| project_status | VARCHAR(2) | 项目状态 |
| system_status | VARCHAR(20) | 系统状态 |
| progress_percent | DECIMAL(5,2) | 进度百分比 |

### 2.2 项目类型配置

| 类型代码 | 类型名称 | 说明 |
|----------|----------|------|
| 01 | 投资项目 | 固定资产投资，结算到资产 |
| 02 | 客户项目 | 为客户执行，结算到客户/销售订单 |
| 03 | 内部项目 | 企业内部项目，结算到成本中心 |
| 04 | 研发项目 | 研究开发项目，研发费用 |
| 05 | 维护项目 | 设备维护项目，结算到维护订单 |

### 2.3 项目档案配置

项目档案控制项目的默认行为：

| 档案配置 | 说明 | 影响 |
|----------|------|------|
| 项目档案 | 项目参数模板 | 状态管理、编号范围 |
| 计划档案 | 计划参数 | 日期计算、工作量 |
| 预算档案 | 预算参数 | 预算控制、容忍度 |
| 结算档案 | 结算参数 | 结算规则、接收方 |

| parent_id | UUID | 父WBS |
| level | INTEGER | 层级 |

| wbs_type | VARCHAR(2) | WBS类型 |

| plant_id | UUID | 工厂 |
| cost_center_id | UUID | 成本中心 |
| planned_start_date | DATE | 计划开始日期 |
| planned_finish_date | DATE | 计划完成日期 |
| actual_start_date | DATE | 实际开始日期 |
| actual_finish_date | DATE | 实际完成日期 |
| duration_days | INTEGER | 持续天数 |
| responsible_id | UUID | 负责人 |

| committed_cost | DECIMAL(15,2) | 承诺成本 |
| actual_cost | DECIMAL(15,2) | 实际成本 |

### 3.2 WBS 类型

```
WBS 类型与用途:
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│   WBS类型: 01 - 汇总WBS                                                 │
│   ┌─────────────────────────────────────────────────────────────┐      │
│   │ 功能: 仅用于层级汇总，不记账成本                              │      │
│   │ 用途: 组织结构、分组汇总                                      │      │
│   │ 限制: 不能分配采购申请、不能确认工时                          │      │
│   └─────────────────────────────────────────────────────────────┘      │
│                                                                         │
│   WBS类型: 02 - 记账WBS                                                 │
│   ┌─────────────────────────────────────────────────────────────┐      │
│   │ 功能: 成本收集点，可记账所有成本                              │      │
│   │ 用途: 采购、工时确认、成本分配                                │      │
│   │ 集成: PR/PO项目分配、CAT2确认、FI过账                        │      │
│   └─────────────────────────────────────────────────────────────┘      │
│                                                                         │
│   WBS类型: 03 - 计划WBS                                                 │
│   ┌─────────────────────────────────────────────────────────────┐      │
│   │ 功能: 用于计划和排程                                          │      │
│   │ 用途: 进度计划、资源计划                                      │      │
│   │ 限制: 不直接记账成本                                          │      │
│   └─────────────────────────────────────────────────────────────┘      │
│                                                                         │
│   WBS类型: 04 - 开票WBS                                                 │
│   ┌─────────────────────────────────────────────────────────────┐      │
│   │ 功能: 收入确认和开票                                          │      │
│   │ 用途: 里程碑开票、开票计划                                    │      │
│   │ 集成: SD开票、收入过账                                        │      │
│   └─────────────────────────────────────────────────────────────┘      │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

## 4. 状态管理

### 4.1 项目状态

| 状态 | 代码 | 说明 | 允许操作 |
|------|------|------|----------|
| 创建 | 01 | 项目已创建 | 修改、删除 |
| 释放 | 02 | 项目已释放 | 记账、采购、确认 |
| 技术完成 | 04 | TECO状态 | 仅查看 |
| 完成 | 03 | 项目完成 | 仅查看 |
| 关闭 | 05 | 项目关闭 | 无操作 |

### 4.2 系统状态

| 状态 | 代码 | 说明 |
|------|------|------|
| CRTD | Created | 已创建 |
| REL | Released | 已释放 |
| TECO | Technically Completed | 技术完成 |
| DLFL | Deletion Flag | 删除标记 |
| CLSD | Closed | 已关闭 |

## 5. 结算规则

### 5.1 结算规则类型

| 规则 | 代码 | 说明 | 接收方 |
|------|------|------|--------|
| 自动结算 | 01 | 自动分配 | 按预设规则 |

| 销售订单 | 客户项目 | 收入确认 |
| 利润中心 | 跨利润中心 | 利润分析 |
| G/L科目 | 直接费用 | 费用过账 |

## 6. 日期管理

### 6.1 日期类型

| 日期类型 | 说明 | 计算方式 |
|----------|------|----------|
| 计划开始 | 计划开始日期 | 手工/自上而下 |
| 计划完成 | 计划完成日期 | 开始+持续天数 |
| 实际开始 | 实际开始日期 | 释放/首次过账 |
| 实际完成 | 实际完成日期 | 技术完成 |
| 预测开始 | 预测开始日期 | 进度计算 |
| 预测完成 | 预测完成日期 | 进度计算 |

### 6.2 日期推算

```
日期推算逻辑:
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│   项目定义日期 (汇总)                                                   │
│   ┌─────────────────────────────────────────────────────────────────┐  │
│   │ 计划开始 = MIN(所有WBS计划开始)                                  │  │
│   │ 计划完成 = MAX(所有WBS计划完成)                                  │  │
│   └─────────────────────────────────────────────────────────────────┘  │
│                                                                         │
│   WBS日期 (自上而下)                                                    │
│   ┌─────────────────────────────────────────────────────────────────┐  │
│   │ 父WBS计划开始 = MIN(子WBS计划开始)                               │  │
│   │ 父WBS计划完成 = MAX(子WBS计划完成)                               │  │
│   │ 持续天数 = 计划完成 - 计划开始 + 1                               │  │
│   └─────────────────────────────────────────────────────────────────┘  │
│                                                                         │
│   网络日期 (正向排程)                                                   │
│   ┌─────────────────────────────────────────────────────────────────┐  │
│   │ 活动开始 = MAX(前驱活动完成) + 1                                 │  │
│   │ 活动完成 = 活动开始 + 持续天数 - 1                               │  │
│   └─────────────────────────────────────────────────────────────────┘  │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```
