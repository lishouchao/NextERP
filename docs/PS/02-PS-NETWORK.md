# PS 网络与活动设计

**模块**: Network & Activity (网络与活动)
**对标**: SAP PS - CN21/CN22/CN23
**版本**: 1.0
**更新日期**: 2026-03-14

## 1. 概述

### 1.1 功能范围

网络和活动是PS模块的执行层，用于详细计划和跟踪项目工作：

| 功能 | 说明 | SAP 对标 |
|------|------|----------|
| 网络创建 | 创建项目网络 | CN21 |
| 网络修改 | 修改网络属性 | CN22 |
| 网络显示 | 查看网络信息 | CN23 |
| 活动维护 | 创建和维护活动 | CN21/CN22 |
| 关系维护 | 活动间关系 | CN21 |
| 确认执行 | 工时和进度确认 | CAT2/CN25 |

## 5. 日程计算

### 5.1 正向排程

```
正向排程逻辑:
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│   输入: 开始日期、活动持续天数、活动关系                                │
│   输出: 每个活动的开始和完成日期                                        │
│                                                                         │
│   算法:                                                                 │
│   ┌─────────────────────────────────────────────────────────────────┐  │
│   │ FOR each activity in topological order:                         │  │
│   │     IF no predecessor:                                          │  │
│   │         early_start = network_start_date                        │  │
│   │     ELSE:                                                       │  │
│   │         early_start = MAX(predecessor.early_finish + lag)       │  │
│   │                                                                 │  │
│   │     early_finish = early_start + duration - 1                   │  │
│   └─────────────────────────────────────────────────────────────────┘  │
│                                                                         │
│   示例:                                                                 │
│   ┌──────────┐     ┌──────────┐     ┌──────────┐                     │
│   │ 0010     │────►│ 0020     │────►│ 0030     │                     │
│   │ 3/1-3/5  │ FS  │ 3/6-3/10│ FS  │ 3/11-3/15│                     │
│   │ (5天)    │     │ (5天)   │     │ (5天)    │                     │
│   └──────────┘     └──────────┘     └──────────┘                     │
│                                                                         │
│   网络完成日期 = MAX(all activities.early_finish) = 3/15               │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 5.2 逆向排程

```
逆向排程逻辑:
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│   输入: 完成日期 (截止日期)、活动持续天数、活动关系                     │
│   输出: 每个活动的最晚开始和完成日期                                    │
│                                                                         │
│   算法:                                                                 │
│   ┌─────────────────────────────────────────────────────────────────┐  │
│   │ FOR each activity in reverse topological order:                 │  │
│   │     IF no successor:                                            │  │
│   │         late_finish = network_deadline                          │  │
│   │     ELSE:                                                       │  │
│   │         late_finish = MIN(successor.late_start - lag)           │  │
│   │                                                                 │  │
│   │     late_start = late_finish - duration + 1                     │  │
│   └─────────────────────────────────────────────────────────────────┘  │
│                                                                         │
│   浮动时间 (Slack) = late_start - early_start                          │
│   关键路径 = 所有浮动时间为0的活动                                      │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 5.3 关键路径

```
关键路径计算:
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│   ┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐    │
│   │ 0010     │────►│ 0020     │────►│ 0040     │────►│ 0050     │    │
│   │ ES=1,LF=5│     │ ES=6,LF=10│    │ ES=11,LF=15│   │ ES=16,LF=20│   │
│   │ LS=1,LF=5│     │ LS=6,LF=10│    │ LS=11,LF=15│   │ LS=16,LF=20│   │
│   │ 浮动=0   │     │ 浮动=0   │     │ 浮动=0   │     │ 浮动=0   │    │
│   └──────────┘     └──────────┘     └──────────┘     └──────────┘    │
│        │                                    ▲                          │
│        │                                    │                          │
│        ▼                                    │                          │
│   ┌──────────┐                         ┌───┴───┐                      │
│   │ 0030     │                         │       │                      │
│   │ ES=6,LF=8│                         │       │                      │
│   │ LS=13,LF=15                        │       │                      │
│   │ 浮动=7   │                         │       │                      │
│   └──────────┘                         │       │                      │
│                                        │       │                      │
│   关键路径: 0010 → 0020 → 0040 → 0050 (总工期: 20天)                  │
│   非关键活动: 0030 (浮动时间: 7天)                                     │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

## 6. 活动确认

### 6.1 确认类型

| 类型 | 说明 | 影响 |
|------|------|------|
| 工时确认 | 确认实际工时 | 更新实际工时、计算成本 |
| 完成确认 | 确认活动完成 | 更新状态、记录完成日期 |
| 部分确认 | 确认部分完成 | 更新进度百分比 |
| 最终确认 | 最终完成确认 | 关闭活动 |

### 6.2 确认记录

| 字段 | 类型 | 说明 |
|------|------|------|
| confirmation_number | VARCHAR(12) | 确认编号 |
| network_id | UUID | 网络ID |
| activity_id | UUID | 活动ID |
| confirmation_date | DATE | 确认日期 |
| work_type | VARCHAR(1) | 工作类型 |
| actual_work | DECIMAL(10,2) | 实际工时 |
| remaining_work | DECIMAL(10,2) | 剩余工时 |
| final_confirmation | BOOLEAN | 最终确认 |
| progress_percent | DECIMAL(5,2) | 完成百分比 |
| actual_start | DATE | 实际开始 |
| actual_finish | DATE | 实际完成 |
| confirmed_by | UUID | 确认人 |

### 6.3 确认流程

```
活动确认流程:
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│   1. 创建确认                                                           │
│   ┌─────────────┐                                                       │
│   │ 选择活动    │                                                       │
│   │ 输入工时    │                                                       │
│   └──────┬──────┘                                                       │
│          │                                                              │
│          ▼                                                              │
│   2. 计算成本                                                           │
│   ┌─────────────┐                                                       │
│   │ 实际工时    │                                                       │
│   │ × 人工费率  │                                                       │
│   │ = 实际成本  │                                                       │
│   └──────┬──────┘                                                       │
│          │                                                              │
```
