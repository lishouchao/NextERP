# PS 预算管理设计

**模块**: Budget Management (预算管理)
**对标**: SAP PS - CJ30/CJ32/CJ37/CJ38
**版本**: 1.0
**更新日期**: 2026-03-14

---

## 1. 概述

### 1.1 功能范围

预算管理是PS模块的财务控制核心，用于编制、监控和控制项目预算：

| 功能 | 说明 | SAP 对标 |
|------|------|----------|
| 预算编制 | 编制项目预算 | CJ30 |
| 预算修改 | 修改预算金额 | CJ32 |
| 预算补充 | 追加预算 | CJ37 |
| 预算转移 | 预算WBS间转移 | CJ38 |
| 预算释放 | 释放预算可用 | CJ30 |
| 可用性控制 | 预算检查与警告 | AVC |

## 2. 预算结构

### 2.1 预算头 (对标 SAP 预算)

| 字段 | 类型 | 说明 |
|------|------|------|
| project_id | UUID | 项目ID |
| project_number | VARCHAR(24) | 项目号 |
| budget_type | VARCHAR(2) | 预算类型 |
| fiscal_year | INTEGER | 会计年度 |
| total_budget | DECIMAL(15,2) | 总预算 |
| released_budget | DECIMAL(15,2) | 已释放预算 |
| used_budget | DECIMAL(15,2) | 已使用预算 |
| currency_id | UUID | 货币 |
| budget_status | VARCHAR(2) | 预算状态 |
| approved_by | UUID | 审批人 |
| approved_at | TIMESTAMP | 审批时间 |

### 2.2 预算类型

| 类型 | 代码 | 说明 | 用途 |
|------|------|------|------|
| 原始预算 | 01 | 初始预算 | 项目批准时 |
| 补充预算 | 02 | 追加预算 | 预算不足时 |
| 预算返回 | 03 | 返回预算 | 预算过多时 |
| 预算转移 | 04 | 转移预算 | WBS间转移 |

### 2.3 预算明细

| 字段 | 类型 | 说明 |
|------|------|------|
| budget_id | UUID | 预算头ID |
| wbs_id | UUID | WBS ID |
| wbs_number | VARCHAR(24) | WBS号 |
| cost_element | VARCHAR(10) | 成本要素 |
| period_01~12 | DECIMAL(15,2) | 各期预算 |
| total_amount | DECIMAL(15,2) | 年度总计 |

### 3.3 预算调整

| 调整类型 | 事务 | 说明 | 影响 |
|----------|------|------|------|
| 补充预算 | CJ37 | 增加预算 | 总预算增加 |

| 预算转移 | CJ38 | WBS间转移 | 总预算不变 |
| 预算释放 | CJ30 | 释放可用 | 已释放增加 |

## 4. 可用性控制 (AVC)

### 4.1 控制参数

| 字段 | 类型 | 说明 |
|------|------|------|
| project_id | UUID | 项目ID |
| tolerance_limit_warning | DECIMAL(5,2) | 警告容忍度% |
| tolerance_limit_error | DECIMAL(5,2) | 错误容忍度% |
| control_scope | VARCHAR(2) | 控制范围 |
| action_type | VARCHAR(2) | 超预算操作 |
| is_active | BOOLEAN | 是否激活 |

### 4.2 控制范围

| 范围 | 代码 | 说明 | 检查级别 |
|------|------|------|----------|
| 整体 | 01 | 项目整体预算 | 项目汇总 |
| 年度 | 02 | 按年度控制 | 每个年度 |
| WBS | 03 | 按WBS控制 | 每个WBS |
| 成本要素 | 04 | 按成本要素 | 每个要素 |

## 5. 预算与成本对比

### 5.1 成本类型

| 成本类型 | 说明 | 计算方式 |
|----------|------|----------|
| 计划成本 | 预估成本 | WBS/活动计划 |
| 承诺成本 | 采购承诺 | PR + PO未收货 |
| 实际成本 | 已发生成本 | 收货 + 发票 + 确认 |
| 剩余预算 | 可用预算 | 预算 - 已使用 |
