# PS 里程碑管理设计

**模块**: Milestone Management (里程碑管理)
**对标**: SAP PS - CJ20N/Milestones
**版本**: 1.0
**更新日期**: 2026-03-14

---

## 1. 概述

### 1.1 功能范围

里程碑管理用于标识项目关键节点，支持进度跟踪和开票触发：

| 功能 | 说明 | SAP 对标 |
|------|------|----------|
| 里程碑创建 | 创建里程碑 | CJ20N |
| 里程碑分配 | 分配到WBS/活动 | CJ20N |
| 进度计算 | 基于里程碑计算进度 | 进度分析 |
| 开票触发 | 里程碑触发开票 | DP80/DP81 |
| 里程碑完成 | 确认里程碑完成 | CJ20N |

## 2. 里程碑主数据

### 2.1 里程碑定义 (对标 SAP MILESTONE)

| 字段 | 类型 | 说明 |
|------|------|------|
| wbs_id | UUID | WBS ID |
| activity_id | UUID | 活动ID |
| network_id | UUID | 网络ID |
| milestone_number | VARCHAR(4) | 里程碑号 |
| milestone_name | VARCHAR(100) | 里程碑名称 |
| description | TEXT | 描述 |
| planned_date | DATE | 计划日期 |
| actual_date | DATE | 实际日期 |
| milestone_percent | DECIMAL(5,2) | 里程碑进度% |
| usage_type | VARCHAR(2) | 用途类型 |
| billing_rule | VARCHAR(2) | 开票规则 |
| billing_percent | DECIMAL(5,2) | 开票比例% |
| billing_value | DECIMAL(15,2) | 开票金额 |
| is_completed | BOOLEAN | 是否完成 |
| completed_at | TIMESTAMP | 完成时间 |

### 2.2 里程碑用途

| 用途 | 代码 | 说明 | 功能 |
|------|------|------|------|
| 进度 | 01 | 进度跟踪 | 计算项目进度 |
| 开票 | 02 | 开票计划 | 触发开票 |
| 触发 | 03 | 事件触发 | 触发后续动作 |
| 结算 | 04 | 结算规则 | 触发结算 |

## 3. 里程碑与进度

### 3.1 进度计算方法

```
里程碑进度计算:
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│   项目里程碑设置:                                                       │
│   ┌─────────────────────────────────────────────────────────────────┐  │
│   │                                                                 │  │
│   │   里程碑   名称         进度%   状态      计划日期   实际日期   │  │
│   │   ────────────────────────────────────────────────────────────  │  │
│   │   M1       项目启动      10%    完成      1/1       1/1        │  │
│   │   M2       设计完成      30%    完成      2/15      2/18       │  │
│   │   M3       采购完成      60%    完成      4/1       4/5        │  │
│   │   M4       安装完成      90%    处理中    6/1       -          │  │
│   │   M5       项目验收     100%    未开始    7/1       -          │  │
│   │   ────────────────────────────────────────────────────────────  │  │
│   │                                                                 │  │
│   └─────────────────────────────────────────────────────────────────┘  │
│                                                                         │
│   进度计算:                                                             │
│   ┌─────────────────────────────────────────────────────────────────┐  │
│   │                                                                 │  │
│   │   当前进度 = SUM(已完成里程碑的进度%)                           │  │
│   │            = 10% + 30% + 60%                                    │  │
│   │            = 100%                                               │  │
│   │                                                                 │  │
│   │   注: 最后一个完成里程碑的进度 = 60%                            │  │
│   │                                                                 │  │
│   │   如果M4部分完成 (50%):                                         │  │
│   │   当前进度 = 60% + (90% - 60%) × 50% = 75%                      │  │
│   │                                                                 │  │
│   └─────────────────────────────────────────────────────────────────┘  │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 3.2 进度方法配置

| 方法 | 代码 | 说明 | 计算方式 |
|------|------|------|----------|
| 手工 | 01 | 手工输入进度 | 用户输入 |
| 工作量 | 02 | 按工作量 | 实际工时/计划工时 |
| 成本 | 03 | 按成本 | 实际成本/计划成本 |
| 里程碑 | 04 | 按里程碑 | 里程碑完成比例 |

## 7. 接口设计

### 7.1 里程碑接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/ps/projects/{id}/milestones | GET | 项目里程碑列表 |
| /api/ps/projects/{id}/milestones | POST | 创建里程碑 |
| /api/ps/milestones/{id} | GET | 里程碑详情 |
| /api/ps/milestones/{id} | PUT | 更新里程碑 |
| /api/ps/milestones/{id}/complete | POST | 完成里程碑 |

### 7.2 开票接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/ps/milestones/{id}/billing | GET | 开票信息 |
| /api/ps/milestones/{id}/billing | POST | 创建开票请求 |
| /api/ps/milestones/{id}/billing/invoice | POST | 生成发票 |

### 7.3 触发接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/ps/milestones/{id}/triggers | GET | 触发规则列表 |
| /api/ps/milestones/{id}/triggers | POST | 配置触发规则 |
| /api/ps/milestones/{id}/triggers/execute | POST | 执行触发动作 |
