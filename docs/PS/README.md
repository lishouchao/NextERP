## 核心概念

### 项目类型

| 类型 | 代码 | 说明 | SAP 对标 |
|------|------|------|----------|
| 投资项目 | 01 | 固定资产投资 | 投资管理 (IM) |
| 客户项目 | 02 | 为客户执行 | SD集成 |
| 内部项目 | 03 | 企业内部项目 | CO集成 |
| 研发项目 | 04 | 研究开发 | 研发管理 |
| 维护项目 | 05 | 设备维护 | PM集成 |

### WBS类型

| 类型 | 代码 | 说明 | 用途 |
|------|------|------|------|
| 汇总WBS | 01 | 仅汇总 | 层级结构 |
| 记账WBS | 02 | 成本收集 | 采购/确认 |
| 计划WBS | 03 | 计划排程 | 进度计划 |
| 开票WBS | 04 | 收入确认 | 开票节点 |

### 系统状态

| 状态 | 代码 | 说明 | 影响 |
|------|------|------|------|
| 创建 | CRTD | 已创建未释放 | 仅可查看 |
| 释放 | REL | 已释放可执行 | 可记账 |
| 技术完成 | TECO | 技术性关闭 | 不再过账 |
| 关闭 | CLSD | 业务关闭 | 最终状态 |

## 业务流程

### 项目生命周期

```
创建(CRTD) ──► 释放(REL) ──► 执行 ──► 技术完成(TECO) ──► 关闭(CLSD)
     │              │           │            │               │
     │              │           │            │               │
     ▼              ▼           ▼            ▼               ▼
  项目定义       WBS释放     成本收集     成本结算        项目归档
  WBS创建       网络释放     工时确认     预算结算
  网络创建      预算释放     采购执行     收入确认
```

### 预算控制流程

```
预算编制 ──► 预算审批 ──► 预算释放 ──► 可用性控制 ──► 预算执行
    │            │            │             │            │
    │            │            │             │            │
    ▼            ▼            ▼             ▼            ▼
 按WBS分配    审批流程    释放比例      容忍度检查    成本记账
 按期间分配   审批通过    可用预算      警告/阻止     更新使用
```
