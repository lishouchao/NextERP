## 2. 检验流程

### 2.1 来料检验流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           来料检验流程                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. 采购收货触发                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   MM模块收货 → 自动创建检验批                                        │   │
│   │   - 物料进入质检库存                                                │   │
│   │   - 状态: REL (已释放)                                              │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   2. 检验执行                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   按检验计划逐项检验:                                                │   │
│   │   ┌─────────────────────────────────────────────────────────────┐  │   │
│   │   │   特性1: 外观检查 → 录入结果 (定性)                           │  │   │
│   │   │   特性2: 尺寸测量 → 录入数值 (定量)                           │  │   │
│   │   │   特性3: 功能测试 → 录入结果                                  │  │   │
│   │   │   ...                                                         │  │   │
│   │   └─────────────────────────────────────────────────────────────┘  │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   3. 使用决策                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   检验员判定:                                                        │   │
│   │   ┌─────────────────────────────────────────────────────────────┐  │   │
│   │   │   AC (接受): 库存转入非限制                                  │  │   │
│   │   │   RJ (拒收): 退货给供应商                                    │  │   │
│   │   │   PR (条件接受): 让步接收                                    │  │   │
│   │   │   SC (报废): 报废处理                                        │  │   │
│   │   └─────────────────────────────────────────────────────────────┘  │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 检验批状态

| 状态 | 代码 | 说明 | 允许操作 |
|------|------|------|----------|
| 创建 | 01 | 检验批创建 | 修改、删除 |
| 已释放 | 02 | 可以检验 | 录入结果 |
| 检验中 | 03 | 正在检验 | 继续录入 |
| 完成 | 04 | 检验完成 | 使用决策 |
| 已决策 | 05 | 已做决策 | 库存过账 |
| 取消 | 06 | 已取消 | - |

## 4. 采样过程

### 4.1 采样类型

| 类型 | 代码 | 说明 | 计算方式 |
|------|------|------|----------|
| 固定样本量 | 01 | 固定数量 | 指定数量 |
| 百分比 | 02 | 按比例计算 | 批量 × % |
| AQL抽样 | 03 | 统计抽样 | 按AQL表 |

### 4.2 AQL抽样示例

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           AQL抽样示例                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   检验批: 1,000个                                                           │
│   AQL水平: 1.0                                                              │
│   检验水平: G2 (一般检验水平II)                                              │
│                                                                             │
│   查表:                                                                     │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   批量范围: 501 - 1,200                                              │   │
│   │   字码: J                                                            │   │
│   │   样本量: 80                                                         │   │
│   │   接收数 (Ac): 2                                                     │   │
│   │   拒收数 (Re): 3                                                     │   │
│   │                                                                       │   │
│   │   判定规则:                                                           │   │
```

## 5. 质量通知

### 5.1 通知类型

| 类型 | 代码 | 说明 | 使用场景 |
|------|------|------|----------|
| 客户投诉 | Q1 | 客户质量问题 | 客户反馈 |
| 内部问题 | Q2 | 内部质量问题 | 过程发现 |
| 供应商问题 | Q3 | 供应商质量问题 | 来料缺陷 |

### 5.2 通知状态

| 状态 | 代码 | 说明 | 操作 |
|------|------|------|------|
| 创建 | 01 | 通知创建 | 编辑 |
| 处理中 | 02 | 正在处理 | 添加任务 |
| 完成 | 03 | 处理完成 | 验证 |
| 关闭 | 04 | 通知关闭 | - |
