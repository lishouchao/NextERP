## 2. 检验特性

### 2.1 特性字段 (qm_characteristic)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| char_code | VARCHAR(8) | 是 | 特性代码 |
| char_name | VARCHAR(100) | 是 | 特性名称 |
| char_type | VARCHAR(2) | 是 | 特性类型 (01:定量 02:定性) |
| target_value | DECIMAL(15,4) | 否 | 目标值 |
| lower_limit | DECIMAL(15,4) | 否 | 下限 |
| upper_limit | DECIMAL(15,4) | 否 | 上限 |
| unit | VARCHAR(3) | 否 | 单位 |
| code_group | VARCHAR(8) | 否 | 代码组 |
| selected_set | VARCHAR(4) | 否 | 选择集 |
| sampling_procedure | VARCHAR(8) | 否 | 采样过程 |
| sample_quantity | DECIMAL(13,3) | 否 | 样本量 |

## 3. 检验方法

### 3.1 方法字段 (qm_inspection_method)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| method_code | VARCHAR(8) | 是 | 方法代码 |
| method_name | VARCHAR(100) | 是 | 方法名称 |
| description | TEXT | 否 | 方法描述 |
| equipment_required | BOOLEAN | 否 | 需要设备 |
| measuring_equipment | VARCHAR(20) | 否 | 测量设备 |
| inspection_time | DECIMAL(8,2) | 否 | 检验时间(分钟) |
| work_instruction | TEXT | 否 | 作业指导书 |

### 3.2 常用检验方法

| 方法代码 | 方法名称 | 设备 | 时间 |
|----------|----------|------|------|
| VIS01 | 目视检查 | 无 | 2 |
| CAL01 | 卡尺测量 | 卡尺 | 5 |
| MIC01 | 千分尺测量 | 千分尺 | 8 |
| WEI01 | 重量测量 | 电子秤 | 3 |
| HAR01 | 硬度测试 | 硬度计 | 10 |
| FUN01 | 功能测试 | 测试仪 | 15 |

## 4. 采样过程

### 4.1 采样类型

| 类型 | 代码 | 说明 | 参数 |
|------|------|------|------|
| 固定样本量 | 01 | 指定数量 | fixed_sample_qty |
| 百分比 | 02 | 按比例 | sample_percent |
| AQL抽样 | 03 | 统计抽样 | aql_level |

### 4.2 采样计算

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           采样计算示例                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. 固定样本量:                                                            │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   批量: 任意                                                         │   │
│   │   样本量 = fixed_sample_qty (如 5)                                   │   │
│   │   结果: 抽取5个样本                                                  │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   2. 百分比抽样:                                                            │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   批量: 1,000                                                         │   │
│   │   百分比: 10%                                                         │   │
│   │   最小样本量: 5                                                       │   │
│   │   最大样本量: 50                                                      │   │
│   │                                                                       │   │
│   │   样本量 = MIN(MAX(批量 × 10%, 5), 50)                              │   │
│   │         = MIN(MAX(100, 5), 50)                                      │   │
│   │         = 50                                                          │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   3. AQL抽样:                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   批量: 1,000                                                         │   │
│   │   AQL: 1.0                                                            │   │
│   │   检验水平: G2                                                        │   │
│   │                                                                       │   │
│   │   查AQL表:                                                            │   │
│   │   字码: J → 样本量: 80                                                │   │
│   │   Ac: 2, Re: 3                                                        │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
