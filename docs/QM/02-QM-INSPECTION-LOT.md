# QM 检验批管理

**模块**: Inspection Lot Management
**对标**: SAP QA01/QA02
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 检验批类型

| 类型 | 代码 | 说明 | 触发来源 |
|------|------|------|----------|
| 来料检验 | 01 | 采购收货检验 | MM收货 |
| 过程检验 | 02 | 生产工序检验 | PP报工 |
| 成品检验 | 03 | 完工入库检验 | PP完工 |
| 库存检验 | 04 | 库存抽检 | 手工创建 |
| 退货检验 | 05 | 销售退货检验 | SD退货 |

### 1.2 检验批生命周期

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           检验批生命周期                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   状态流转:                                                                  │
│                                                                             │
│   ┌────────┐    ┌────────┐    ┌────────┐    ┌────────┐    ┌────────┐     │
│   │  创建  │───►│ 已释放 │───►│ 检验中 │───►│ 完成   │───►│ 已决策 │     │
│   │  (01)  │    │  (02)  │    │  (03)  │    │  (04)  │    │  (05)  │     │
│   └────────┘    └────────┘    └────────┘    └────────┘    └────────┘     │
│       │             │             │             │                          │
│       │             │             │             │                          │
│       └─────────────┴─────────────┴─────────────┘                          │
│                           │                                                 │
│                           ▼                                                 │
│                     ┌────────┐                                             │
│                     │  取消  │                                             │
│                     │  (06)  │                                             │
│                     └────────┘                                             │
│                                                                             │
│   操作说明:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   创建: 检验批创建，可以修改/删除                                    │   │
│   │   已释放: 可以开始录入检验结果                                       │   │
│   │   检验中: 部分结果已录入                                             │   │
│   │   完成: 所有特性检验完成                                             │   │
│   │   已决策: 使用决策已完成                                             │   │
│   │   取消: 检验批取消                                                   │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. 检验批字段

### 2.1 主字段 (qm_inspection_lot)

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| lot_number | VARCHAR(12) | 是 | 检验批号 | QALS |
| lot_type | VARCHAR(3) | 是 | 检验类型 | - |
| material_id | UUID | 是 | 物料ID | MATNR |
| batch_number | VARCHAR(10) | 否 | 批次号 | CHARG |
| lot_quantity | DECIMAL(13,3) | 是 | 批次数量 | LOSMENGE |
| sample_quantity | DECIMAL(13,3) | 否 | 样本数量 | LPMNG |
| inspected_quantity | DECIMAL(13,3) | 否 | 已检数量 | - |
| accepted_quantity | DECIMAL(13,3) | 否 | 接受数量 | - |
| rejected_quantity | DECIMAL(13,3) | 否 | 拒收数量 | - |
| unit | VARCHAR(3) | 是 | 单位 | - |
| plant_id | UUID | 是 | 工厂ID | WERK |
| sloc_id | UUID | 否 | 库存地点 | LGORT |
| source_type | VARCHAR(2) | 否 | 来源类型 | - |
| source_document | VARCHAR(20) | 否 | 来源单据 | - |
| lot_status | VARCHAR(2) | 是 | 批状态 | - |
| decision_made | BOOLEAN | 否 | 已做决策 | - |
| decision_result | VARCHAR(2) | 否 | 决策结果 | - |

## 3. 检验结果

### 3.1 结果字段 (qm_inspection_result)

| 字段 | 类型 | 说明 |
|------|------|------|
| lot_id | UUID | 检验批ID |
| insp_char_id | UUID | 检验特性ID |
| sample_number | INTEGER | 样本号 |
| measured_value | DECIMAL(15,4) | 测量值 |
| original_value | VARCHAR(30) | 原始值 |
| code_value | VARCHAR(4) | 代码值 |
| evaluation_result | VARCHAR(2) | 评估结果 |
| is_out_of_spec | BOOLEAN | 超标 |
| inspection_date | DATE | 检验日期 |
| inspector_id | UUID | 检验员 |

### 3.2 结果录入流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           结果录入流程                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. 选择检验批                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 输入检验批号或扫描条码                                           │   │
│   │   - 显示检验批概览                                                   │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   2. 选择检验特性                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 显示待检验特性列表                                               │   │
│   │   - 按顺序检验                                                       │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   3. 录入结果                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   定量特性:                                                           │   │
│   │   ┌─────────────────────────────────────────────────────────────┐  │   │
│   │   │   样本1: 输入测量值 100.5 mm → 系统自动评估 A               │  │   │
│   │   │   样本2: 输入测量值 103.0 mm → 系统自动评估 R               │  │   │
│   │   └─────────────────────────────────────────────────────────────┘  │   │
│   │                                                                       │   │
│   │   定性特性:                                                           │   │
│   │   ┌─────────────────────────────────────────────────────────────┐  │   │
│   │   │   样本1: 选择代码 A01 (无缺陷) → 评估 A                      │  │   │
│   │   │   样本2: 选择代码 R01 (划痕) → 评估 R                        │  │   │
│   │   └─────────────────────────────────────────────────────────────┘  │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   4. 特性评估                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   if 所有样本评估 = A:                                               │   │
│   │       特性评估 = A (接受)                                            │   │
│   │   else:                                                              │   │
│   │       特性评估 = R (拒收)                                            │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 4. 接口设计

### 4.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/qm/inspection-lots | GET | 检验批列表 |
| /api/qm/inspection-lots | POST | 创建检验批 |
| /api/qm/inspection-lots/{id} | GET | 检验批详情 |
| /api/qm/inspection-lots/{id}/characters | GET | 检验特性列表 |
| /api/qm/inspection-lots/{id}/results | GET | 检验结果列表 |
| /api/qm/inspection-lots/{id}/results | POST | 录入结果 |
