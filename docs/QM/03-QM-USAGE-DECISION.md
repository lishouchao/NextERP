# QM 使用决策

**模块**: Usage Decision
**对标**: SAP QA11/QA12
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 决策类型

| 代码 | 结果 | 说明 | 库存处理 |
|------|------|------|----------|
| A01 | AC | 接受 | 转入非限制库存 |
| A02 | AC | 接受 | 转入质检库存 |
| R01 | RJ | 拒收 | 退货给供应商 |
| R02 | RJ | 拒收 | 转入冻结库存 |
| R03 | SC | 报废 | 报废处理 |
| P01 | PR | 条件接受 | 让步接收 |

## 2. 决策字段

### 2.1 使用决策表 (qm_usage_decision)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| lot_id | UUID | 是 | 检验批ID |
| lot_number | VARCHAR(12) | 是 | 检验批号 |
| decision_code | VARCHAR(4) | 是 | 决策代码 |
| decision_text | VARCHAR(100) | 否 | 决策文本 |
| decision_result | VARCHAR(2) | 是 | 决策结果 |
| accepted_qty | DECIMAL(13,3) | 否 | 接受数量 |
| rejected_qty | DECIMAL(13,3) | 否 | 拒收数量 |
| scrapped_qty | DECIMAL(13,3) | 否 | 报废数量 |
| rework_qty | DECIMAL(13,3) | 否 | 返工数量 |
| is_stock_posted | BOOLEAN | 否 | 已过账到库存 |
| movement_type | VARCHAR(3) | 否 | 移动类型 |
| material_doc_id | UUID | 否 | 物料凭证ID |
| decision_date | DATE | 是 | 决策日期 |
| decision_by | UUID | 否 | 决策人 |
| remarks | TEXT | 否 | 备注 |

## 3. 条件接受

### 3.1 让步接收

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           让步接收处理                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   场景: 检验结果为R (拒收)，但经评估可以使用                                 │
│                                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   条件接受审批流程:                                                   │   │
│   │                                                                       │   │
│   │   1. 检验员发起让步接收申请                                           │   │
│   │      - 填写让步原因                                                   │   │
│   │      - 说明缺陷影响                                                   │   │
│   │                                                                       │   │
│   │   2. 技术评审                                                         │   │
│   │      - 技术部门确认是否可用                                           │   │
│   │      - 评估风险                                                       │   │
│   │                                                                       │   │
│   │   3. 审批                                                             │   │
│   │      - 质量经理审批                                                   │   │
│   │      - 必要时升级审批                                                 │   │
│   │                                                                       │   │
│   │   4. 执行                                                             │   │
│   │      - 按条件接受数量过账                                             │   │
│   │      - 记录让步信息                                                   │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   注: 条件接受物料需标记，后续使用时需特别关注                               │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
