# QM 质量通知

**模块**: Quality Notification
**对标**: SAP QM01/QM02
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 通知类型

| 类型 | 代码 | 说明 | 使用场景 |
|------|------|------|----------|
| 客户投诉 | Q1 | 客户质量问题 | 客户反馈缺陷 |
| 内部问题 | Q2 | 内部质量问题 | 过程中发现 |
| 供应商问题 | Q3 | 供应商质量问题 | 来料缺陷 |

## 2. 通知字段

### 2.1 通知头 (qm_notification)

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| notification_number | VARCHAR(12) | 是 | 通知单号 | QMEL |
| notification_type | VARCHAR(3) | 是 | 通知类型 | QMART |
| short_text | VARCHAR(100) | 是 | 简短描述 | QMTXT |
| long_text | TEXT | 否 | 详细描述 | - |
| priority | VARCHAR(2) | 否 | 优先级 | PRIOK |
| material_id | UUID | 否 | 物料ID | MATNR |
| batch_number | VARCHAR(10) | 否 | 批次号 | CHARG |
| lot_id | UUID | 否 | 检验批ID | - |
| customer_id | UUID | 否 | 客户ID | KUNUM |
| vendor_id | UUID | 否 | 供应商ID | LIFNUM |
| plant_id | UUID | 否 | 工厂ID | - |
| cost_center_id | UUID | 否 | 成本中心ID | - |
| reported_date | DATE | 是 | 报告日期 | QMDAT |
| due_date | DATE | 否 | 截止日期 | - |
| completion_date | DATE | 否 | 完成日期 | - |
| notification_status | VARCHAR(2) | 是 | 通知状态 | - |
| responsible_id | UUID | 否 | 责任人ID | - |

### 2.2 通知项目 (qm_notification_item)

| 字段 | 类型 | 说明 |
|------|------|------|
| notification_id | UUID | 通知ID |
| item_number | INTEGER | 项目号 |
| problem_type | VARCHAR(4) | 问题类型 |
| problem_text | VARCHAR(100) | 问题描述 |
| object_type | VARCHAR(10) | 对象类型 |
| object_id | UUID | 对象ID |
| quantity | DECIMAL(13,3) | 数量 |
| unit | VARCHAR(3) | 单位 |
| item_status | VARCHAR(2) | 项目状态 |

### 2.3 通知任务 (qm_notification_task)

| 字段 | 类型 | 说明 |
|------|------|------|
| notification_id | UUID | 通知ID |
| item_id | UUID | 项目ID |
| task_number | INTEGER | 任务号 |
| task_type | VARCHAR(4) | 任务类型 |
| task_text | VARCHAR(100) | 任务描述 |
| responsible_id | UUID | 责任人ID |
| department | VARCHAR(50) | 部门 |
| planned_start | DATE | 计划开始 |
| planned_finish | DATE | 计划完成 |
| actual_start | DATE | 实际开始 |
| actual_finish | DATE | 实际完成 |
| task_status | VARCHAR(2) | 任务状态 |
| verified_by | UUID | 验证人 |
| verification_result | VARCHAR(2) | 验证结果 |

---

## 3. 任务类型

| 类型 | 代码 | 说明 | 使用场景 |
|------|------|------|----------|
| 纠正措施 | CAC | 纠正问题 | 立即解决问题 |
| 预防措施 | PAC | 防止再发 | 根本原因预防 |
| 立即措施 | IMM | 临时措施 | 紧急处理 |
| 分析任务 | ANA | 原因分析 | 8D分析 |

## 4. 处理流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           质量通知处理流程                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. 创建通知                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 选择通知类型 (Q1/Q2/Q3)                                         │   │
│   │   - 填写问题描述                                                     │   │
│   │   - 设置优先级                                                       │   │
│   │   - 分配责任人                                                       │   │
│   │   状态: 01 (创建)                                                    │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   2. 添加项目                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 记录具体问题点                                                   │   │
│   │   - 关联物料/批次                                                   │   │
│   │   - 记录影响数量                                                     │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   3. 分配任务                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   状态: 02 (处理中)                                                  │   │
│   │   - 创建纠正措施任务                                                 │   │
│   │   - 创建预防措施任务                                                 │   │
│   │   - 分配责任人                                                       │   │
│   │   - 设置截止日期                                                     │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   4. 执行与验证                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 责任人执行任务                                                   │   │
│   │   - 记录执行结果                                                     │   │
│   │   - 验证措施有效性                                                   │   │
│   │   状态: 03 (完成)                                                    │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   5. 关闭通知                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 所有任务已完成                                                   │   │
│   │   - 验证通过                                                         │   │
│   │   - 状态: 04 (关闭)                                                  │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 5. 8D报告

### 5.1 8D步骤

| 步骤 | 名称 | 说明 |
|------|------|------|
| D1 | 成立团队 | 组建问题解决团队 |
| D2 | 问题描述 | 明确问题描述 |
| D3 | 临时措施 | 实施临时措施 |
| D4 | 根本原因 | 分析根本原因 |
| D5 | 永久措施 | 制定永久措施 |
| D6 | 措施实施 | 实施并验证措施 |
| D7 | 预防再发 | 防止问题再发 |
| D8 | 团队表彰 | 总结与表彰 |

## 6. 接口设计

### 6.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/qm/notifications | GET | 通知列表 |
| /api/qm/notifications | POST | 创建通知 |
| /api/qm/notifications/{id} | GET | 通知详情 |
| /api/qm/notifications/{id} | PUT | 更新通知 |
| /api/qm/notifications/{id}/items | GET | 通知项目列表 |
| /api/qm/notifications/{id}/items | POST | 添加项目 |
| /api/qm/notifications/{id}/tasks | GET | 通知任务列表 |
| /api/qm/notifications/{id}/tasks | POST | 添加任务 |
| /api/qm/notifications/{id}/close | POST | 关闭通知 |
