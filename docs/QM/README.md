# QM 质量管理模块

**对标**: SAP ECC QM / Oracle Quality
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 模块概述

QM (Quality Management) 模块负责管理企业的质量检验流程，从来料检验到成品出货，提供完整的质量管理能力。

### 核心能力

| 能力 | 说明 | 对标 |
|------|------|------|
| 检验计划 | 检验特性与方法 | QP01/QP02 |
| 检验批 | 来料/过程/成品检验 | QA01/QA02 |
| 结果记录 | 检验结果录入 | QE01/QE02 |
| 使用决策 | 检验判定 | QA11/QA12 |
| 质量通知 | 质量问题处理 | QM01/QM02 |

## 检验类型

| 类型 | 代码 | 说明 | 触发点 |
|------|------|------|--------|
| 来料检验 | 01 | 采购入库检验 | 收货触发 |
| 过程检验 | 02 | 生产过程检验 | 工序完成 |
| 成品检验 | 03 | 完工入库检验 | 生产完工 |
| 库存检验 | 04 | 库存抽检 | 定期触发 |
| 退货检验 | 05 | 销售退货检验 | 退货入库 |

---

## 检验结果

| 结果 | 代码 | 说明 | 后续处理 |
|------|------|------|----------|
| 接受 | AC | 符合标准 | 库存转入非限制 |
| 拒收 | RJ | 不符合标准 | 退货/报废 |
| 条件接受 | PR | 让步接收 | 特批入库 |
| 报废 | SC | 严重缺陷 | 报废处理 |
