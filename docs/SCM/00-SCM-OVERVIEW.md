# SCM 供应链管理模块总览

**模块**: Supply Chain Management (供应链管理)
**对标**: SAP SCM / Oracle SCM Cloud / Kinaxis
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 模块概述

### 1.1 功能范围

SCM模块负责企业供应链的全流程管理，从需求预测到物流配送：

| 子模块 | 功能 | 对标 |
|--------|------|------|
| 需求管理 | 需求预测、销售计划 | SAP DP |
| 供应计划 | 供应计划、MRP运行 | SAP PP/DS |
| 库存优化 | 安全库存、补货策略 | SAP inventory Optimization |
| 物流管理 | 发货、运输、跟踪 | SAP TM |
| 供应链协同 | 供应商协同、VMI | SAP SNC |

### 3.2 MRP流程

```
MRP (物料需求计划) 运行流程:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   1. 数据准备                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   输入: 主生产计划(MPS) + 销售订单 + 预测 + 库存 + BOM + 提前期       │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                          │                                                  │
│                          ▼                                                  │
│   2. 计算毛需求                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   毛需求 = 独立需求 + 相关需求                                        │  │
│   │   独立需求: 销售订单、预测                                            │  │
│   │   相关需求: BOM展开的组件需求                                         │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                          │                                                  │
│                          ▼                                                  │
│   3. 计算净需求                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   净需求 = 毛需求 - 计划入库 - 现有库存 + 安全库存 - 已分配库存       │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                          │                                                  │
│                          ▼                                                  │
│   4. 生成计划订单                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   if 净需求 > 0:                                                     │  │
│   │       计划订单量 = 批量规则(净需求)                                   │  │
│   │       计划订单日期 = 需求日期 - 提前期                                │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                          │                                                  │
│                          ▼                                                  │
│   5. 下达执行                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   自制 → 转生产订单 (PP)                                             │  │
│   │   外购 → 转采购申请 (MM)                                             │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 4. 库存策略

### 4.1 ABC分类

```
ABC库存分类:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   分类    占品种%    占金额%    管理策略           检查周期                   │
│   ─────────────────────────────────────────────────────────────────────    │
│   A类     10-20%     70-80%    重点管理，精确控制   每日/每周                 │
│   B类     20-30%     15-25%    正常管理，适度控制   每周/每两周               │
│   C类     50-60%      5-10%    简化管理，批量采购   每月/每季                 │
│   ─────────────────────────────────────────────────────────────────────    │
│                                                                             │
│   管理策略:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   A类: 安全库存低、频繁盘点、供应商密切合作                          │  │
│   │   B类: 安全库存中等、定期盘点、供应商正常合作                        │  │
│   │   C类: 安全库存较高、批量采购、简化流程                              │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.2 服务水平

| 服务水平% | Z值 | 说明 | 适用场景 |
|-----------|-----|------|----------|
| 99% | 2.33 | 极高 | 关键物料、A类 |
| 95% | 1.65 | 高 | 重要物料 |
| 90% | 1.28 | 中等 | 一般物料 |
| 85% | 1.04 | 较低 | C类物料 |

## 5. 物流模式

### 5.1 运输方式

| 方式 | 代码 | 时效 | 成本 | 适用场景 |
|------|------|------|------|----------|
| 公路 | 01 | 1-3天 | 中 | 短途、门到门 |
| 铁路 | 02 | 3-7天 | 低 | 长途、大宗 |
| 海运 | 03 | 15-45天 | 极低 | 国际、大批量 |
| 空运 | 04 | 1-3天 | 高 | 紧急、高价值 |
| 快递 | 05 | 1-2天 | 极高 | 小件、紧急 |
