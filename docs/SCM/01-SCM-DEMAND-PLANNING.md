### 1.3 预测方法

| 方法 | 代码 | 说明 | 适用场景 |
|------|------|------|------|
| 移动平均 | 01 | 简单、数据稳定 | 猎取稳定、需求 |
| 指数平滑 | 02 | 近期趋势、 中等波动 |
| 季节分解 | 03 | 季节性强 | 零售波动大 |
| ARIMA | 04 | 复杂模式 | 高波动、长期预测 |
| 机器学习 | 05 | 鼠策略、 新产品、 精度高价值 |

| 人工判断 | 06 | 经验判断 | 管理层决策 |

### 1.4 预测准确性度量

| 指标 | 说明 | 计算公式 |
|------|------|------|--------|
| MAPE | 平均绝对百分比误差 | (预测值 - 实际值) / 实际值 × 100% |
| RMSE | 儒-均方误差 | √[(预测值 - 实际值)² / ∆(Σ(预测值)) |
| 预测偏差率 | (实际值 - 预测值) / 预测值 × 100% |

**示例:**
```
实际销售: 1000件，预测销售: 950件
MAPE = 950
RMSE = 52.6件
预测偏差率 = (1000-950) / 950 × 100 = 5.5%
```
