# SCM 供应计划设计

**模块**: Supply Planning (供应计划)
**对标**: SAP PP/DS / Oracle ASCP
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

供应计划负责将需求转化为可执行的供应计划：

| 功能 | 说明 | 对标 |
|------|------|------|
| MPS主生产计划 | 独立需求计划 | SAP MPS |
| MRP物料需求计划 | 相关需求计划 | SAP MRP |
| 产能规划 | 产能平衡分析 | SAP Capacity Planning |
| 供应网络 | 多节点供应规划 | SAP Network Design |

## 2. MPS主生产计划

### 2.1 MPS字段 (scm_supply_plan)

| 字段 | 类型 | 说明 | 对标 |
|------|------|------|------|
| plan_number | VARCHAR(12) | 计划编号 | Plan Number |
| plan_name | VARCHAR(100) | 计划名称 | Plan Name |
| plan_type | VARCHAR(2) | 计划类型 | Plan Type (01:MPS) |
| start_date | DATE | 开始日期 | Start Date |
| end_date | DATE | 结束日期 | End Date |
| planning_horizon | INTEGER | 计划跨度(天) | Horizon |
| run_mode | VARCHAR(2) | 运行模式 | Run Mode |
| plan_status | VARCHAR(2) | 计划状态 | Status |

### 2.2 MPS计划类型

| 类型 | 代码 | 说明 | 适用场景 |
|------|------|------|----------|
| MPS | 01 | 主生产计划 | 成品、贸易商品 |
| MRP | 02 | 物料需求计划 | 所有物料 |
| DRP | 03 | 分销需求计划 | 多地点分销 |

### 2.3 运行模式

| 模式 | 代码 | 说明 | 特点 |
|------|------|------|------|
| 净改变 | 01 | 仅计算变化部分 | 快速、增量更新 |
| 再生式 | 02 | 重新计算所有物料 | 完整、耗时较长 |
| 模拟 | 03 | 模拟运行不 不影响实际数据 |

### 2.4 MPS明细 (scm_supply_plan_item)

| 字段 | 类型 | 说明 |
|------|------|------|
| product_id | UUID | 产品ID |
| plant_id | UUID | 工厂ID |
| plan_date | DATE | 计划日期 |
| gross_requirement | DECIMAL(13,3) | 毛需求 |
| scheduled_receipt | DECIMAL(13,3) | 计划入库 |
| on_hand | DECIMAL(13,3) | 现有库存 |
| safety_stock | DECIMAL(13,3) | 安全库存 |
| net_requirement | DECIMAL(13,3) | 净需求 |
| planned_order | DECIMAL(13,3) | 计划订单 |
| planned_receipt_date | DATE | 计划入库日期 |
| planned_release_date | DATE | 计划下达日期 |

## 3. MRP计算逻辑

### 3.1 计算流程

```
MRP计算流程:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   1. 初始化                                                                    │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   加载: 主生产计划(MPS) + 销售订单 + 预测 + 库存 + BOM + 提前期     │   │
│   │   初始化: 物料主数据、库存数据、BOM、提前期                        │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│   2. 顶层需求处理 (Level 0 - 成品)                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   FOR each 成品:                                                     │   │
│   │       毛需求 = 销售订单 + 预测 - 已分配库存                           │   │
│   │       计划入库 = 生产订单 + 采购订单 + 调拨单                             │   │
│   │       净需求 = 毛需求 - 计划入库 - 现有库存 + 安全库存              │   │
│   │       IF 净需求 > 0:                                                   │   │
│   │           计划订单 = 批量规则(净需求)                                   │   │
│   │           计划入库日期 = 需求日期 - 提前期                                │   │
│   │           计划下达日期 = 计划入库日期 - 提前期                                │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│   3. BOM展开 (Level 1+ - 组件/原材料)                                     │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   FOR each 计划订单(成品):                                           │   │
│   │       相关需求 = 计划订单 × BOM用量                                   │   │
│   │       对每个组件执行步骤2的计算逻辑                                     │   │
│   │       递归展开直到最底层原材料                                   │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│   4. 异常处理                                                                   │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   检查: 逾期订单、短缺、产能不足                                    │   │
│   │   生成异常信息， 通知计划员                                          │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                    │                                        │
│                                    ▼                                        │
│   5. 结果输出                                                                   │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   计划订单列表 (planned_orders)                                          │   │
│   │   采购建议 (purchase_recommendations)                                   │   │
│   │   异常报告 (exception_report)                                             │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.2 计算公式

```
净需求计算:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   净需求 = MAX(0, 毛需求 - 计划入库 - 现有库存 + 安全库存)                        │
│                                                                             │
│   其中:                                                                        │
│   毛需求 (Gross Requirement)                                                │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   独立需求: 销售订单、预测                                             │   │
│   │   相关需求: BOM展开的组件需求 (父件计划订单 × BOM用量)            │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   计划入库 (Scheduled Receipt)                                              │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   未结生产订单 (按计划完成日期)                                         │   │
│   │   未结采购订单 (按计划交货日期)                                         │   │
│   │   调拨在途 (按预计到达日期)                                             │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   现有库存 (On-hand Inventory)                                              │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   非限制使用库存                                                   │   │
│   │   可用库存 (非限制 - 冻结 - 质检)                                  │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   安全库存 (Safety Stock)                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   为应对需求波动而设置的缓冲库存                                │   │
│   │   计算公式: Z × √(LT × σd² + d² × σLT²)                             │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   计划订单 (Planned Order)                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   订单数量 = 批量规则(净需求)                                         │   │
│   │   订单日期 = 需求日期 - 提前期                                            │   │
│   │   下达日期 = 订单日期 - 处理提前期                                 │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 6. 异常处理

### 6.1 MRP异常类型

| 异常类型 | 代码 | 说明 | 处理建议 |
|----------|------|------|----------|
| 逾期订单 | 01 | 订单无法按期完成 | 加急、拆分 |
| 短缺 | 02 | 库存不足 | 紧急采购、替代物料 |
| 产能不足 | 03 | 生产能力不足 | 加班、外包 |
| 提前期不足 | 04 | 供应商交货延迟 | 催货、更换供应商 |
