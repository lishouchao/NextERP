# SCM 库存优化设计

**模块**: Inventory Optimization (库存优化)
**对标**: SAP Inventory Optimization / Oracle Inventory Optimization
**版本**: 1.0
**更新日期**: 2026-03-16

## 1. 概述

### 1.1 功能范围

库存优化负责确定最优库存策略以降低成本并提高服务水平：

| 功能 | 说明 | 对标 |
|------|------|------|
| 库存策略 | 定义补货策略 | Reorder Policy |
| 安全库存 | 计算安全库存水平 | Safety Stock |
| 补货计划 | 自动补货建议 | Replenishment |
| 库存分布 | 多地点库存优化 | Multi-echelon |

## 2. 库存策略

### 2.1 库存策略类型

| 策略类型 | 代码 | 说明 | 适用场景 |
|----------|------|------|----------|
| 连续盘点 | 01 | 实时监控，低于再订货点即补货 | 高价值物料 |
| 定期盘点 | 02 | 固定周期检查，按需补货 | 一般物料 |
| 双箱法 | 03 | 两箱库存，一箱用完即补货 | 低价值、标准件 |
| ABC分类 | 04 | 按价值和重要性分类管理 | 混合物料 |

### 2.2 库存策略字段 (scm_inventory_policy)

| 字段 | 类型 | 说明 |
|------|------|------|
| policy_code | VARCHAR(10) | 策略编码 |
| policy_name | VARCHAR(100) | 策略名称 |
| policy_type | VARCHAR(2) | 策略类型 |
| product_id | UUID | 产品ID |
| plant_id | UUID | 工厂ID |
| reorder_point | DECIMAL(13,3) | 再订货点 |
| reorder_quantity | DECIMAL(13,3) | 订货批量 |
| max_stock | DECIMAL(13,3) | 最大库存 |
| min_stock | DECIMAL(13,3) | 最小库存 |
| service_level | DECIMAL(5,2) | 服务水平% |
| review_cycle | INTEGER | 盘点周期(天) |

### 2.3 再订货点计算

```
再订货点计算:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   再订货点 (ROP) = 平均日需求 × 提前期 + 安全库存                          │
│                                                                             │
│   示例:                                                                      │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   平均日需求: 100 件/天                                            │  │
│   │   提前期: 7 天                                                       │  │
│   │   安全库存: 200 件                                                   │  │
│   │                                                                     │  │
│   │   再订货点 = 100 × 7 + 200 = 900 件                                 │  │
│   │                                                                     │  │
│   │   含义: 当库存降到 900 件以下时，需要发起补货                         │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 3. 安全库存

### 3.1 服务水平与Z值

| 服务水平% | Z值 | 说明 | 适用场景 |
|-----------|-----|------|----------|
| 99.9% | 3.09 | 极高 | 关键物料 |
| 99% | 2.33 | 很高 | A类物料 |
| 95% | 1.65 | 高 | B类物料 |
| 90% | 1.28 | 中等 | C类物料 |
| 85% | 1.04 | 较低 | 低价值物料 |

### 3.2 安全库存计算

```
安全库存计算公式:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   标准公式:                                                                  │
│   SS = Z × √(LT × σd² + d² × σLT²)                                        │
│                                                                             │
│   简化公式 (假设提前期恒定):                                                 │
│   SS = Z × σd × √LT                                                        │
│                                                                             │
│   其中:                                                                      │
│   Z = 服务水平对应的Z值                                                      │
│   LT = 平均提前期                                                            │
│   σd = 需求标准差                                                            │
│   d = 平均需求                                                                │
│   σLT = 提前期标准差                                                          │
│                                                                             │
│   示例:                                                                      │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   服务水平: 95% (Z = 1.65)                                         │  │
│   │   平均提前期: 7 天                                                   │  │
│   │   需求标准差: 25 件/天                                               │  │
│   │                                                                     │  │
│   │   安全库存 = 1.65 × 25 × √7 = 109 件                                 │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.3 安全库存字段 (scm_safety_stock)

| 字段 | 类型 | 说明 |
|------|------|------|
| product_id | UUID | 产品ID |
| plant_id | UUID | 工厂ID |
| avg_demand | DECIMAL(13,3) | 平均需求 |
| demand_variability | DECIMAL(13,3) | 需求波动(标准差) |
| avg_lead_time | DECIMAL(10,2) | 平均提前期(天) |
| lead_time_variability | DECIMAL(10,2) | 提前期波动(天) |
| service_level | DECIMAL(5,2) | 服务水平% |
| safety_stock_qty | DECIMAL(13,3) | 安全库存数量 |
| calculation_date | DATE | 计算日期 |

## 4. 补货计划

### 4.1 补货计划字段 (scm_replenishment)

| 字段 | 类型 | 说明 |
|------|------|------|
| replen_number | VARCHAR(12) | 补货单号 |
| replen_type | VARCHAR(2) | 补货类型 (01:自动 02:手动 03:调拨) |
| product_id | UUID | 产品ID |
| plant_id | UUID | 工厂ID |
| current_stock | DECIMAL(13,3) | 当前库存 |
| safety_stock | DECIMAL(13,3) | 安全库存 |
| replen_qty | DECIMAL(13,3) | 补货数量 |
| source_type | VARCHAR(2) | 来源类型 (01:采购 02:生产 03:调拨) |
| required_date | DATE | 需求日期 |
| replen_status | VARCHAR(2) | 补货状态 |

### 4.2 补货状态

| 状态 | 代码 | 说明 | 操作 |
|------|------|------|------|
| 待审批 | 01 | 等待审批 | 审批、拒绝 |
| 已审批 | 02 | 已批准 | 下达 |
| 已下达 | 03 | 已转采购/生产 | 跟踪 |
| 已完成 | 04 | 已到货 | 关闭 |
| 已取消 | 05 | 已取消 | - |

### 4.3 补货计算示例

```
补货计算示例:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   物料: MAT-001                                                             │
│   ─────────────────────────────────────────────────────────────────────    │
│                                                                             │
│   当前库存:     500 件                                                      │
│   安全库存:     200 件                                                      │
│   在途数量:     100 件                                                      │
│   未结订单:     150 件                                                      │
│                                                                             │
│   计算净需求:                                                                │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   可用库存 = 当前库存 + 在途 + 未结订单 = 500 + 100 + 150 = 750 件 │  │
│   │   净需求 = 安全库存 - 可用库存 = 200 - 750 = -550 件                │  │
│   │                                                                     │  │
│   │   净需求为负，说明可用库存超过安全库存，无需补货                │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   若净需求为正:                                                              │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   假设可用库存 = 100 件                                            │  │
│   │   净需求 = 200 - 100 = 100 件                                        │  │
│   │   补货数量 = MAX(净需求, 最小订货量)                                 │  │
│   │   假设最小订货量 = 200 件，则补货数量 = 200 件                        │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 5. 库存分布优化

### 5.1 多级库存模型

```
多级库存分布:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│                        中央仓库 (Central Warehouse)                         │
│                        库存: 10,000 件                                      │
│                           ┌───────────────────┐                             │
│                           │                   │                             │
│              ┌────────────┴─────────┐         │                             │
│              │                        │         │                             │
│              ▼                        ▼         ▼                             │
│    ┌─────────────────┐        ┌─────────────────┐                            │
│    │  区域仓库 A      │        │  区域仓库 B      │                            │
│    │  库存: 2,000 件  │        │  库存: 1,500 件  │                            │
│    └────────┬────────┘        └────────┬────────┘                            │
│              │                        │                                      │
│              ▼                        ▼                                      │
│    ┌─────────────────┐        ┌─────────────────┐                            │
│    │  前置仓 A1       │        │  前置仓 B1       │                            │
│    │  库存: 500 件    │        │  库存: 300 件    │                            │
│    └─────────────────┘        └─────────────────┘                            │
│                                                                             │
│   优化目标:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   1. 最小化总库存成本                                                │  │
│   │   2. 满足各节点服务水平要求                                            │  │
│   │   3. 平衡运输成本与库存持有成本                                        │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 5.2 库存分配策略

| 策略 | 说明 | 适用场景 |
|------|------|----------|
| 推式分配 | 从中央向区域推送 | 需求稳定 |
| 拉式分配 | 从区域向中央拉动 | 需求波动大 |
| 混合分配 | 推拉结合 | 季节性需求 |
