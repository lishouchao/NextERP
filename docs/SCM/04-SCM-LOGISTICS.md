# SCM 物流管理设计

**模块**: Logistics Management (物流管理)
**对标**: SAP TM / Oracle Transportation Management
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

物流管理负责产品的发货、运输和配送：

| 功能 | 说明 | 对标 |
|------|------|------|
| 发货管理 | 发货单创建与执行 | Shipment |
| 运输计划 | 运输方式选择与调度 | Transport Planning |
| 物流跟踪 | 实时物流状态跟踪 | Tracking |
| 签收管理 | POD签收确认 | POD Management |

## 2. 发货管理

### 2.1 发货单字段 (scm_shipment)

| 字段 | 类型 | 说明 | 对标 |
|------|------|------|------|
| shipment_number | VARCHAR(12) | 发货单号 | Shipment Number |
| shipment_type | VARCHAR(2) | 发货类型 | Shipment Type |
| ship_from_plant | UUID | 发货工厂 | Ship From |
| ship_to_party | UUID | 收货方 | Ship To |
| carrier_id | UUID | 承运商 | Carrier |
| transport_mode | VARCHAR(2) | 运输方式 | Transport Mode |
| planned_ship_date | DATE | 计划发货日期 | Planned Date |
| actual_ship_date | DATE | 实际发货日期 | Actual Date |
| shipment_status | VARCHAR(2) | 发货状态 | Status |
| freight_cost | DECIMAL(15,2) | 运费 | Freight Cost |

### 2.2 发货类型

| 类型 | 代码 | 说明 | 特点 |
|------|------|------|------|
| 销售发货 | 01 | 客户销售订单 | 直接销售 |
| 调拨发货 | 02 | 工厂/仓库间调拨 | 内部转移 |
| 退货发货 | 03 | 客户退货 | 反向物流 |
| 寄售发货 | 04 | 寄售库存补货 | VMI |

### 2.3 发货状态

| 状态 | 代码 | 说明 | 操作 |
|------|------|------|------|
| 待发货 | 01 | 等待发货 | 拣货、打包 |
| 已发货 | 02 | 已出库 | 运输 |
| 运输中 | 03 | 在途 | 跟踪 |
| 已到达 | 04 | 到达目的地 | 签收 |
| 已签收 | 05 | 客户已签收 | 完成 |
| 已取消 | 06 | 已取消 | - |

### 2.4 发货明细 (scm_shipment_item)

| 字段 | 类型 | 说明 |
|------|------|------|
| shipment_id | UUID | 发货单ID |
| line_number | INTEGER | 行号 |
| product_id | UUID | 产品ID |
| ordered_qty | DECIMAL(13,3) | 订单数量 |
| shipped_qty | DECIMAL(13,3) | 发货数量 |
| received_qty | DECIMAL(13,3) | 收货数量 |
| batch_number | VARCHAR(20) | 批次号 |

## 3. 运输管理

### 3.1 运输方式

| 方式 | 代码 | 说明 | 时效 | 成本 | 适用场景 |
|------|------|------|------|------|----------|
| 公路 | 01 | 卡车运输 | 1-3天 | 中 | 短途、灵活 |
| 铁路 | 02 | 火车运输 | 3-7天 | 低 | 长途、大宗 |
| 海运 | 03 | 船运 | 15-45天 | 极低 | 国际、大批量 |
| 空运 | 04 | 飞机运输 | 1-3天 | 高 | 紧急、高价值 |
| 快递 | 05 | 快递服务 | 1-2天 | 极高 | 小件、紧急 |

### 3.3 运输成本计算

```
运输成本计算:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   总成本 = 基础运费 + 附加费用                                              │
│                                                                             │
│   基础运费:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   公路: 按公里 × 吨位/体积                                          │  │
│   │   铁路: 按车皮/集装箱计费                                            │  │
│   │   海运: 按集装箱/体积计费                                            │  │
│   │   空运: 按重量(公斤)计费                                             │  │
│   │   快递: 按重量 + 体积(取大)计费                                      │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   附加费用:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   提货费: 工厂提货费用                                               │  │
│   │   送货费: 送货上门费用                                               │  │
│   │   保险费: 货物保险                                                   │  │
│   │   仓储费: 中转仓储                                                   │  │
│   │   保费: 加急/节假日                                                  │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 4. 物流跟踪

### 4.1 跟踪状态

| 状态 | 代码 | 说明 | 触发条件 |
|------|------|------|----------|
| 已揽收 | 01 | 承运商已取件 | 揽收扫描 |
| 运输中 | 02 | 在途运输 | 离开网点 |
| 中转 | 03 | 到达中转站 | 中转扫描 |
| 派送中 | 04 | 正在派送 | 开始派送 |
| 已签收 | 05 | 收货人签收 | 签收确认 |
| 异常 | 06 | 物流异常 | 异常上报 |

### 4.2 跟踪记录 (scm_tracking)

| 字段 | 类型 | 说明 |
|------|------|------|
| shipment_id | UUID | 发货单ID |
| tracking_number | VARCHAR(50) | 物流单号 |
| tracking_time | TIMESTAMP | 跟踪时间 |
| location | VARCHAR(100) | 当前位置 |
| tracking_status | VARCHAR(2) | 跟踪状态 |
| status_desc | VARCHAR(200) | 状态描述 |
| operator | VARCHAR(40) | 操作人 |

### 4.3 物流异常处理

| 异常类型 | 代码 | 说明 | 处理方式 |
|----------|------|------|----------|
| 延误 | 01 | 未按期到达 | 催促、赔偿 |
| 破损 | 02 | 货物损坏 | 理赔、补发 |
| 丢失 | 03 | 货物丢失 | 报警、理赔 |
| 地址错误 | 04 | 送错地址 | 转寄、退回 |
| 拒收 | 05 | 收货人拒收 | 退回、协商 |

## 5. 签收管理

### 5.1 签收流程

```
签收流程:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   1. 到达通知                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   └── 系统自动发送短信/邮件通知收货人                                 │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                          │                                                  │
│                          ▼                                                  │
│   2. 验货                                                                   │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   ┌─────────────────────────────────────────────────────────────┐  │  │
│   │   │   检查外包装完好性                                           │  │  │
│   │   │   清点数量                                                   │  │  │
│   │   │   抽检质量 (可选)                                            │  │  │
│   │   └─────────────────────────────────────────────────────────────┘  │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                          │                                                  │
│                          ▼                                                  │
│   3. 签收确认                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   ┌─────────────────────────────────────────────────────────────┐  │  │
│   │   │   正常签收: 确认收货，更新状态                                 │  │  │
│   │   │   部分签收: 记录实收数量，标注差异                             │  │  │
│   │   │   拒收: 记录拒收原因，退回处理                                 │  │  │
│   │   └─────────────────────────────────────────────────────────────┘  │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                          │                                                  │
│                          ▼                                                  │
│   4. POD回传                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   └── 签收凭证(签名/照片)上传，完成发货流程                           │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 5.2 签收结果

| 结果 | 代码 | 说明 | 后续操作 |
|------|------|------|----------|
| 正常签收 | 01 | 全部签收 | 订单完成 |
| 部分签收 | 02 | 部分签收 | 差异处理 |
| 拒收 | 03 | 拒绝签收 | 退货处理 |

## 6. 接口设计
| 接口 | 方法 | 说明 |
|------|------|------|
| /api/scm/shipments | GET | 发货列表 |
| /api/scm/shipments | POST | 创建发货单 |
| /api/scm/shipments/{id} | GET | 发货详情 |
| /api/scm/shipments/{id} | PUT | 更新发货 |
| /api/scm/shipments/{id}/ship | POST | 发货出库 |
| /api/scm/shipments/{id}/track | GET | 物流跟踪 |
| /api/scm/shipments/{id}/receive | POST | 签收确认 |
| /api/scm/carriers | GET | 承运商列表 |
| /api/scm/carriers/{id}/performance | GET | 承运商绩效 |
