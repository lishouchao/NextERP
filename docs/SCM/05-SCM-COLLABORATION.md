# SCM 供应链协同设计

**模块**: Supply Chain Collaboration (供应链协同)
**对标**: SAP SNC / Oracle Supply Chain Collaboration
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

供应链协同负责与供应商的协作和信息共享：

| 功能 | 说明 | 对标 |
|------|------|------|
| 供应商协同 | 需求预测共享 | SAP SNC |
| VMI库存 | 供应商管理库存 | Vendor Managed Inventory |
| CPFR | 协同计划预测补货 | Collaborative Planning |
| 供应商承诺 | 库存交货承诺 | Supplier Commitment |

## 2. 供应商协同

### 2.1 协同配置 (scm_supplier_collab)

| 字段 | 类型 | 说明 |
|------|------|------|
| collab_number | VARCHAR(12) | 协同编号 |
| collab_type | VARCHAR(2) | 协同类型 |
| supplier_id | UUID | 供应商ID |
| product_id | UUID | 产品ID |
| share_forecast | BOOLEAN | 共享预测 |
| share_inventory | BOOLEAN | 共享库存 |
| share_order | BOOLEAN | 共享订单 |
| horizon_days | INTEGER | 展望期(天) |
| refresh_cycle | INTEGER | 刷新周期(天) |

### 2.2 协同类型

| 类型 | 代码 | 说明 | 共享内容 |
|------|------|------|----------|
| 需求预测共享 | 01 | 共享预测 | 预测数据 |
| 库存信息共享 | 02 | 共享库存 | 库存水平 |
| 订单协同 | 03 | 共享订单 | 采购订单 |
| 产能协同 | 04 | 共享产能 | 产能信息 |

### 2.3 数据共享策略

```
数据共享配置:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   共享内容           共享级别       更新频率       可见范围                 │
│   ─────────────────────────────────────────────────────────────────────    │
│   需求预测           产品级         每周           未来12周                  │
│   库存水平           产品+仓库       每日           当前库存                  │
│   在途订单           订单级         实时           未交货订单                │
│   消耗记录           产品级         每日           最近30天消耗              │
│   ─────────────────────────────────────────────────────────────────────    │
│                                                                             │
│   数据脱敏:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   敏感字段可选择不共享:                                              │  │
│   │   • 客户名称 → 可选脱敏                                               │  │
│   │   • 具体价格 → 可选隐藏                                               │  │
│   │   • 利润信息 → 不共享                                                 │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 3. VMI库存管理

### 3.1 VMI字段 (scm_vmi_inventory)

| 字段 | 类型 | 说明 |
|------|------|------|
| supplier_id | UUID | 供应商ID |
| product_id | UUID | 产品ID |
| plant_id | UUID | 工厂ID |
| sloc_id | UUID | 库位ID |
| on_hand_qty | DECIMAL(13,3) | 现有库存 |
| min_qty | DECIMAL(13,3) | 最小库存 |
| max_qty | DECIMAL(13,3) | 最大库存 |
| consumption_qty | DECIMAL(13,3) | 消耗数量 |
| settlement_type | VARCHAR(2) | 结算方式 |

### 3.2 VMI流程

```
VMI (供应商管理库存) 流程:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   1. 库存监控                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   └── 供应商实时查看客户库存水平                                     │  │
│   │       监控库存是否低于最小库存                                       │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                          │                                                  │
│                          ▼                                                  │
│   2. 补货决策                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   ┌─────────────────────────────────────────────────────────────┐  │  │
│   │   │   if 库存 < 最小库存:                                         │  │  │
│   │   │       供应商决定补货数量                                         │  │  │
│   │   │       补货数量 = MIN(max_qty - 当前库存, 供应商产能)             │  │  │
│   │   └─────────────────────────────────────────────────────────────┘  │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                          │                                                  │
│                          ▼                                                  │
│   3. 发货通知                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   └── 供应商创建发货计划                                               │  │
│   │       通知客户即将到货                                                 │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                          │                                                  │
│                          ▼                                                  │
│   4. 收货入库                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   └── 客户收货入库，库存增加                                           │  │
│   │       VMI库存所有权仍归供应商                                           │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                          │                                                  │
│                          ▼                                                  │
│   5. 消耗结算                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   ┌─────────────────────────────────────────────────────────────┐  │  │
│   │   │   按消耗结算: 客户实际使用后才结算                                 │  │  │
│   │   │   按入库结算: 入库时即结算                                           │  │  │
│   │   │   定期结算: 按周期统一结算                                           │  │  │
│   │   └─────────────────────────────────────────────────────────────┘  │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.3 结算方式

| 方式 | 代码 | 说明 | 特点 |
|------|------|------|------|
| 按消耗 | 01 | 使用后结算 | 客户资金压力小 |
| 按入库 | 02 | 入库时结算 | 供应商资金回笼快 |
| 定期结算 | 03 | 周期结算 | 简化管理 |

## 4. 供应商承诺

### 4.1 承诺字段 (scm_supplier_commit)

| 字段 | 类型 | 说明 |
|------|------|------|
| supplier_id | UUID | 供应商ID |
| product_id | UUID | 产品ID |
| plant_id | UUID | 工厂ID |
| commit_date | DATE | 承诺日期 |
| committed_qty | DECIMAL(13,3) | 承诺数量 |
| commit_status | VARCHAR(2) | 承诺状态 |
| delivered_qty | DECIMAL(13,3) | 已交付数量 |

### 4.2 承诺状态

| 状态 | 代码 | 说明 | 操作 |
|------|------|------|------|
| 已承诺 | 01 | 供应商已承诺 | 跟踪 |
| 部分交付 | 02 | 部分已交付 | 继续跟踪 |
| 完全交付 | 03 | 全部交付 | 完成 |
| 已取消 | 04 | 承诺取消 | 关闭 |

## 5. CPFR协同

### 5.1 CPFR流程

```
CPFR (协同计划、预测与补货) 流程:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   阶段          活动                    参与方               输出              │
│   ─────────────────────────────────────────────────────────────────────    │
│                                                                             │
│   1. 战略规划    协作协议                  双方               合作框架          │
│                  目标设定                                                     │
│                                                                             │
│   2. 需求计划    销售预测                  零售商             需求预测          │
│                  促销计划                                                     │
│                                                                             │
│   3. 供应计划    产能规划                  供应商             供应计划          │
│                  库存规划                                                     │
│                                                                             │
│   4. 协同预测    预测共享                  双方               协同预测          │
│                  差异识别                  双方               差异报告          │
│                  差异解决                  双方               一致预测          │
│                                                                             │
│   5. 补货计划    订单预测                  双方               补货计划          │
│                  库存补货                                                     │
│                                                                             │
│   6. 执行监控    订单执行                  双方               执行状态          │
│                  异常处理                                                     │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 5.2 CPFR收益

| 收益 | 说明 | 预期效果 |
|------|------|----------|
| 库存降低 | 减少安全库存 | 降低15-30% |
| 缺货减少 | 提高服务水平 | 降低50-80% |
| 预测准确 | 提高预测精度 | 提高20-40% |
| 成本降低 | 降低总成本 | 降低10-20% |
