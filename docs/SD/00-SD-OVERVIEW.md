# SD 销售与分销模块总览

**模块**: Sales and Distribution (销售与分销)
**对标**: SAP ECC SD (Sales and Distribution)
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 模块概述

### 1.1 功能范围

SD模块是NextERP的核心业务模块，负责管理企业销售业务的全流程：

| 子模块 | 功能 | SAP 对标 |
|--------|------|----------|
| 销售订单 | 订单创建与管理 | VA01/VA02/VA03 |
| 交货管理 | 出库与发运 | VL01N/VL02N |
| 开票管理 | 发票与贷项凭证 | VF01/VF02 |
| 定价管理 | 价格与折扣 | VK11/VK12 |
| 信用管理 | 信用检查与控制 | FD32 |

## 2. 销售范围

### 2.1 销售范围概念

销售范围是SD模块的核心组织概念，由三个要素组成：

```
销售范围 (Sales Area) = 销售组织 + 分销渠道 + 产品组

┌────────────────────────────────────────────────────────────────────────────┐
│                           销售范围结构                                      │
├────────────────────────────────────────────────────────────────────────────┤
│                                                                            │
│   销售组织 (Sales Organization)                                            │
│   ┌────────────────────────────────────────────────────────────────────┐  │
│   │                                                                    │  │
│   │   1000 - 华东销售区                                                │  │
│   │   ├── 分销渠道 10 - 批发                                           │  │
│   │   │   ├── 产品组 01 - 消费品    → 销售范围: 1000/10/01            │  │
│   │   │   └── 产品组 02 - 工业品    → 销售范围: 1000/10/02            │  │
│   │   │                                                                │  │
│   │   ├── 分销渠道 20 - 零售                                           │  │
│   │   │   ├── 产品组 01 - 消费品    → 销售范围: 1000/20/01            │  │
│   │   │   └── 产品组 02 - 工业品    → 销售范围: 1000/20/02            │  │
│   │   │                                                                │  │
│   │   └── 分销渠道 30 - 直销                                           │  │
│   │       └── 产品组 01 - 消费品    → 销售范围: 1000/30/01            │  │
│   │                                                                    │  │
│   │   2000 - 华北销售区                                                │  │
│   │   └── ...                                                          │  │
│   │                                                                    │  │
│   └────────────────────────────────────────────────────────────────────┘  │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 分销渠道

| 代码 | 名称 | 说明 | 适用场景 |
|------|------|------|----------|
| 10 | 批发 | 批量销售给经销商 | B2B批发业务 |
| 20 | 零售 | 零售终端销售 | 门店销售 |
| 30 | 直销 | 直接销售给终端客户 | 大客户直销 |
| 40 | 电商 | 电子商务渠道 | 线上销售 |

### 2.3 产品组

| 代码 | 名称 | 说明 | 业务特点 |
|------|------|------|----------|
| 01 | 消费品 | 快消品、日用品 | 高频、低单价 |
| 02 | 工业品 | 工业设备、原料 | 低频、高单价 |
| 03 | 服务 | 服务类产品 | 无实物交付 |

### 3.2 销售订单类型

| 订单类型 | 代码 | 说明 | 业务场景 |
|----------|------|------|----------|
| 标准订单 | OR | 正常销售订单 | 常规销售业务 |

| 借项订单 | DR | 借项凭证申请 | 价格补差 |
| 退货订单 | RE | 退货处理 | 客户退货 |

## 4. 定价机制

### 4.1 定价过程

```
定价过程示例 (Pricing Procedure):
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   步骤  条件类型  描述           从   到   计算         结果                │
│   ─────────────────────────────────────────────────────────────────────    │
│   10    PR00     销售价格                                  1,000.00         │
│   20    K004     客户折扣%                        -10%     -100.00          │
│   30             小计1          10   10            900.00                   │
│   40    K007     附加费                                  +50.00            │
│   50             净值          10   40            950.00                   │
│   60    MWST     销项税          50         13%      123.50                 │
│   70             含税金额        10   60          1,073.50                  │
│   80    SKTO     现金折扣                              统计性              │
│   ─────────────────────────────────────────────────────────────────────    │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.2 条件类型

| 条件类型 | 名称 | 计算类型 | 说明 |
|----------|------|----------|------|
| PR00 | 价格 | 固定金额 | 基础销售价格 |
| K004 | 折扣 | 百分比 | 客户折扣 |
| K007 | 附加费 | 百分比/金额 | 运费等附加 |
| MWST | 税 | 百分比 | 销项税 |
| SKTO | 现金折扣 | 百分比 | 付款折扣 |

### 5.2 信用状态

| 状态 | 代码 | 说明 | 影响 |
