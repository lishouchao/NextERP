# SD 销售订单管理设计

**模块**: Sales Order Management (销售订单管理)
**对标**: SAP SD - VA01/VA02/VA03
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

销售订单管理是SD模块的核心功能，负责处理从客户下单到订单完成的整个过程：

| 功能 | 说明 | SAP 对标 |
|------|------|----------|
| 订单创建 | 创建销售订单 | VA01 |
| 订单修改 | 修改订单信息 | VA02 |
| 订单查询 | 查看订单详情 | VA03 |
| 订单审批 | 订单审批流程 | 工作流 |
| 订单状态 | 状态管理与跟踪 | 状态概览 |

### 4.1 状态类型

```
订单状态体系:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │

│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                                                                     │  │
│   │   01 创建 ──► 02 审批 ──► 03 处理中 ──► 04 已完成 ──► 05 关闭      │  │
│   │     │           │           │            │            │             │  │
│   │     ▼           ▼           ▼            ▼            ▼             │  │
│   │   草稿       审批通过     交货处理     全部交货      订单关闭        │  │

│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │   A 未交货 → B 部分交货 → C 已交货                                  │  │
│   └─────────────────────────────────────────────────────────────────────┘  │

│   开票状态 (billing_status):                                                │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
```

### 4.2 状态限制

| 当前状态 | 允许操作 | 限制操作 |
|----------|----------|----------|
| 01-创建 | 编辑、删除、提交审批 | 创建交货单 |
| 02-审批 | 创建交货单、修改数量 | 删除订单 |
| 03-处理中 | 创建交货单 | 修改价格 |
| 04-已完成 | 查询、打印 | 修改 |
| 05-关闭 | 查询 | 所有修改 |

## 8. 接口设计

### 8.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/sd/orders | GET | 销售订单列表 |
| /api/sd/orders | POST | 创建销售订单 |
| /api/sd/orders/{id} | GET | 订单详情 |
| /api/sd/orders/{id} | PUT | 更新订单 |
| /api/sd/orders/{id} | DELETE | 删除订单 |
| /api/sd/orders/{id}/submit | POST | 提交审批 |
| /api/sd/orders/{id}/approve | POST | 审批通过 |
| /api/sd/orders/{id}/reject | POST | 审批拒绝 |
| /api/sd/orders/{id}/credit-check | POST | 信用检查 |
| /api/sd/orders/{id}/availability | GET | 可用性检查 |

### 8.2 创建订单请求示例

