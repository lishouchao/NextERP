# SD 交货管理设计

**模块**: Delivery Management (交货管理)
**对标**: SAP SD - VL01N/VL02N/VL03N
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

交货管理负责处理销售订单的出库与发运过程：

| 功能 | 说明 | SAP 对标 |
|------|------|----------|
| 交货单创建 | 从订单创建交货单 | VL01N |
| 拣配处理 | 拣配、包装 | VL02N |
| 发货过账 | 库存发货 | VL02N |
| 交货查询 | 查看交货状态 | VL03N |
| 装运管理 | 装运点、运输 | VT01N |

### 6.2 状态限制

| 当前状态 | 允许操作 | 限制操作 |
|----------|----------|----------|
| 01-未处理 | 修改、删除、拣配 | 发货过账 |
| 02-拣配中 | 确认拣配、取消拣配 | 删除交货单 |
| 03-已拣配 | 发货过账 | 修改数量 |
| 04-已发货 | 查询、打印 | 所有修改 |

```json
{
```
