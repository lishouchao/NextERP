# SD 开票管理设计

**模块**: Billing Management (开票管理)
**对标**: SAP SD - VF01/VF02/VF03
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

开票管理负责处理销售业务的发票与贷项凭证：

| 功能 | 说明 | SAP 对标 |
|------|------|----------|
| 开票创建 | 创建发票/贷项凭证 | VF01 |
| 开票过账 | 过账到财务 | VF01 |
| 开票查询 | 查看开票状态 | VF03 |
| 开票取消 | 取消已过账凭证 | VF11/S1 |
| 开票拆分 | 按规则拆分开票 | 拆分规则 |

## 7. 开票状态管理

### 7.1 状态类型

```
开票状态 (billing_status):
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   01 已创建 ──► 02 已过账 ──► 03 已取消                                     │
│       │             │              │                                        │
│       ▼             ▼              ▼                                        │
│    未过账        FI凭证生成      冲销凭证                                   │
│    可修改        生成应收        原凭证取消                                 │
│    可删除        不可修改        不可操作                                   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 7.2 状态限制

| 当前状态 | 允许操作 | 限制操作 |
|----------|----------|----------|
| 01-已创建 | 修改、删除、过账 | 生成应收 |
| 02-已过账 | 查询、打印、取消 | 修改、删除 |
| 03-已取消 | 查询 | 所有操作 |

|------|------|------|
| /api/sd/billings | GET | 开票凭证列表 |
