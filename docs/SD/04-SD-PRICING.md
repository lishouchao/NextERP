# SD 定价管理设计

**模块**: Pricing Management (定价管理)
**对标**: SAP SD - VK11/VK12/VK13
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

定价管理负责销售业务的价格与折扣配置：

| 功能 | 说明 | SAP 对标 |
|------|------|----------|
| 条件记录 | 维护价格条件 | VK11/VK12 |
| 定价过程 | 配置定价规则 | M/08 |
| 自动定价 | 销售单据定价 | - |
| 价格模拟 | 模拟定价结果 | - |

## 2. 条件类型

### 2.1 条件类型配置

| 条件类型 | 名称 | 计算类型 | 说明 |
|----------|------|----------|------|
| PR00 | 价格 | 固定金额 | 基础销售价格 |
| PR01 | 价格 | 固定金额 | 促销价格 |
| K004 | 客户折扣 | 百分比 | 客户级别折扣 |
| K005 | 物料折扣 | 百分比 | 物料级别折扣 |
| K007 | 附加费 | 百分比 | 运费等附加 |
| KF00 | 运费 | 固定金额 | 固定运费 |
| MWST | 税 | 百分比 | 销项税 |
| SKTO | 现金折扣 | 百分比 | 付款折扣 |


## 3. 条件记录

### 3.1 条件记录字段 (对标 SAP KONP)

| 字段 | 类型 | 说明 | SAP 字段 |
|------|------|------|----------|
| condition_type | VARCHAR(4) | 条件类型 | KSCHL |
| condition_record | VARCHAR(10) | 条件记录号 | KNUMH |
| condition_item | INTEGER | 条件项 | KOPOS |
| amount | DECIMAL(15,2) | 金额 | KBETR |
| rate | DECIMAL(9,5) | 比率/百分比 | KBETR |
| price_unit | INTEGER | 价格单位 | KPEIN |
| currency_id | UUID | 货币 | WAERS |
| calculation_type | VARCHAR(1) | 计算类型 | KRECH |
| valid_from | DATE | 有效开始 | DATAB |
| valid_to | DATE | 有效结束 | DATBI |
| sales_org_id | UUID | 销售组织 | VKORG |
| customer_id | UUID | 客户 | KUNNR |
| material_id | UUID | 物料 | MATNR |

```

│    10   PR00     销售价格                           -     -                │
│    20   K004     客户折扣                   10    10    -     -           │
│    30   K005     物料折扣                   10    10    -     -           │
│    40             小计1           10    30            -     X              │
│    50   K007     附加费                                 -     -           │
│    60   KF00     运费                                   -     -           │
```

## 8. 接口设计

### 8.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/sd/conditions | GET | 条件记录列表 |
| /api/sd/conditions | POST | 创建条件记录 |
| /api/sd/conditions/{id} | GET | 条件记录详情 |
| /api/sd/conditions/{id} | PUT | 更新条件记录 |
| /api/sd/conditions/{id} | DELETE | 删除条件记录 |
| /api/sd/pricing/preview | POST | 预览定价 |
| /api/sd/pricing-procedures | GET | 定价过程列表 |

### 8.2 创建条件记录请求

```json
{
  "conditionType": "PR00",
  "salesOrgId": "uuid-sales-org",
  "distributionChannel": "10",
  "customerId": "uuid-customer",
  "materialId": "uuid-material",
  "amount": 1000.00,
  "currencyId": "uuid-cny",
  "calculationType": "B",
  "validFrom": "2026-03-01",
  "validTo": "2026-12-31"
}
```

```json
{
  "salesOrgId": "uuid-sales-org",
```
