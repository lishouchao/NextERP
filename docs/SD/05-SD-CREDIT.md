# SD 信用管理设计

**模块**: Credit Management (信用管理)
**对标**: SAP SD - FD32/FD33
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

信用管理负责客户信用风险控制：

| 功能 | 说明 | SAP 对标 |
|------|------|----------|
| 信用主数据 | 维护客户信用额度 | FD32 |
| 信用检查 | 检查客户信用状态 | OVA8 |
| 信用监控 | 监控客户信用使用 | FD33 |
| 信用释放 | 释放信用冻结订单 | VKM1/VKM3 |

## 2. 客户信用主数据

### 2.1 信用主数据字段

| 字段 | 类型 | 说明 | SAP 字段 |
|------|------|------|----------|
| customer_id | UUID | 客户 | KUNNR |
| company_id | UUID | 公司代码 | BUKRS |
| credit_limit | DECIMAL(15,2) | 信用额度 | KLIMK |
| used_limit | DECIMAL(15,2) | 已用额度 | SKFOR |
| available_limit | DECIMAL(15,2) | 可用额度 | - |
| risk_class | VARCHAR(1) | 风险类别 | CTLPC |
| credit_group | VARCHAR(4) | 信用组 | KKBER |
| credit_status | VARCHAR(2) | 信用状态 | - |
| check_rule | VARCHAR(1) | 检查规则 | - |
| last_check_date | DATE | 上次检查日期 | - |
| next_check_date | DATE | 下次检查日期 | - |

### 4.2 状态影响

| 状态 | 订单创建 | 交货处理 | 开票处理 | 说明 |
|------|----------|----------|----------|------|
| 正常(01) | 正常 | 正常 | 正常 | 无限制 |
| 预警(02) | 警告提示 | 警告提示 | 正常 | 需关注 |
| 冻结(03) | 自动冻结 | 阻止 | 正常 | 需审批 |

## 7. 接口设计

### 7.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/sd/credit/{customerId} | GET | 客户信用概览 |
| /api/sd/credit/{customerId} | PUT | 更新信用主数据 |
| /api/sd/credit/check | POST | 执行信用检查 |
| /api/sd/credit/logs | GET | 信用检查日志 |
| /api/sd/credit/blocked-orders | GET | 冻结订单列表 |
| /api/sd/credit/release/{orderId} | POST | 释放冻结订单 |
