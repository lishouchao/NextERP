## 核心概念

### 销售范围

```
销售范围 = 销售组织 + 分销渠道 + 产品组

示例: 1000/10/01
- 销售组织: 1000 (华东销售区)
- 分销渠道: 10 (批发)
- 产品组: 01 (消费品)
```

### 分销渠道

| 代码 | 名称 | 说明 |
|------|------|------|
| 10 | 批发 | 批量销售给经销商 |
| 20 | 零售 | 零售终端销售 |
| 30 | 直销 | 直接销售给终端客户 |
| 40 | 电商 | 电子商务渠道 |

### 产品组

| 代码 | 名称 | 说明 |
|------|------|------|
| 01 | 消费品 | 快消品、日用品 |
| 02 | 工业品 | 工业设备、原料 |
| 03 | 服务 | 服务类产品 |

### 订单类型

| 类型 | 代码 | 说明 |
|------|------|------|
| 标准订单 | OR | 正常销售订单 |
| 贷项订单 | CR | 贷项凭证申请 |
| 借项订单 | DR | 借项凭证申请 |
| 退货订单 | RE | 退货处理 |

### 交货类型

| 类型 | 代码 | 说明 |
|------|------|------|
| 外向交货 | LF | 销售发货 |
| 退货交货 | LR | 客户退货 |
| 无订单交货 | LO | 无订单发货 |

### 开票类型

| 类型 | 代码 | 说明 |
|------|------|------|
| 发票 | F1/F2 | 销售发票 |
| 贷项凭证 | G2 | 贷项通知单 |
| 借项凭证 | L2 | 借项通知单 |
| 取消凭证 | S1 | 取消发票 |

## 业务流程

### 标准销售流程 (Order-to-Cash)

```
创建订单 ──► 审批 ──► 创建交货 ──► 拣配 ──► 发货过账 ──► 开票 ──► 收款
  (VA01)      (WF)     (VL01N)     (VL02N)    (VL02N)      (VF01)    (F-28)
     │          │          │           │          │           │         │
     ▼          ▼          ▼           ▼          ▼           ▼         ▼
  信用检查   订单释放   库存检查    分配库存   MM发货     FI过账    应收核销
```

### 定价流程

```
定价过程:
┌──────────────────────────────────────────────────────────────────┐
│  步骤10: PR00 价格                     1,000.00                  │
│  步骤20: K004 折扣 10% (10-10)          -100.00                  │
│  步骤30: 小计1 (10-20)                    900.00                  │
│  步骤40: MWST 税 13% (30-30)             +117.00                  │
│  步骤50: 总计 (10-40)                   1,017.00                  │
└──────────────────────────────────────────────────────────────────┘
```

### 信用检查流程

```
订单创建 ──► 信用检查 ──► [OK] ──► 继续处理
                 │
                 ├── [WA] ──► 警告提示 ──► 可继续
                 │
                 └── [BL] ──► 订单冻结 ──► 审批释放 ──► 继续
```
