## 2. 银行主数据

### 2.1 银行字段 (tr_bank)

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| bank_country | VARCHAR(3) | 是 | 银行国家 | BANKS |
| bank_key | VARCHAR(15) | 是 | 银行代码 | BANKL |
| bank_name | VARCHAR(100) | 是 | 银行名称 | BANKA |
| bank_name_en | VARCHAR(100) | 否 | 英文名称 | - |
| bank_type | VARCHAR(2) | 否 | 银行类型 | - |
| region_id | UUID | 否 | 地区 | PROVINZ |
| city | VARCHAR(40) | 否 | 城市 | ORT01 |
| street | VARCHAR(60) | 否 | 街道 | STRAS |
| postal_code | VARCHAR(10) | 否 | 邮编 | PSTLZ |
| swift_code | VARCHAR(11) | 否 | SWIFT代码 | SWIFT |
| contact_person | VARCHAR(80) | 否 | 联系人 | - |
| phone | VARCHAR(50) | 否 | 电话 | - |
| email | VARCHAR(100) | 否 | 邮箱 | - |
| status | VARCHAR(2) | 是 | 状态 | - |

### 2.2 银行类型

| 类型 | 代码 | 说明 |
|------|------|------|

| 外资银行 | 03 | 外资银行 |
| 政策性银行 | 04 | 政策性银行 |

## 3. 银行账户

### 3.1 账户字段 (tr_bank_account)

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| bank_id | UUID | 是 | 银行ID | - |
| bank_key | VARCHAR(15) | 是 | 银行代码 | BANKL |
| bank_name | VARCHAR(100) | 否 | 银行名称 | - |
| company_id | UUID | 是 | 公司ID | BUKRS |
| company_code | VARCHAR(4) | 是 | 公司代码 | - |
| account_number | VARCHAR(30) | 是 | 账号 | BKONT |
| account_name | VARCHAR(100) | 否 | 账户名称 | - |
| account_holder | VARCHAR(100) | 否 | 户名 | - |
| account_type | VARCHAR(2) | 是 | 账户类型 | - |
| currency_id | UUID | 是 | 货币ID | - |
| currency_code | VARCHAR(3) | 是 | 货币代码 | WAERS |
| gl_account_id | UUID | 否 | GL科目ID | - |
| gl_account_code | VARCHAR(10) | 否 | 科目代码 | HKONT |
| credit_limit | DECIMAL(18,2) | 否 | 授信额度 | - |
| used_limit | DECIMAL(18,2) | 否 | 已用额度 | - |
| interest_rate | DECIMAL(6,4) | 否 | 利率 | - |
| interest_type | VARCHAR(2) | 否 | 利率类型 | - |
| open_date | DATE | 否 | 开户日期 | - |
| maturity_date | DATE | 否 | 到期日期 | - |
| account_status | VARCHAR(2) | 是 | 账户状态 | - |
| is_primary | BOOLEAN | 否 | 主账户标识 | - |
| is_ebank_enabled | BOOLEAN | 否 | 网银启用 | - |
| ebank_url | VARCHAR(200) | 否 | 网银地址 | - |

### 3.2 账户类型

| 类型 | 代码 | 说明 | 特点 |
|------|------|------|------|
| 活期账户 | 01 | 活期存款 | 随时存取 |
| 定期账户 | 02 | 定期存款 | 固定期限 |
| 保证金账户 | 03 | 保证金 | 专款专用 |
| 外币账户 | 04 | 外币存款 | 外币结算 |
| 贷款账户 | 05 | 银行贷款 | 信贷业务 |

### 3.3 账户状态

| 状态 | 代码 | 说明 |
|------|------|------|
| 正常 | 01 | 正常使用 |
| 冻结 | 02 | 账户冻结 |
| 销户 | 03 | 已销户 |

### 3.4 利率类型

| 类型 | 代码 | 说明 |
|------|------|------|
| 固定 | 01 | 固定利率 |
| 浮动 | 02 | 浮动利率 |

## 4. 账户余额

### 4.1 余额字段 (tr_account_balance)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| account_id | UUID | 是 | 账户ID |
| account_number | VARCHAR(30) | 是 | 账号 |
| balance_date | DATE | 是 | 余额日期 |
| opening_balance | DECIMAL(18,2) | 是 | 期初余额 |
| closing_balance | DECIMAL(18,2) | 是 | 期末余额 |
| total_debit | DECIMAL(18,2) | 否 | 借方合计 |
| total_credit | DECIMAL(18,2) | 否 | 贷方合计 |
| in_transit | DECIMAL(18,2) | 否 | 在途金额 |
| frozen_amount | DECIMAL(18,2) | 否 | 冻结金额 |
| available_balance | DECIMAL(18,2) | 否 | 可用余额 |
| currency_id | UUID | 否 | 货币ID |

### 4.2 余额计算

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           余额计算逻辑                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   期末余额计算:                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   期末余额 = 期初余额 + 借方合计 - 贷方合计                          │   │
│   │                                                                       │   │
│   │   说明:                                                               │   │
│   │   - 借方合计 = 收入金额                                               │   │
│   │   - 贷方合计 = 支出金额                                               │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   可用余额计算:                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   可用余额 = 期末余额 - 冻结金额                                      │   │
│   │                                                                       │   │
│   │   冻结资金包括:                                                       │   │
│   │   - 开立银行承兑汇票保证金                                           │   │
│   │   - 履约保证金                                                       │   │
│   │   - 司法冻结资金                                                     │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 5. 接口设计

### 5.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/tr/banks | GET | 银行列表 |
| /api/tr/banks | POST | 创建银行 |
| /api/tr/banks/{id} | GET | 银行详情 |
| /api/tr/banks/{id} | PUT | 更新银行 |
| /api/tr/bank-accounts | GET | 银行账户列表 |
| /api/tr/bank-accounts | POST | 创建账户 |
| /api/tr/bank-accounts/{id} | GET | 账户详情 |
| /api/tr/bank-accounts/{id} | PUT | 更新账户 |
| /api/tr/account-balances | GET | 账户余额列表 |
| /api/tr/account-balances | POST | 记录余额 |
| /api/tr/account-balances/current | GET | 当前余额 |
