# TR 银行对账

**模块**: Bank Statement Processing
**对标**: SAP FF67/FEBA
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

| 功能 | 说明 | 对标 |
|------|------|------|
| 对账单导入 | 导入银行对账单 | FF67 |
| 对账单处理 | 对账单明细处理 | FEBA |
| 自动对账 | 自动匹配规则 | - |
| 手工对账 | 手工匹配处理 | FEBA |

### 1.2 银行对账流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           银行对账流程                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. 导入银行对账单                                                         │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 从网银下载对账单文件                                             │   │
│   │   - 支持格式: MT940 / BAI2 / 自定义                                  │   │
│   │   - 解析对账单头和明细                                               │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   2. 自动匹配                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 按金额匹配FI凭证                                                 │   │
│   │   - 按参考号匹配                                                     │   │
│   │   - 按日期匹配                                                       │   │
│   │   - 应用匹配规则                                                     │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   3. 手工对账                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 查看未匹配项目                                                   │   │
│   │   - 手工选择FI凭证进行对账                                           │   │
│   │   - 创建新的FI凭证 (如需要)                                          │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   4. 完成对账                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 检查对账状态                                                     │   │
│   │   - 生成对账报告                                                     │   │
│   │   - 过账差异                                                         │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. 银行对账单头

### 2.1 对账单头字段 (tr_bank_statement_hdr)

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| statement_number | VARCHAR(18) | 是 | 对账单号 | ANZBU |
| external_id | VARCHAR(35) | 否 | 外部ID | EXTERNO |
| account_id | UUID | 是 | 账户ID | - |
| account_number | VARCHAR(30) | 是 | 账号 | BKONT |
| bank_key | VARCHAR(15) | 否 | 银行代码 | BANKL |
| statement_date | DATE | 是 | 对账日期 | AZDAT |
| value_date | DATE | 否 | 起息日 | VALUT |
| opening_balance | DECIMAL(18,2) | 否 | 期初余额 | BALIN |
| closing_balance | DECIMAL(18,2) | 否 | 期末余额 | BALIN |
| currency_id | UUID | 否 | 货币ID | - |
| total_debit | DECIMAL(18,2) | 否 | 借方合计 | - |
| total_credit | DECIMAL(18,2) | 否 | 贷方合计 | - |
| debit_count | INTEGER | 否 | 借方笔数 | - |
| credit_count | INTEGER | 否 | 贷方笔数 | - |
| statement_status | VARCHAR(2) | 是 | 对账单状态 | - |
| is_reconciled | BOOLEAN | 否 | 已对账标识 | - |
| source_type | VARCHAR(2) | 否 | 来源类型 | - |
| file_name | VARCHAR(200) | 否 | 原始文件名 | - |

### 2.2 对账单状态

| 状态 | 代码 | 说明 |
|------|------|------|
| 导入 | 01 | 已导入 |
| 处理中 | 02 | 处理中 |
| 已对账 | 03 | 已对账 |
| 已过账 | 04 | 已过账 |

### 2.3 来源类型

| 类型 | 代码 | 说明 |
|------|------|------|
| 网银导入 | 01 | 网银下载 |
| 手工录入 | 02 | 手工录入 |
| EBICS | 03 | EBICS接口 |

## 5. 自动对账规则

### 5.1 对账规则

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           自动对账规则                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   规则优先级:                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   1. 参考号完全匹配 + 金额相等                                       │   │
│   │   2. 金额相等 + 日期相近 (±3天)                                      │   │
│   │   3. 金额相等 + 摘要包含关键字                                       │   │
│   │   4. 金额范围匹配 (容差范围内)                                       │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   匹配条件:                                                                 │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 金额匹配 (允许设置容差)                                          │   │
│   │   - 日期匹配 (允许设置天数范围)                                      │   │
│   │   - 参考号匹配                                                       │   │
│   │   - 摘要关键字匹配                                                   │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 6. 接口设计

### 6.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/tr/bank-statements | GET | 对账单列表 |
| /api/tr/bank-statements | POST | 创建对账单 |
| /api/tr/bank-statements/import | POST | 导入对账单 |
| /api/tr/bank-statements/{id} | GET | 对账单详情 |
| /api/tr/bank-statements/{id}/items | GET | 对账单明细 |
| /api/tr/bank-statements/{id}/auto-reconcile | POST | 自动对账 |
| /api/tr/bank-statements/{id}/reconcile | POST | 手工对账 |
| /api/tr/bank-statements/{id}/complete | POST | 完成对账 |
| /api/tr/reconciliations | GET | 对账记录列表 |
