**版本**: 1.0

## 1. 概述

### 1.1 功能范围

| 功能 | 说明 | 对标 |
|------|------|------|
| 现金头寸 | 现金头寸查询 | FF7A |
| 现金流量 | 现金流量记录 | FDES |
| 资金计划 | 资金计划编制 | FDES |
| 头寸分析 | 头寸报表 | FF7B |

### 1.2 现金管理架构

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           现金管理架构                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   数据来源                          现金头寸                                 │
│   ┌──────────┐   ┌──────────┐                                            │
│   │ 银行余额 │   │ 在途资金 │                                            │
│   └──────────┘   └──────────┘                                            │
│        │              │                                                    │
│   ┌──────────┐   ┌──────────┐      ┌─────────────────────────────────┐   │
│   │ 冻结资金 │   │ 信用额度 │ ───► │       现金头寸 (Cash Position)  │   │
│   └──────────┘   └──────────┘      │                                  │   │
│        │              │             │ 银行余额 + 在途 - 冻结 = 可用    │   │
│        └──────┬───────┘             │ 可用 + 信用额度 = 总可用         │   │
│               ▼                     └─────────────────────────────────┘   │
│   ┌──────────────────────────┐                                            │
│   │     现金流量 (Cash Flow) │                                            │
│   │                          │                                            │
│   │ - 经营活动现金流量       │                                            │
│   │ - 投资活动现金流量       │                                            │
│   │ - 筹资活动现金流量       │                                            │
│   └──────────────────────────┘                                            │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. 现金头寸

### 2.1 现金头寸字段 (tr_cash_position)

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| company_id | UUID | 是 | 公司ID | BUKRS |
| company_code | VARCHAR(4) | 是 | 公司代码 | - |
| position_date | DATE | 是 | 头寸日期 | DATUM |
| currency_id | UUID | 是 | 货币ID | - |
| bank_balance | DECIMAL(18,2) | 否 | 银行余额 | - |
| in_transit_in | DECIMAL(18,2) | 否 | 在途收入 | - |
| in_transit_out | DECIMAL(18,2) | 否 | 在途支出 | - |
| frozen_amount | DECIMAL(18,2) | 否 | 冻结资金 | - |
| cash_balance | DECIMAL(18,2) | 否 | 现金余额 | - |
| credit_available | DECIMAL(18,2) | 否 | 可用信用额度 | - |
| total_available | DECIMAL(18,2) | 否 | 总可用资金 | - |

### 2.2 头寸计算逻辑

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           现金头寸计算                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   现金余额计算:                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   现金余额 = 银行余额 + 在途收入 - 在途支出 - 冻结资金               │   │
│   │                                                                       │   │
│   │   示例:                                                               │   │
│   │   银行余额:    1,000,000.00                                          │   │
│   │   在途收入:      100,000.00                                          │   │
│   │   在途支出:       50,000.00                                          │   │
│   │   冻结资金:       80,000.00                                          │   │
│   │   ─────────────────────────────────────────────────────────────────│   │
│   │   现金余额:      970,000.00                                          │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   总可用资金计算:                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   总可用资金 = 现金余额 + 可用信用额度                               │   │
│   │                                                                       │   │
│   │   示例:                                                               │   │
│   │   现金余额:      970,000.00                                          │   │
│   │   可用信用额度:  500,000.00                                          │   │
│   │   ─────────────────────────────────────────────────────────────────│   │
│   │   总可用资金:  1,470,000.00                                          │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.3 头寸来源

| 组成部分 | 数据来源 |
|----------|----------|
| 银行余额 | 银行账户余额表 |
| 在途收入 | 未到账收款记录 |
| 在途支出 | 已支付未清算记录 |
| 冻结资金 | 银行账户冻结记录 |
| 信用额度 | 银行授信额度 |

## 3. 现金流量

### 3.1 现金流量字段 (tr_cash_flow_item)

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| company_id | UUID | 是 | 公司ID | BUKRS |
| flow_type | VARCHAR(2) | 是 | 流量类型 | - |
| direction | VARCHAR(1) | 是 | 方向 | - |
| category | VARCHAR(4) | 否 | 分类 | - |
| value_date | DATE | 是 | 起息日 | VALUT |
| amount | DECIMAL(18,2) | 是 | 金额 | WRBTR |
| currency_id | UUID | 否 | 货币ID | - |
| source_type | VARCHAR(2) | 否 | 来源类型 | - |
| source_document | VARCHAR(20) | 否 | 来源单据 | - |
| source_item | INTEGER | 否 | 来源项 | - |
| description | VARCHAR(100) | 否 | 描述 | SGTXT |
| is_planned | BOOLEAN | 否 | 计划标识 | - |
| is_realized | BOOLEAN | 否 | 实现标识 | - |
| realized_date | DATE | 否 | 实现日期 | - |

### 3.2 流量类型

| 类型 | 代码 | 说明 | 分类 |
|------|------|------|------|
| 经营活动 | 01 | 日常经营 | 经营 |
| 投资活动 | 02 | 投资支出 | 投资 |
| 筹资活动 | 03 | 融资活动 | 筹资 |

### 3.3 流量方向

| 方向 | 代码 | 说明 |
|------|------|------|
| 流入 | I | 现金流入 |
| 流出 | O | 现金流出 |

### 3.4 来源类型

| 类型 | 代码 | 说明 |
|------|------|------|
| FI凭证 | FI | 来自财务凭证 |
| 销售订单 | SD | 来自销售模块 |
| 采购订单 | MM | 来自采购模块 |
| 手工录入 | TR | 资金模块手工 |

## 5. 接口设计

### 5.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/tr/cash-positions | GET | 现金头寸列表 |
| /api/tr/cash-positions/{date} | GET | 指定日期头寸 |
| /api/tr/cash-positions/calculate | POST | 计算头寸 |
| /api/tr/cash-flows | GET | 现金流量列表 |
| /api/tr/cash-flows | POST | 创建现金流量 |
| /api/tr/cash-flows/{id} | GET | 现金流量详情 |
| /api/tr/cash-flows/{id}/realize | POST | 实现流量 |
| /api/tr/cash-flows/report | GET | 现金流量报表 |
