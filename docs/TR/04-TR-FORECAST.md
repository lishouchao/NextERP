# TR 流动性预测

**模块**: Liquidity Forecast
**对标**: SAP FF64/FF65
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

| 功能 | 说明 | 对标 |
|------|------|------|
| 预测生成 | 生成流动性预测 | FF64 |
| 预测调整 | 调整预测数据 | FF65 |
| 资金计划 | 编制资金计划 | FDES |
| 汇率管理 | 汇率维护 | OB08 |

### 1.2 预测流程

## 2. 流动性预测

### 2.1 预测头字段 (tr_forecast_hdr)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| forecast_number | VARCHAR(10) | 是 | 预测号 |
| forecast_type | VARCHAR(2) | 是 | 预测类型 |
| forecast_date | DATE | 是 | 预测日期 |
| period_start | DATE | 是 | 预测起始 |
| period_end | DATE | 是 | 预测结束 |
| company_id | UUID | 否 | 公司ID |
| currency_id | UUID | 否 | 货币ID |
| forecast_status | VARCHAR(2) | 是 | 预测状态 |
| created_by | UUID | 否 | 创建人 |

### 2.2 预测类型

| 类型 | 代码 | 说明 |
|------|------|------|
| 日预测 | 01 | 按日预测 |
| 周预测 | 02 | 按周预测 |
| 月预测 | 03 | 按月预测 |

### 2.3 预测状态

| 状态 | 代码 | 说明 |
|------|------|------|
| 创建 | 01 | 已创建 |
| 已确认 | 02 | 已确认 |

### 2.4 预测行字段 (tr_forecast_line)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| header_id | UUID | 是 | 预测头ID |
| company_id | UUID | 是 | 公司ID |
| forecast_date | DATE | 是 | 预测日期 |
| week_number | INTEGER | 否 | 周号 |
| month_number | INTEGER | 否 | 月号 |
| quarter_number | INTEGER | 否 | 季度号 |
| fiscal_year | INTEGER | 否 | 会计年度 |
| cash_flow_group | VARCHAR(4) | 否 | 现金流量组 |
| cash_flow_type | VARCHAR(2) | 是 | 类型 |
| certainty_level | VARCHAR(2) | 否 | 确定性级别 |
| inflow_amount | DECIMAL(18,2) | 否 | 流入金额 |
| outflow_amount | DECIMAL(18,2) | 否 | 流出金额 |
| net_flow | DECIMAL(18,2) | 否 | 净流量 |
| currency_id | UUID | 否 | 货币ID |
| source_type | VARCHAR(2) | 否 | 来源类型 |
| source_count | INTEGER | 否 | 来源单据数 |

### 2.5 现金流量类型

| 类型 | 代码 | 说明 |
|------|------|------|
| 应收 | 01 | 应收账款 |
| 应付 | 02 | 应付账款 |
| 税金 | 03 | 税金支付 |
| 工资 | 04 | 工资支付 |
| 其他 | 05 | 其他收支 |

### 2.6 确定性级别

| 级别 | 代码 | 说明 | 数据来源 |
|------|------|------|----------|
| 高 | A | 已确认 | 已开票应收/应付 |
| 中 | B | 已计划 | 计划收入/支出 |
| 低 | C | 预测 | 历史趋势预测 |

## 3. 预测生成

### 3.1 预测数据来源

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           预测数据来源                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   高确定性 (A):                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 已开票应收账款 (预计回款日期)                                    │   │
│   │   - 已确认应付账款 (预计付款日期)                                    │   │
│   │   - 到期贷款本息                                                     │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   中确定性 (B):                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 销售订单 (未开票)                                                │   │
│   │   - 采购订单 (未收票)                                                │   │
│   │   - 计划工资支付                                                     │   │
│   │   - 计划税费支付                                                     │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   低确定性 (C):                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 历史销售趋势预测                                                 │   │
│   │   - 历史采购趋势预测                                                 │   │
│   │   - 其他预测数据                                                     │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 4. 资金计划

### 4.1 资金计划头字段 (tr_cash_plan_hdr)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| plan_number | VARCHAR(10) | 是 | 计划号 |
| plan_name | VARCHAR(100) | 是 | 计划名称 |
| description | TEXT | 否 | 描述 |
| plan_type | VARCHAR(2) | 是 | 计划类型 |
| plan_date | DATE | 是 | 计划日期 |
| period_start | DATE | 是 | 期间起始 |
| period_end | DATE | 是 | 期间结束 |
| currency_id | UUID | 否 | 货币ID |
| plan_status | VARCHAR(2) | 是 | 计划状态 |
| approved_by | UUID | 否 | 审批人 |
| approved_at | TIMESTAMP | 否 | 审批时间 |

### 4.2 计划类型

| 类型 | 代码 | 说明 |
|------|------|------|
| 日计划 | 01 | 每日计划 |
| 周计划 | 02 | 每周计划 |
| 月计划 | 03 | 每月计划 |

### 4.3 计划状态

| 状态 | 代码 | 说明 |
|------|------|------|
| 草稿 | 01 | 草稿状态 |
| 已审批 | 02 | 已审批 |
| 已执行 | 03 | 已执行 |

### 4.4 计划行字段 (tr_cash_plan_line)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| header_id | UUID | 是 | 计划头ID |
| company_id | UUID | 是 | 公司ID |
| plan_date | DATE | 是 | 计划日期 |
| line_type | VARCHAR(2) | 是 | 行类型 |
| category | VARCHAR(4) | 否 | 分类 |
| planned_amount | DECIMAL(18,2) | 是 | 计划金额 |
| actual_amount | DECIMAL(18,2) | 否 | 实际金额 |
| variance | DECIMAL(18,2) | 否 | 差异 |
| currency_id | UUID | 否 | 货币ID |
| description | VARCHAR(100) | 否 | 描述 |

### 4.5 行类型

| 类型 | 代码 | 说明 |
|------|------|------|

## 5. 汇率管理

### 5.1 汇率类型字段 (tr_exchange_rate_type)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| rate_type_code | VARCHAR(2) | 是 | 汇率类型代码 |
| rate_type_name | VARCHAR(100) | 是 | 名称 |
| usage_type | VARCHAR(2) | 否 | 用途 |
| is_active | BOOLEAN | 是 | 是否激活 |

### 5.2 汇率类型

| 类型 | 代码 | 说明 |
|------|------|------|
| 记账汇率 | 01 | 用于日常记账 |
| 报表汇率 | 02 | 用于报表折算 |
| 预算汇率 | 03 | 用于预算编制 |

### 5.3 汇率字段 (tr_exchange_rate)

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| rate_type_id | UUID | 是 | 汇率类型ID | KURST |
| from_currency_id | UUID | 是 | 源货币ID | FCURR |
| from_currency | VARCHAR(3) | 是 | 源货币 | - |
| to_currency_id | UUID | 是 | 目标货币ID | TCURR |
| to_currency | VARCHAR(3) | 是 | 目标货币 | - |
| exchange_rate | DECIMAL(12,6) | 是 | 汇率 | UKURS |
| ratio_from | INTEGER | 否 | 比率(从) | - |
| ratio_to | INTEGER | 否 | 比率(到) | - |
| valid_from | DATE | 是 | 有效起始 | GDATU |
| valid_to | DATE | 否 | 有效结束 | - |
| is_active | BOOLEAN | 是 | 是否激活 | - |

## 6. 接口设计

### 6.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/tr/forecasts | GET | 预测列表 |
| /api/tr/forecasts | POST | 创建预测 |
| /api/tr/forecasts/{id} | GET | 预测详情 |
| /api/tr/forecasts/generate | POST | 生成预测 |
| /api/tr/forecasts/{id}/confirm | POST | 确认预测 |

| /api/tr/cash-plans | POST | 创建资金计划 |

| /api/tr/cash-plans/{id}/approve | POST | 审批计划 |
| /api/tr/exchange-rates | GET | 汇率列表 |
