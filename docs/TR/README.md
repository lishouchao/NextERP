# TR 资金管理模块

**对标**: SAP ECC TR (FDES/FF70/FF7A)
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 模块概述

TR (Treasury) 模块负责管理企业的现金流、银行账户和资金计划
提供现金管理、流动性预测和银行对账等功能。

### 核心能力

| 能力 | 说明 | 对标 |
|------|------|------|
| 现金管理 | 现金头寸管理 | FF7A/FF7B |
| 流动性预测 | 资金预测 | FF64/FF65 |
| 银行账户 | 银行账户管理 | FI12 |
| 银行对账 | 银行对账单 | FF67/FEBA |
| 资金计划 | 现金流量计划 | FDES |

## 资金管理流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           资金管理流程                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. 数据收集                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   应收预测 (SD) + 应付预测 (MM) + 税金计划 (FI) + 薪资计划 (HR)      │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   2. 流动性预测                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   生成未来期间的现金流预测                                           │   │
│   │   - Day 1-7: 高确定性                                               │   │
│   │   - Day 8-30: 中确定性                                              │   │
│   │   - Day 31-90: 低确定性                                             │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   3. 现金头寸分析                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   银行账户余额 + 在途资金 - 冻结资金 = 可用资金                      │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   4. 资金决策                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   盈余资金 → 理财投资 / 提前还款                                     │   │
│   │   资金缺口 → 银行借款 / 延迟付款                                     │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
