## 1. 概述

### 1.1 功能范围

| 子模块 | 说明 | SAP 对标 |
|--------|------|----------|
| 仓库号 | 仓库主数据 | SPRO |

| 仓位 | 具体仓位管理 | LS01N/LS02N |
| 转运需求 | 仓库需求 | LB10/LB11 |
| 转运单 | 仓库移动 | LT01/LT02 |
| 策略配置 | 上架/拣配策略 | OMLY |

### 2.2 仓库类型

| 类型 | 代码 | 说明 | 特点 |
|------|------|------|------|
| 标准仓库 | 01 | 标准仓库 | 货架存储 |

## 4. 转运流程

### 4.1 转运需求到转运单

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           转运流程                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. 转运需求 (TR)                                                          │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   来源: MM物料凭证 / 生产订单 / 销售订单                             │   │
│   │   内容: 物料、数量、源仓位、目标仓位                                 │   │
│   │   状态: 未处理 → 已创建TO → 已完成                                   │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   2. 转运单 (TO)                                                            │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   创建: 手工或自动从TR生成                                          │   │
│   │   内容: TR信息 + 作业指示                                           │   │
│   │   分配: 仓库人员                                                    │   │
│   │   状态: 创建 → 处理中 → 已确认                                      │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   3. 确认过账                                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   确认: 实际数量确认                                                │   │
│   │   差异: 记录差异数量和原因                                          │   │
│   │   更新: 仓位库存、TR状态、TO状态                                    │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.2 转运单类型

| 类型 | 代码 | 说明 | 触发场景 |
|------|------|------|----------|
| 上架 | 01 | 入库上架 | 收货触发 |
| 拣配 | 02 | 出库拣配 | 发货触发 |
| 内部转储 | 03 | 库内移动 | 库存调整 |
| 补货 | 04 | 库位补货 | 拣配补充 |

## 5. 策略配置

### 5.1 上架策略

| 策略 | 代码 | 说明 | 适用场景 |
|------|------|------|----------|
| 固定仓位 | 01 | 固定仓位 | 专用物料 |
| 空仓位 | 02 | 空仓位 | 新物料 |
| 混合仓位 | 03 | 混合存储 | 多品种小批量 |
| 就近上架 | 04 | 距离最近 | 快速周转 |

### 5.2 拣配策略

| 策略 | 代码 | 说明 | 适用场景 |
|------|------|------|----------|
| FIFO | 01 | 先进先出 | 有保质期物料 |
| LIFO | 02 | 后进先出 | 特殊行业 |
| FEFO | 03 | 先到期先出 | 食品医药 |
| 固定仓位 | 04 | 固定仓位拣配 | 专用物料 |
