## 2. 仓库号

### 2.1 仓库号字段 (wm_warehouse)

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| warehouse_number | VARCHAR(3) | 是 | 仓库号 | LGNUM |
| warehouse_name | VARCHAR(100) | 是 | 仓库名称 | LNUMT |
| plant_id | UUID | 是 | 工厂 | WERKS |
| sloc_id | UUID | 否 | 库存地点 | LGORT |
| warehouse_type | VARCHAR(2) | 否 | 仓库类型 | LGTYP |
| picking_strategy | VARCHAR(2) | 否 | 拣配策略 | - |
| warehouse_status | VARCHAR(2) | 否 | 状态 | - |

### 2.2 仓库类型

| 类型 | 代码 | 说明 | 特点 |
|------|------|------|------|
| 标准仓库 | 01 | 标准仓库 | 货架存储 |
| 高货架仓库 | 02 | 高货架库 | 高位存储 |
| 自动仓库 | 03 | AS/RS | 自动化 |
| 越库仓库 | 04 | 越库 | 快速周转 |

### 2.3 创建仓库号流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           创建仓库号流程                                     │
├─────────────────────────────────────────────────────────────────────────────┤

│   1. 定义基本信息                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 仓库号 (3位)                                                    │   │
│   │   - 仓库名称                                                        │   │
│   │   - 工厂/库存地点                                                   │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   2. 配置仓库参数                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 仓库类型                                                        │   │
│   │   - 默认拣配策略                                                    │   │
│   │   - 验证档案                                                        │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   3. 定义存储类型                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 创建至少一个存储类型                                            │   │

│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   4. 激活仓库号                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 仓库状态改为ACTIVE                                              │   │
│   │   - 可用于业务操作                                                  │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 3. 存储类型

### 3.1 存储类型字段 (wm_storage_type)

| 字段 | 类型 | 必填 | 说明 | 对标 |

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| warehouse_id | UUID | 是 | 仓库号 | LGNUM |

| bin_description | VARCHAR(100) | 否 | 仓位描述 | LPTXT |
| row_number | VARCHAR(4) | 否 | 行 | - |
| stack_level | VARCHAR(4) | 否 | 架/列 | - |
| level_number | VARCHAR(4) | 否 | 层 | - |

## 5. 固定仓位

### 5.1 固定仓位概念

固定仓位是指为特定物料分配的专用仓位，该物料只能存放在指定的仓位中。

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           固定仓位配置                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   物料 → 固定仓位映射:                                                      │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   物料代码   │  固定仓位  │  最大数量  │  存储类型                  │   │
│   │   MAT001    │  A-01-01  │  1000      │  001                       │   │
│   │   MAT002    │  A-01-02  │  500       │  001                       │   │
│   │   MAT003    │  B-02-01  │  2000      │  002                       │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   特点:                                                                     │
│   - 上架时只能放入固定仓位                                                  │
│   - 其他物料不能使用该仓位                                                  │
│   - 适用于高周转或专用物料                                                  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 6. 接口设计

### 6.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/wm/warehouses | GET | 仓库号列表 |
| /api/wm/warehouses | POST | 创建仓库号 |
| /api/wm/warehouses/{id} | GET | 仓库号详情 |
| /api/wm/warehouses/{id}/storage-types | GET | 仓库的存储类型 |
| /api/wm/storage-types | GET | 存储类型列表 |
| /api/wm/storage-types | POST | 创建存储类型 |
| /api/wm/storage-bins | GET | 仓位列表 |
| /api/wm/storage-bins | POST | 创建仓位 |
| /api/wm/storage-bins/batch | POST | 批量创建仓位 |
| /api/wm/storage-bins/{id} | PUT | 更新仓位 |
| /api/wm/storage-bins/{id}/block | POST | 阻止仓位 |
