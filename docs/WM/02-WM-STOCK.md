## 2. 仓位库存字段

### 2.1 仓位库存 (wm_bin_stock)

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| warehouse_id | UUID | 是 | 仓库号 | LGNUM |
| storage_type_id | UUID | 否 | 存储类型 | LGTYP |
| storage_bin_id | UUID | 是 | 仓位 | LGPLA |
| bin_code | VARCHAR(10) | 是 | 仓位号 | - |
| material_id | UUID | 是 | 物料 | MATNR |
| material_code | VARCHAR(18) | 是 | 物料代码 | - |
| plant_id | UUID | 是 | 工厂 | WERKS |
| batch_number | VARCHAR(10) | 否 | 批次号 | CHARG |
| quantity | DECIMAL(13,3) | 是 | 库存数量 | GESME |
| base_unit | VARCHAR(3) | 是 | 基本单位 | MEINS |
| value | DECIMAL(15,2) | 否 | 库存金额 | - |
| special_stock | VARCHAR(1) | 否 | 特殊库存 | BESTQ |
| stock_type | VARCHAR(2) | 否 | 库存类型 | - |
| stock_status | VARCHAR(2) | 否 | 库存状态 | - |
| gr_date | DATE | 否 | 入库日期 | - |

### 2.2 库存类型

| 类型 | 代码 | 说明 |
|------|------|------|
| 非限制 | 01 | 非限制使用 |
| 质检 | 02 | 质量检验 |
| 冻结 | 03 | 冻结状态 |

### 2.3 库存状态

| 状态 | 代码 | 说明 |
|------|------|------|
| 可用 | 01 | 可用 |
| 拣配中 | 02 | 正在拣配 |
| 锁定 | 03 | 已锁定 |

### 2.4 特殊库存标识

| 标识 | 代码 | 说明 |
|------|------|------|
| 销售订单 | E | 销售订单库存 |
| 寄售 | K | 客户寄售 |
| 分包订单 | O | 分包订单库存 |
| 项目 | Q | 项目库存 |

## 4. 库存转移

### 4.1 转移类型

| 类型 | 说明 | 对标 |
|------|------|------|
| 仓位到仓位 | 同存储类型内移动 | 999 |
| 存储类型转移 | 不同存储类型间移动 | 309/311 |
| 仓库间转移 | 不同仓库间移动 | 311 |

### 4.2 转移流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           库存转移流程                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. 创建转运需求 (TR)                                                      │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 源仓位: A-01-01                                                  │   │
│   │   - 目标仓位: B-02-01                                                │   │

│   │   - 数量: 100                                                        │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   2. 创建转运单 (TO)                                                        │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 从TR自动创建或手工创建                                           │   │

│   │   - 状态: 创建                                                       │   │

│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 确认实际数量                                                     │   │
│   │   - 记录差异(如有)                                                   │   │
```

## 6. 接口设计

### 6.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/wm/bin-stocks | GET | 仓位库存列表 |
| /api/wm/bin-stocks/{id} | GET | 仓位库存详情 |
| /api/wm/bin-stocks/query-by-bin | GET | 按仓位查询 |
