# WM 转运管理

**模块**: Transfer Order Management
**对标**: SAP WM (LT01/LT02/LT12)
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 1. 概述

### 1.1 功能范围

| 功能 | 说明 | 对标 |
|------|------|------|
| 转运需求 | 仓库移动需求 | LB10/LB11 |
| 转运单 | 仓库移动指令 | LT01/LT02 |
| 转运确认 | 确认移动完成 | LT12 |

### 1.2 转运流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           转运流程概览                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   来源单据                          WM 转运流程                             │
│   ┌──────────┐   ┌──────────┐                                             │
│   │ MM凭证   │   │ 生产订单 │                                             │
│   └──────────┘   └──────────┘                                             │
│        │              │                                                    │
│   ┌──────────┐   ┌──────────┐                                             │
│   │ 销售订单 │   │ 采购订单 │                                             │
│   └──────────┘   └──────────┘                                             │
│        │              │                                                    │
│        └──────┬───────┘                                                    │
│               ▼                                                            │
│   ┌───────────────────────────────────────────────────────────────────┐   │
│   │                      转运需求 (TR)                                 │   │
│   │   - 记录仓库移动需求                                               │   │
│   │   - 包含: 物料、数量、源仓位、目标仓位                             │   │
│   │   - 状态: 未处理 → 已创建TO → 已完成                               │   │
│   └───────────────────────────────────────────────────────────────────┘   │
│               │                                                            │
│               ▼                                                            │
│   ┌───────────────────────────────────────────────────────────────────┐   │
│   │                      转运单 (TO)                                   │   │
│   │   - 可执行的仓库移动指令                                           │   │
│   │   - 包含: TR信息 + 作业指示                                        │   │
│   │   - 状态: 创建 → 处理中 → 已确认                                   │   │
│   └───────────────────────────────────────────────────────────────────┘   │
│               │                                                            │
│               ▼                                                            │
│   ┌───────────────────────────────────────────────────────────────────┐   │
│   │                      确认过账                                       │   │
│   │   - 确认实际移动数量                                               │   │
│   │   - 记录差异数量和原因                                             │   │
│   │   - 更新仓位库存                                                   │   │
│   └───────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. 转运需求 (TR)

### 2.1 TR字段 (wm_transfer_requirement)

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| tr_number | VARCHAR(12) | 是 | TR号 | TBNUM |
| tr_item | INTEGER | 是 | TR项 | TBPOS |
| warehouse_id | UUID | 是 | 仓库号 | LGNUM |
| material_id | UUID | 是 | 物料 | MATNR |
| material_code | VARCHAR(18) | 是 | 物料代码 | - |
| plant_id | UUID | 是 | 工厂 | WERKS |
| batch_number | VARCHAR(10) | 否 | 批次号 | CHARG |
| quantity | DECIMAL(13,3) | 是 | 需求数量 | NSOLM |
| base_unit | VARCHAR(3) | 是 | 基本单位 | MEINS |
| source_st_type | VARCHAR(3) | 否 | 源存储类型 | - |
| source_bin | VARCHAR(10) | 否 | 源仓位 | VLPLA |
| dest_st_type | VARCHAR(3) | 否 | 目标存储类型 | - |
| dest_bin | VARCHAR(10) | 否 | 目标仓位 | NLPLA |
| movement_type | VARCHAR(3) | 是 | 移动类型 | BWART |
| source_type | VARCHAR(2) | 否 | 来源类型 | - |
| source_document | VARCHAR(20) | 否 | 来源单据 | - |
| priority | VARCHAR(2) | 否 | 优先级 | - |
| tr_status | VARCHAR(2) | 是 | TR状态 | TBNST |

### 2.2 TR状态

| 状态 | 代码 | 说明 |
|------|------|------|
| 未处理 | 01 | 待处理 |
| 已创建TO | 02 | 已生成转运单 |
| 已完成 | 03 | 已完成 |
| 取消 | 04 | 已取消 |

### 2.3 TR来源类型

| 类型 | 代码 | 说明 |
|------|------|------|
| MM凭证 | MM | 物料凭证触发 |
| 采购订单 | PO | 采购订单触发 |
| 销售订单 | SO | 销售订单触发 |
| 生产订单 | PR | 生产订单触发 |
| 手工创建 | MN | 手工创建 |

### 2.4 移动类型

| 类型 | 代码 | 说明 | 触发场景 |
|------|------|------|----------|
| 上架 | 101 | 入库上架 | 采购收货 |
| 拣配 | 201 | 出库拣配 | 销售发货 |
| 仓位转移 | 309 | 仓位间移动 | 库存调整 |
| 存储类型转移 | 311 | 存储类型间移动 | 库存调整 |

### 2.5 优先级

| 级别 | 代码 | 说明 |
|------|------|------|
| 紧急 | 01 | 最高优先 |
| 高 | 02 | 高优先 |
| 正常 | 03 | 正常 |
| 低 | 04 | 低优先 |

## 3. 转运单 (TO)

### 3.1 TO头字段 (wm_transfer_order_hdr)

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| to_number | VARCHAR(10) | 是 | TO号 | TANUM |
| warehouse_id | UUID | 是 | 仓库号 | LGNUM |
| to_type | VARCHAR(2) | 是 | TO类型 | - |
| tr_id | UUID | 否 | TR ID | - |
| tr_number | VARCHAR(12) | 否 | TR号 | TBNUM |
| source_type | VARCHAR(2) | 否 | 来源类型 | - |
| source_document | VARCHAR(20) | 否 | 来源单据 | - |
| assigned_to | UUID | 否 | 分配人员 | - |
| to_status | VARCHAR(2) | 是 | TO状态 | TASTA |
| created_date | DATE | 是 | 创建日期 | - |
| confirmed_date | DATE | 否 | 确认日期 | - |

### 3.2 TO项字段 (wm_transfer_order_item)

| 字段 | 类型 | 必填 | 说明 | 对标 |
|------|------|------|------|------|
| header_id | UUID | 是 | TO头ID | - |
| to_number | VARCHAR(10) | 是 | TO号 | TANUM |
| to_item | INTEGER | 是 | TO项 | TAPOS |
| material_id | UUID | 是 | 物料 | MATNR |
| material_code | VARCHAR(18) | 是 | 物料代码 | - |
| batch_number | VARCHAR(10) | 否 | 批次号 | CHARG |
| target_qty | DECIMAL(13,3) | 是 | 目标数量 | NSOLM |
| picked_qty | DECIMAL(13,3) | 否 | 拣配数量 | NISTA |
| difference_qty | DECIMAL(13,3) | 否 | 差异数量 | NDIFA |
| base_unit | VARCHAR(3) | 是 | 基本单位 | MEINS |
| source_st_type | VARCHAR(3) | 否 | 源存储类型 | VLTYP |
| source_bin | VARCHAR(10) | 否 | 源仓位 | VLPLA |
| dest_st_type | VARCHAR(3) | 否 | 目标存储类型 | NLTYP |
| dest_bin | VARCHAR(10) | 否 | 目标仓位 | NLPLA |
| movement_type | VARCHAR(3) | 否 | 移动类型 | BWART |
| item_status | VARCHAR(2) | 是 | 项状态 | PSTAT |
| tr_id | UUID | 否 | TR ID | - |

### 3.3 TO类型

| 类型 | 代码 | 说明 | 触发场景 |
|------|------|------|----------|
| 上架 | 01 | 入库上架 | 收货触发 |
| 拣配 | 02 | 出库拣配 | 发货触发 |
| 内部转储 | 03 | 库内移动 | 库存调整 |
| 补货 | 04 | 库位补货 | 拣配补充 |

### 3.4 TO状态

| 状态 | 代码 | 说明 |
|------|------|------|
| 创建 | 01 | 已创建 |
| 处理中 | 02 | 正在处理 |
| 已确认 | 03 | 已完成 |
| 取消 | 04 | 已取消 |

### 3.5 TO项状态

| 状态 | 代码 | 说明 |
|------|------|------|
| 未开始 | 01 | 未开始 |
| 已拣配 | 02 | 已拣配 |
| 已确认 | 03 | 已确认 |

## 4. TR创建流程

### 4.1 从MM凭证创建TR

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           从MM凭证创建TR                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. MM物料凭证过账                                                         │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   移动类型: 101 (采购收货)                                           │   │
│   │   物料: MAT001                                                       │   │
│   │   数量: 100 PC                                                       │   │
│   │   库存地点: 1000                                                     │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   2. 自动创建TR                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   TR号: TR0001                                                       │   │
│   │   移动类型: 101                                                      │   │
│   │   源仓位: 100 (收货暂存区)                                           │   │
│   │   目标仓位: (系统根据上架策略确定)                                   │   │
│   │   状态: 未处理                                                       │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 5. TO创建流程

### 5.1 从TR创建TO

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           从TR创建TO                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. 选择待处理的TR                                                         │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   TR号: TR0001                                                       │   │
│   │   状态: 未处理                                                       │   │
│   │   物料: MAT001                                                       │   │
│   │   数量: 100 PC                                                       │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   2. 确定目标仓位 (如果未指定)                                              │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 根据上架策略确定目标仓位                                         │   │
│   │   - 或根据拣配策略确定源仓位                                         │   │
│   │   - 检查仓位容量和状态                                               │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   3. 创建TO                                                                 │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   TO号: TO0001                                                       │   │
│   │   类型: 01 (上架)                                                    │   │
│   │   关联TR: TR0001                                                     │   │
│   │   状态: 创建                                                         │   │
│   │   TO项: 源仓位/目标仓位/物料/数量                                    │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   4. 更新TR状态                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   TR状态: 已创建TO                                                   │   │
│   │   关联TO: TO0001                                                     │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 6. TO确认流程

### 6.1 确认流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           TO确认流程                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. 选择待确认的TO                                                         │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   TO号: TO0001                                                       │   │
│   │   状态: 处理中                                                       │   │
│   │   TO项: 1项                                                          │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   2. 输入确认数量                                                           │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   目标数量: 100 PC                                                   │   │
│   │   确认数量: 98 PC (可修改)                                           │   │
│   │   差异数量: 2 PC (自动计算)                                          │   │
│   │   差异原因: (如有差异需选择)                                         │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                          │                                                  │
│                          ▼                                                  │
│   3. 更新库存和状态                                                         │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   - 更新TO项状态: 已确认                                             │   │
│   │   - 扣减源仓位库存                                                   │   │
│   │   - 增加目标仓位库存                                                 │   │
│   │   - 更新TO头状态: 已确认                                             │   │
│   │   - 更新TR状态: 已完成                                               │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 6.2 差异处理

| 差异原因 | 代码 | 说明 |
|----------|------|------|
| 损坏 | 01 | 物料损坏 |
| 丢失 | 02 | 物料丢失 |
| 数量不足 | 03 | 库存不足 |
| 其他 | 04 | 其他原因 |

## 7. 接口设计

### 7.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/wm/transfer-requirements | GET | TR列表 |
| /api/wm/transfer-requirements | POST | 创建TR |

| /api/wm/transfer-requirements/{id}/cancel | POST | 取消TR |

| /api/wm/transfer-orders/{id}/confirm | POST | 确认TO |
| /api/wm/transfer-orders/{id}/cancel | POST | 取消TO |
