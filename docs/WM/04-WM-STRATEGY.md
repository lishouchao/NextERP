## 2. 上架策略

### 2.1 上架策略字段 (wm_putaway_strategy)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| strategy_code | VARCHAR(2) | 是 | 策略代码 |
| strategy_name | VARCHAR(100) | 是 | 策略名称 |
| strategy_type | VARCHAR(2) | 是 | 策略类型 |
| material_group | VARCHAR(9) | 否 | 物料组 |
| priority_st_type_01 | VARCHAR(3) | 否 | 优先存储类型1 |
| priority_st_type_02 | VARCHAR(3) | 否 | 优先存储类型2 |
| priority_st_type_03 | VARCHAR(3) | 否 | 优先存储类型3 |
| capacity_check | BOOLEAN | 否 | 容量检查 |
| is_active | BOOLEAN | 是 | 是否激活 |

### 2.2 上架策略类型

| 类型 | 代码 | 说明 | 适用场景 |
|------|------|------|----------|
| 固定仓位 | 01 | 固定仓位 | 专用物料 |
| 空仓位 | 02 | 空仓位 | 新物料 |
| 混合仓位 | 03 | 混合存储 | 多品种小批量 |
| 就近上架 | 04 | 距离最近 | 快速周转 |

## 3. 拣配策略

### 3.1 拣配策略字段 (wm_picking_strategy)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| strategy_code | VARCHAR(2) | 是 | 策略代码 |
| strategy_name | VARCHAR(100) | 是 | 策略名称 |
| strategy_type | VARCHAR(2) | 是 | 策略类型 |
| material_group | VARCHAR(9) | 否 | 物料组 |
| batch_selection | VARCHAR(2) | 否 | 批次选择规则 |
| allow_partial | BOOLEAN | 否 | 允许部分拣配 |
| is_active | BOOLEAN | 是 | 是否激活 |

### 3.2 拣配策略类型

| 类型 | 代码 | 说明 | 适用场景 |
|------|------|------|----------|
| FIFO | 01 | 先进先出 | 有保质期物料 |
| LIFO | 02 | 后进先出 | 特殊行业 |
| FEFO | 03 | 先到期先出 | 食品医药 |
| 固定仓位 | 04 | 固定仓位拣配 | 专用物料 |

### 3.3 FIFO策略

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           FIFO (先进先出) 策略                               │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   适用场景:                                                                 │
│   - 有保质期的物料                                                          │
│   - 避免物料过期                                                            │
│   - 库存周转优化                                                            │
│                                                                             │
│   搜索逻辑:                                                                 │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   1. 查找物料所有库存仓位                                           │   │
│   │   2. 按入库日期升序排列                                             │   │
│   │   3. 优先拣配入库日期最早的仓位                                     │   │
│   │   4. 如数量不足,继续拣配下一仓位                                    │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   示例:                                                                     │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │   需求: MAT001, 150 PC                                              │   │
│   │                                                                       │   │
│   │   可用库存:                                                          │   │
│   │   A-01-01: 100 PC, 入库日期: 2026-01-15                             │   │
│   │   A-01-02: 80 PC,  入库日期: 2026-02-10                             │   │
│   │   B-02-01: 50 PC,  入库日期: 2026-03-01                             │   │
│   │                                                                       │   │
│   │   拣配结果:                                                          │   │
│   │   A-01-01: 100 PC (全部)                                            │   │
│   │   A-01-02: 50 PC  (部分)                                            │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 5. 接口设计

### 5.1 REST API

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/wm/putaway-strategies | GET | 上架策略列表 |
| /api/wm/putaway-strategies | POST | 创建上架策略 |
| /api/wm/putaway-strategies/{id} | PUT | 更新上架策略 |
| /api/wm/picking-strategies | GET | 拣配策略列表 |
| /api/wm/picking-strategies | POST | 创建拣配策略 |
| /api/wm/picking-strategies/{id} | PUT | 更新拣配策略 |
| /api/wm/strategies/determine-putaway-bin | POST | 确定上架仓位 |
| /api/wm/strategies/determine-picking-bin | POST | 确定拣配仓位 |
