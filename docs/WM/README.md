# WM 仓库管理模块

**对标**: SAP ECC WM (LL01/LL02/MB1B)
**版本**: 1.0
**更新日期**: 2026-03-16

---

## 模块概述

WM (Warehouse Management) 模块提供细粒度的仓库管理能力，支持仓位级别的库存管理和仓库作业执行。

### 核心能力

| 能力 | 说明 | 对标 |
|------|------|------|
| 仓库号 | 仓库主数据 | SPRO |
| 存储类型 | 存储区域定义 | OMLC |
| 仓位 | 具体仓位管理 | LS01N/LS02N |
| 转运需求 | 仓库需求 | LB10/LB11 |
| 转运单 | 仓库移动 | LT01/LT02 |
